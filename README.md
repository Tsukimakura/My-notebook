# Tsukimakura's notebook

支持个人服务器部署与站内 AI 问答；访问：<https://notes.tsukimakura.com/>。

一个以计算机科学、信息安全与基础学科为主的学习知识库。已发布内容位于 `docs/`；`drafts/` 仅用于暂存尚未归类的材料，不会随网站发布。

## 本地开发

前置要求：Python 3.12+ 与 Node.js 22.13+（CI 使用 Node.js 22）。

```bash
make bootstrap  # 首次安装 Python 与 Node 依赖
make serve      # 启动 http://127.0.0.1:8000/
make format     # 自动统一 Markdown 格式
make check      # 严格构建与链接检查
```

不用 `make` 时，也可执行：

```bash
.venv/bin/mkdocs serve
.venv/bin/mkdocs build --strict
```

## 发布与质量控制

- 对 `main` 的提交和 Pull Request 会自动执行严格构建。
- `main` 的检查通过后，构建并发布 GHCR 容器镜像，由个人服务器主动拉取更新。
- Python 和 Node 依赖分别固定在 `requirements.lock`、`package.json` 与 `package-lock.json`。
- 新笔记、公式和附件约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。

笔记包含学习过程与 AI 辅助整理的内容；重要结论请以教材、标准和原始资料为准。欢迎通过 Issue 或页面编辑链接提出修正。

## 站内 AI 与自托管

访客自带 OpenAI、DeepSeek 或 Anthropic API key，通过后端扩展检索词、检索公开笔记并回答。供应商、模型 ID、密钥及保存时间集中在对话栏的“设置”中。常用模型列表随供应商切换，同时保留手动输入；模型 ID 按供应商记住，已有自定义 ID 不会被列表覆盖。设置中提供官方模型目录及模型列表 API 的查询说明。

维护模型选项只需编辑 `docs/javascripts/notebook-ai-models.js`：按对应官方链接核实 API ID，修改 `models` 中的 `id`、`name` 和 `checked` 核对日期，再递增 `mkdocs.yml` 中该文件的 `?v=` 版本并提交发布。列表为人工维护的文字问答模型选项，不会自动调用供应商或验证账户权限；无需填写任何 key，也不要在此文件放入凭据。

key 默认在当前标签页临时保存，最多 2 小时；用户可主动选择在此浏览器记住 7 天或 30 天。期限从保存时计算，不随浏览或提问延长，到期后停止使用并在页面运行或下次打开时清除；可随时清除已保存 key。长期保存使用 localStorage，同源脚本和设备使用者可能读取，不应在公共设备上启用。后端不将 key、问题或回答写入磁盘或应用日志。任务结果仅在内存中暂存，完成后 2 分钟过期，定期清理；访问结果需要原来的 key。

桌面端对话位于右侧独立栏，手机端位于下半屏，等待回答时仍可阅读笔记。可新建、命名、切换和删除多个会话；切换时原会话继续生成，回答写回原会话。每个会话独立保存模型、检索范围、消息、引用和记忆；切换供应商或模型并保存会新建会话，旧会话仍可打开。

聊天记录使用浏览器 IndexedDB 保存，默认一直保留，也可选择 30 天或 90 天没有新消息后删除，在下次打开网站时清理。首次显示最近 20 轮，可加载更早的消息；单会话最多 2,000 条消息。支持导出和导入 JSON，导入会新增会话，不覆盖原记录；单次导入最多 100 个会话、20 MB。导出不包含应用保存的 API key，但包括聊天正文和用户填写的记忆，请自行保管。浏览器限制存储或空间不足时会提示；清除网站数据会丢失记录，不会自动同步到服务器或其他设备。

后续提问携带最近最多 3 轮、受长度限制的问答，加上本会话记忆和共享学习偏好。可以编辑记忆，或从回答中选择文字后点击“记住这条”；这不会额外调用模型。“整理旧对话”每次用一次模型调用，将最多 3 轮较早问答合入原有记忆，成功后显示整理到第几轮。自动整理默认关闭；主动开启后，在至少 4 轮旧问答尚未整理时，每次回答后最多额外整理一次。摘要失败、被截断或整理期间被手动修改时，不覆盖原有记忆。记忆只是背景，不作为笔记证据，历史引用编号不能直接沿用。清除记忆不会删除原消息，也不会自动重新整理已经清除的旧片段。

检索保留独立子问题，分别召回再合并，减少同一页面挤占来源。课程名称继承课程首页的中英文标题；课程总结先覆盖各章核心结论和学习路线，正文片段总预算为 24,000 字符、默认最多 12 条。可在目录树选择课程、单篇笔记或小节，并选择只在所选范围检索或允许补充；范围外来源标为“补充”。选择目录表示限定范围，不代表将目录全文发给模型。目录仅来自已发布网站的公开索引，后端只接受索引中存在的编号，不读取客户端提供的文件路径或外部网址。

正常每次提问调用两次模型，开启自动整理后可能额外调用一次，费用由访客承担。检索词扩展最多等待 15 秒，DeepSeek 的这一步关闭思考；正文生成保留所选模型默认的思考设置，预算上限为 8,192 tokens，较长的回答可能增加时间和费用。供应商报告达到输出上限、未正常结束或超过本站 64,000 字符上限时，页面保留已收到的内容并明确标为未完成。“准备续写”只填写追问，点击发送后才会再次调用模型；历史裁剪保留回答末尾，便于衔接未写完的内容。

新页面提交后台生成任务后，每 2 秒通过独立短请求查询状态，等待秒数由浏览器本地时钟每秒刷新。每次网络请求最多等待 12 秒；状态查询遇到临时网络错误时会有限重试，任务创建响应丢失时仅按原编号查询，不自动重新提交模型请求。任务编号与原 key 的短期哈希绑定，有效期内相同编号、相同输入不会重复生成；全站最多同时生成 4 个任务，内存任务记录最多 64 条。

生成时限为 4 分钟，浏览器为网络提交和查询留出额外余量。停止等待、删除正在生成的会话或离开页面会尽力取消对应任务，但不保证供应商停止计费。刷新后已有记录仍可恢复，未保存的生成结果不会自动重发。旧客户端的 `/api/ask` JSON 和 SSE 接口继续兼容。后台任务只在当前单进程内存中保存，运行模板固定一个 worker；重启或更新服务会丢失未取回的结果，页面会提示，不自动重复生成。

回答支持 Markdown 和 KaTeX 公式；原始 HTML 按文字显示，链接限制在本站。浏览器依赖随站点提供，更新依赖后使用 `npm run vendor:sync` 同步，并由 `make check` 检查一致性。

运行 `make ai-bootstrap` 安装后端依赖，使用 `make ai-serve` 预览完整功能。通用运行模板位于 `deploy/`；真实配置、凭据和运维记录不提交仓库。

默认访问 `http://127.0.0.1:8000`。端口占用时可运行 `make ai-serve PORT=8001`，并访问对应端口；`make serve` 仅提供静态预览。

## 界面与封面

网站通过 `overrides/` 定制首页和导航，正文、首页与问答共享 `docs/stylesheets/notebook-theme.css` 中的颜色与字体。明暗模式首次跟随系统，手动切换后记住选择；减少动态效果设置会关闭过渡动画。首页分区和课程入口在 `docs/index.md` 的页面信息中维护。

封面位于 `docs/assets/cover/afternoon.png`，使用维护者提供的图片，发布副本移除了文字元数据，像素保持不变。标题使用站内提供的 Noto Serif CJK 子集，许可见 `docs/assets/fonts/OFL-Noto.txt`；正文使用系统字体，不访问外部字体服务。字体子集仅在需要补字时使用 `scripts/subset_heading_font.py` 重新生成，网站构建不依赖字体处理工具。

问答栏可拖动边缘调整桌面宽度，手机端拖动顶部调整高度；也可聚焦分隔条后使用方向键，双击恢复默认。参考笔记默认折叠，点击回答中的编号仍会跳转正文；首页的问题建议只填入输入框，不自动调用模型。

选中笔记正文后，可通过“提问这段内容”添加引用，并优先检索这篇笔记。引用保留 LaTeX、链接和代码，显示排版预览，也可展开编辑 Markdown；输入框单独填写问题，点击发送后才调用模型。引用跳转会短暂标记对应小节，站内切换保留正在进行的对话；Esc 可先收起展开的工具，再收起问答栏。
