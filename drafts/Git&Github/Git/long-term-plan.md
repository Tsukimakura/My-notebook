# long-term-plan

## 第 1 周：基础夯实期

### 第 1-2 天：环境搭建与基础操作

- 完成 WSL + VS Code 环境配置

- 学习 `git init`、`git status`、`git add`、`git commit`

- 创建第一个本地仓库并提交 3-5 次更改

- 练习使用 `git log` 查看历史

**每日练习**：

```bash
# 创建练习项目
mkdir git-week1-practice
cd git-week1-practice
git init
# 创建多个文件并进行多次提交练习
```

### 第 3-4 天：分支管理入门

- 学习创建、切换、合并分支

- 练习功能分支工作流

- 理解合并冲突及解决方法

**实战项目**：使用分支开发一个简单的待办事项应用

### 第 5-7 天：远程仓库操作

- 配置 SSH 密钥连接 GitHub

- 学习 `git push`、`git pull`、`git clone`

- 创建个人项目并推送到 GitHub

- 练习从 GitHub 克隆开源项目

## 第 2 周：技能进阶期

### 第 8-9 天：高级分支操作

- 学习 `git rebase` 与 `git merge` 的区别

- 练习交互式变基整理提交历史

- 掌握 `git stash` 临时保存技巧

### 第 10-11 天：GitHub 协作功能

- 学习 Fork + Pull Request 工作流

- 为开源项目提交第一个 PR（可从文档修复开始）

- 学习 GitHub Issues 和 Projects 的使用

### 第 12-14 天：实战项目开发

- 使用 Git 管理一个完整的个人项目

- 实践功能分支工作流

- 学习使用 Git Hooks 进行自动化检查

## 第 3 周：精通掌握期

### 第 15-16 天：内部原理深入

- 理解 Git 对象模型（blob、tree、commit）

- 学习 `git cat-file`、`git ls-tree` 等底层命令

- 探索 `.git` 目录结构

### 第 17-18 天：团队协作规范

- 学习 Git Flow 工作流

- 制定团队 Git 使用规范

- 练习代码审查流程

### 第 19-21 天：高级故障处理

- 掌握 `git reflog` 找回丢失的提交

- 学习 `git bisect` 调试技巧

- 练习复杂合并冲突的解决

## 第 4 周及以后：持续提升

### 专业化发展方向

- **DevOps 方向**：GitHub Actions CI/CD 流水线

- **开源贡献**：成为开源项目维护者

- **团队管理**：制定团队 Git 工作流规范

- **工具开发**：开发 Git 扩展工具

### 持续学习资源

- [Pro Git 书籍](https://git-scm.com/book/zh/v2)

- [GitHub Skills](https://skills.github.com/)

- [Learn Git Branching](https://learngitbranching.js.org/)

## 📋 学习检查清单

### 基础技能 ✅

- 能够在本地创建和管理 Git 仓库

- 熟练使用基本的 add、commit、status、log 命令

- 理解工作区、暂存区、版本库的概念

- 能够创建、切换、合并分支

### 中级技能 ✅

- 能够使用 GitHub 进行远程协作

- 熟练解决合并冲突

- 理解 rebase 与 merge 的区别及应用场景

- 能够使用 Git Hooks 进行自动化

### 高级技能 ✅

- 理解 Git 内部工作原理

- 能够处理复杂的版本控制问题

- 能够制定团队 Git 使用规范

- 能够指导他人使用 Git

## 🎯 成功指标

- **1 个月**：能够独立使用 Git 进行个人项目开发

- **2 个月**：能够熟练参与团队协作项目

- **3 个月**：能够解决复杂的版本控制问题并指导他人
