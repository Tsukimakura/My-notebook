# 08_重积分

## 一、 重积分的基础理论

**1. 基本概念**

- **重积分的本质**：通过“分割、求和、取极限”三步定义。即 $\lim_{||T|| \to 0} \sum_{i=1}^m f(P_i) \sigma(D_i)$，其中分割细度 $||T||$ 为子区域直径的最大值。

- **可积的必要条件**：若函数 $f$ 在有界闭域上可积，则 $f$ 必须是**有界**的。

**2. 达布和与可积判别准则**

- **达布上下和**：达布上和为各子区域上确界与测度乘积之和，达布下和为下确界与测度乘积之和。加细分割会使达布下和变大，上和变小。

- **达布准则**：有界函数可积的充要条件是上积分等于下积分。二维 Dirichlet 函数因上下积分不相等而不可积。

**3. 零面积集与 Lebesgue 定理**

- **零面积（体积）集**：能被有限个总面积（体积）任意小的矩形（长方体）覆盖的集合。直线段、连续函数图像、分段光滑曲线均为零面积集。

- **Lebesgue 可积性定理**：有界函数可积的充要条件是其**所有间断点构成的集合是一个零测度集**（零面积/零体积集）。

- **一般集合上的积分判定**：若集合的边界是零面积集，且函数在集合内的间断点也是零面积集，则函数在该集合上可积。改变零面积集上的函数值不改变积分结果。

## 二、 重积分的基本性质

- **线性性质**：$\int_E (\alpha f + \beta g) d\sigma = \alpha \int_E f d\sigma + \beta \int_E g d\sigma$。

- **区域可加性**：若两区域交集为零面积集，则总积分为两区域积分之和。

- **非负性与保号性**：若 $f \ge g$，则其积分也满足相应的不等号关系。

- **面积定义**：集合 $E$ 的面积 $\sigma(E) = \iint_E 1 d\sigma$。集合可求面积的充要条件是其边界的面积为零。

- **积分中值定理**：若 $f, g$ 连续且 $g$ 不变号，则 $\int_K f g d\sigma = f(\xi) \int_K g d\sigma$。特别地，$\int_K f d\sigma = f(\xi) \sigma(K)$。

## 三、 二重积分的计算 (化为累次积分)

**1. 直角坐标系 (Fubini 定理)**

- **X 型区域**：上下边界为函数 $y_1(x) \le y \le y_2(x)$，左右边界为常数 $a \le x \le b$。

    - 公式：$\iint_E f d\sigma = \int_a^b dx \int_{y_1(x)}^{y_2(x)} f(x,y) dy$。

- **Y 型区域**：左右边界为函数 $x_1(y) \le x \le x_2(y)$，上下边界为常数 $c \le y \le d$。

    - 公式：$\iint_E f d\sigma = \int_c^d dy \int_{x_1(y)}^{x_2(y)} f(x,y) dx$。

- **解题技巧**：当某一次序下的内层积分原函数无法用初等函数表示时，需通过绘制区域图形**交换积分次序**来求解。

**2. 变量代换与雅可比行列式**

- **雅可比行列式本质**：刻画了二维平面映射过程中面积微元的**局部放大率**。$J = \frac{\partial(x,y)}{\partial(u,v)}$。

- **一般代换公式**：$\iint_D f(x,y) dxdy = \iint_\Delta f(x(u,v), y(u,v)) |J| dudv$。

**3. 极坐标变换**

- **标准极坐标**：$x = r\cos\theta, y = r\sin\theta$。雅可比行列式 $|J| = r$，微元变为 $r dr d\theta$。

- **定限方法**：

    - **极点在区域外部**（$\theta$ 型）：$\int_\alpha^\beta d\theta \int_{r_1(\theta)}^{r_2(\theta)} f \cdot r dr$。

    - **极点在区域内部**：$\int_0^{2\pi} d\theta \int_0^{r(\theta)} f \cdot r dr$。

    - **极点在区域边界上**：$\int_\alpha^\beta d\theta \int_0^{r(\theta)} f \cdot r dr$。

- **广义极坐标（针对椭圆）**：$x = ar\cos\theta, y = br\sin\theta$。雅可比行列式 $|J| = abr$。

- **极点平移**：若圆心在 $(x_0, y_0)$，则令 $x = x_0 + r\cos\theta, y = y_0 + r\sin\theta$，此时 $|J| = r$ 保持不变。

## 四、 三重积分的计算

**1. 直角坐标系**

- **“先一后二”法（投影法/柱体法）**：适用于上下曲面方程易确定的情况。

    - 公式：$\iiint_\Omega f dV = \iint_D dxdy \int_{z_1(x,y)}^{z_2(x,y)} f(x,y,z) dz$。

- **“先二后一”法（截面法/切片法）**：适用于截面面积容易求解的情况。

    - 公式：$\iiint_\Omega f dV = \int_e^h dz \iint_{D_z} f(x,y,z) dxdy$。

**2. 柱坐标变换**

- **坐标关系**：$x = r\cos\theta, y = r\sin\theta, z = z$。

- **雅可比行列式与微元**：$|J| = r$，微元 $dV = r dr d\theta dz$。

- **适用场景**：积分区域具有绕 $z$ 轴的旋转对称性（如圆柱、旋转抛物面、圆锥）。

**3. 球坐标变换**

- **坐标关系**：$x = r\sin\varphi\cos\theta, y = r\sin\varphi\sin\theta, z = r\cos\varphi$。（$\varphi$ 为与 $z$ 轴正向夹角，$\theta$ 为水平方位角）。

- **雅可比行列式与微元**：$|J| = r^2\sin\varphi$，微元 $dV = r^2\sin\varphi dr d\varphi d\theta$。

- **适用场景**：积分区域为球体、球壳、或顶点在原点的圆锥面。

- **广义球坐标（针对椭球）**：$x = ar\sin\varphi\cos\theta, y = br\sin\varphi\sin\theta, z = cr\cos\varphi$。雅可比行列式 $|J| = abcr^2\sin\varphi$。

**4. 补充常见曲面**

- **双曲抛物面 (马鞍面)**：标准方程 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = z$。形式为 $z = xy$ 的曲面本质上也是双曲抛物面。
