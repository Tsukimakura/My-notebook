# 02_子空间、向量空间的和、积与商

## 一、 子空间与和空间

- **子空间判定**：非空集合 $U \le V$ 的充要条件是：$0 \in U$，且对线性组合封闭（即 $\forall u, v \in U, \forall \alpha, \beta \in \mathbb{F} \implies \alpha u + \beta v \in U$）。

- **和空间定义**：$U_1 + \dots + U_m \triangleq \{u_1 + \dots + u_m \mid u_i \in U_i\}$。该空间等于这些子空间并集的张成空间 $L(\bigcup_{i=1}^m U_i)$。

---

## 二、 直和及其等价条件

- **直和定义**：若和空间中的任意向量 $w$ 都有**唯一**的分解式 $w = u_1 + \dots + u_m$，则称该和为直和，记作 $\oplus$。

- **等价判定定理**（互为充要条件）：

    1. 和空间为直和（$U_1 \oplus \dots \oplus U_m$）。

    2. **零向量表示法唯一**：$0 = w_1 + \dots + w_m \implies w_1 = w_2 = \dots = w_m = 0$。

    3. **交集为零**：任意子空间与其外其余子空间之和的交集均为 $\{0\}$。

    4. **维数可加**：$\dim(U_1 + \dots + U_m) = \sum_{i=1}^m \dim(U_i)$（限有限维空间）。

    5. **基的并集为基**：各子空间的基合并后，构成和空间的基。

---

## 三、 积空间与自然映射

- **积空间定义与运算**：由笛卡尔积 $V_1 \times \dots \times V_m$ 构成，内部的加法与数乘按**对应分量**进行运算。

- **维数公式**：$\dim(V_1 \times \dots \times V_m) = \sum_{i=1}^m \dim V_i$。

- **积空间内部结构**：积空间可视为各子空间自然嵌入后的直和。

    - _注：有限维时直积与直和同构；当包含无限多个空间时，直积（允许无限非零分量）与直和（仅限有限非零分量）不等价_。

- **自然映射**：定义映射 $T: U_1 \times \dots \times U_m \to U_1 + \dots + U_m$，规则为 $T(u_1, \dots, u_m) = u_1 + \dots + u_m$。

    - 映射 $T$ 必然是**线性映射**且为**满射**。

    - **单射等价性**：$T$ 为单射 $\iff$ 目标和空间是直和。
