# 06_本征值、本征向量与不变子空间

**基本设定**：数域 $\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$；有限维向量空间 $V$；线性算子 $T \in \mathscr{L}(V)$。

## 一、 不变子空间与衍生算子

### 1. 不变子空间

- **定义**：若子空间 $W \le V$ 满足 $\forall v \in W, Tv \in W$，则称 $W$ 为 $T$-不变子空间。

- **平凡不变子空间**：$\{0\}$、全空间 $V$、零空间 $\text{null } T$、值域 $\text{range } T$。

- **交换算子性质**：若算子 $S$ 与 $T$ 可交换（$ST = TS$），则 $\text{range } S$ 是 $T$-不变子空间。

- **注意**：不变子空间**不一定**存在不变的直和补空间。

### 2. 衍生算子

若 $W$ 是 $T$-不变子空间，可定义两个新算子：

- **限制算子** $T|_W : W \to W$

- **商算子** $T/W : V/W \to V/W$，定义为 $(T/W)(v+W) = Tv + W$。（具备良定义性与线性）

---

## 二、 本征值与本征子空间

### 1. 基本概念

- **定义**：若存在标量 $\lambda \in \mathbb{F}$ 及**非零向量** $v \in V$，使得 $Tv = \lambda v$，则 $\lambda$ 为本征值，$v$ 为对应的本征向量。

- **本征子空间**：$E(\lambda, T) = \text{null}(T - \lambda I)$。由零向量和属于 $\lambda$ 的所有本征向量组成，是 $T$-不变子空间。

### 2. 核心定理与性质

- **等价刻画**：$\lambda$ 是 $T$ 的本征值 $\iff T - \lambda I$ 不是单射 $\iff T - \lambda I$ 不是满射 $\iff T - \lambda I$ 不可逆。

- **存在性定理**：复数域 $\mathbb{C}$ 上的有限维线性算子**必定存在**至少一个本征值。

- **线性无关性**：属于**互异本征值**的本征向量必定**线性无关**。

- **直和性质**：互异本征值对应的本征子空间之和为**直和**，即 $E(\lambda_1, T) \oplus \dots \oplus E(\lambda_m, T)$。

- **数量限制**：互异本征值的个数 $m \le \dim V$。

---

## 三、 多项式算子与空间分解

### 1. 极小多项式

- **算子多项式**：$p(T) = a_0 I + a_1 T + \dots + a_m T^m$。多项式算子满足交换律（$p(T)q(T) = q(T)p(T)$）。

- **定义**：使 $q(T) = \mathbf{0}$ 的**次数最低的首一多项式**称为 $T$ 的极小多项式。

- **性质**：极小多项式是**唯一**的，且必**整除**任何使算子为零的多项式。

### 2. 准素分解（空间分解）定理

- 若 $f(T) = \mathbf{0}$，且 $f(x)$ 具有互素因子分解 $f(x) = p_1(x)^{e_1} \dots p_r(x)^{e_r}$（$p_i(x)$ 为不可约多项式）。

- **结论**：全空间可分解为不变子空间的直和：$V = V_1 \oplus V_2 \oplus \dots \oplus V_r$。其中 $V_i = \text{null } p_i(T)^{e_i}$，且均为 $T$-不变子空间。

---

## 四、 矩阵的上三角化（复数域）

### 1. 存在性与等价条件

- **定理**：在复数域 $\mathbb{C}$ 上，必定存在 $V$ 的一组基，使得算子 $T$ 的矩阵为**上三角矩阵**。

- **等价刻画**：设存在基 $v_1, \dots, v_n$，以下三者等价：

    1. $\mathcal{M}(T)$ 为上三角矩阵。

    2. $\forall j \in \{1, \dots, n\}$，$T v_j \in \text{span}(v_1, \dots, v_j)$。

    3. $\forall j \in \{1, \dots, n\}$，$\text{span}(v_1, \dots, v_j)$ 是 $T$-不变子空间。

### 2. 上三角矩阵的性质

若 $T$ 的矩阵为上三角矩阵：

- **本征值分布**：主对角线上的所有元素**恰好**是 $T$ 的全体本征值。

- **可逆性判定**：$T$ 可逆 $\iff$ 主对角线上的元素**全部不为 0**。

---

## 五、 算子可对角化的判定

对于 $\dim V = n$ 的空间与算子 $T \in \mathscr{L}(V)$，设其互不相同的本征值为 $\lambda_1, \dots, \lambda_m$。

### 1. 充要条件（等价刻画族）

以下命题完全等价（判断可对角化的核心依据）：

1. **定义**：$T$ 是可对角化的。

2. **基条件**：$V$ 中存在一组由 $T$ 的**本征向量**构成的基。

3. **分解条件1**：存在 $n$ 个一维的 $T$-不变子空间 $U_i$，使得 $V = U_1 \oplus \dots \oplus U_n$。

4. **分解条件2**：全空间是所有本征子空间的直和：$V = E(\lambda_1, T) \oplus \dots \oplus E(\lambda_m, T)$。

5. **维数条件**：全空间维数等于各本征子空间维数之和：$\dim V = \sum_{i=1}^m \dim E(\lambda_i, T)$。

### 2. 极小多项式准则

- **定理**：$T$ 可对角化 $\iff$ $T$ 的极小多项式**没有重根**（即由互不相同的线性因式相乘构成）。

### 3. 极简充分条件

- **定理**：若算子 $T$ 拥有 $n$ 个**互不相同**的本征值（即互异本征值个数等于空间维数），则 $T$ **必定可对角化**。
