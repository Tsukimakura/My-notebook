# ZJU校赛提升计划

## 核心战略

- **Web为主，其他为辅**：每天的前1小时专注于一个Web核心漏洞，后30分钟学习一个其他方向的基础知识点。

- **工具深化，理解原理**：不追求学新工具，而是把你已会的工具（sqlmap, nmap, dirsearch/gobuster）用得更精，并理解其背后的原理，这样才能应对CTF的变种题。

- **动手为王**：理论后立刻在CTF靶场或简单题目上实践，这是最高效的学习方式。

---

## 5天冲刺学习方案

### **第一天：Web深化 - SQL注入 | 其他方向 - 密码学基础**

**Web (1小时)：超越`sqlmap`的SQL注入**

- **学习目标**：理解SQL注入的各种类型，并能手动利用，因为CTF中经常需要绕过WAF或处理非常规注入。

- **学习内容**：

    1. **Union注入**：理解`ORDER BY`确定列数，`UNION SELECT`获取数据。

    2. **布尔盲注**：当页面没有回显数据，但会根据SQL语句真假返回不同页面时使用。

    3. **时间盲注**：当页面没有任何回显差异时，使用`sleep()`等函数通过页面响应时间判断。

    4. **堆叠查询**：能否执行多条SQL语句（`;`后跟新语句），这在某些题型中至关重要。

- **实践任务**：

    - 在 [sqli-labs](https://github.com/Audi-1/sqli-labs) 或 [PortSwigger的SQLi实验室](https://portswigger.net/web-security/sql-injection) 中，尝试**手动**完成至少一道联合注入和一道盲注题目。不要用sqlmap。

    - **思考**：如果sqlmap扫不出来，可能是什么原因？（如：需要特定的User-Agent、Token、或者被WAF拦截了）

**其他方向 (30分钟)：密码学 - 编码与古典密码**

- **学习目标**：能识别并解决CTF中最常见的密码学简单题。

- **学习内容**：

    1. **Base64/Base32/Hex**：一眼识别，熟练使用Python或在线工具解码。

    2. **ROT13**：凯撒密码的一种。

    3. **莫尔斯电码**、`AAencode`/`JJencode`等。

- **实践任务**：

    - 找一个包含Base64、Hex和莫尔斯电码的CTF题目练习（搜索“CTF crypto beginner”即可找到）。

---

### **第二天：Web深化 - XSS与CSRF | 其他方向 - 逆向工程基础**

**Web (1小时)：XSS与CSRF的本质**

- **学习目标**：理解XSS的三种类型及利用场景，理解CSRF的攻击原理。

- **学习内容**：

    1. **XSS**：

        - **反射型**： payload在URL中，需要用户点击。

        - **存储型**： payload被存入数据库，影响所有访问用户。

        - **DOM型**： 纯前端漏洞，不经过服务器。

    2. **如何利用**： 盗取Cookie（`document.cookie`）、发起HTTP请求、键盘记录等。

    3. **CSRF**： 诱导已登录用户访问恶意链接，以其身份执行非本意操作。

- **实践任务**：

    - 在 [XSS游戏](https://xss-game.appspot.com/) 完成前3关。

    - **思考**： 如何构造一个POC，证明存在存储型XSS？

**其他方向 (30分钟)：逆向工程 - 字符串分析**

- **学习目标**： 拿到一个二进制文件，能快速找到其中的flag字符串。

- **学习内容**：

    1. 使用 `strings` 命令：`strings binary_file | grep -i flag`

    2. 使用 `ltrace`/`strace` 跟踪程序执行。

- **实践任务**：

    - 下载一个简单的CTF逆向题（如来自 `pwnable.kr` 的 `flag` 题），尝试用 `strings` 直接找到flag。

---

### **第三天：Web深化 - 文件包含与文件上传 | 其他方向 - 隐写术基础**

**Web (1小时)：文件上传漏洞与目录遍历**

- **学习目标**：掌握绕过文件上传限制的技巧，理解目录遍历漏洞。

- **学习内容**：

    1. **文件上传**：

        - 绕过前端JS检查（Burp改包）。

        - 绕过MIME类型检查（`Content-Type`）。

        - 绕过后缀名检查（`.php` -> `.php5`, `.phtml`, `.phar`）。

        - 制作图片马。

    2. **目录遍历**： `../../../../etc/passwd`

- **实践任务**：

    - 在 [Upload Labs](https://github.com/c0ny1/upload-labs) 尝试前5关。

    - 使用 `dirsearch` 或 `gobuster` 扫描一个测试网站，尝试发现敏感的备份文件（如：`index.php.bak`, `.git`, `.DS_Store`）。

**其他方向 (30分钟)：隐写术 - 入门三板斧**

- **学习目标**： 解决大部分简单的图片隐写题。

- **学习内容**：

    1. `binwalk`： 分析图片中是否隐藏了其他文件。

    2. `steghide`： 无密码/已知密码提取隐藏文件（常用密码：空、`password`、`passwd`、`secret`）。

    3. `exiftool`： 查看图片元数据，flag可能在注释里。

    4. `strings`： 查看图片中的字符串。

- **实践任务**：

    - 找几道简单的CTF隐写题，依次使用上述工具尝试。

---

### **第四天：Web深化 - 命令执行与SSRF | 其他方向 - PWN基础**

**Web (1小时)：命令执行与SSRF**

- **学习目标**： 理解如何利用应用系统执行系统命令，以及如何让服务器发起内部网络请求。

- **学习内容**：

    1. **命令执行**：

        - 识别漏洞点（如：`ping.php?ip=127.0.0.1`）。

        - 连接命令（`;`, `|`, `&`, `&&`）。

        - 绕过空格限制（`${IFS}`, `<`, `%09`）。

    2. **SSRF**：

        - 利用`file://`协议读取本地文件。

        - 利用`http://127.0.0.1:8080`访问内网服务。

        - 利用DNS重绑定等技术绕过`127.0.0.1`限制。

- **实践任务**：

    - 在DVWA中设置难度为Low，实践Command Injection和SSRF模块。

    - **思考**： 命令执行拿到shell后，下一步做什么？（如：查找flag文件，权限提升）

**其他方向 (30分钟)：PWN - 缓冲区溢出概念**

- **学习目标**： 理解最简单的栈溢出原理，能完成覆盖返回地址的题目。

- **学习内容**：

    1. 什么是栈、函数调用约定、返回地址。

    2. 最简单的“覆盖返回地址”拿到shell。

- **实践任务**：

    - 搜索“CTF PWN beginner buffer overflow”，找一个最简单的教程，跟着做一遍，理解如何用一串AAA...覆盖到返回地址。

---

### **第五天：整合与策略 | 其他方向 - OSINT与杂项**

**Web & 整体 (1.5小时)：实战模拟与比赛策略**

- **学习目标**： 整合知识，制定比赛策略。

- **学习内容与任务**：

    1. **完整演练**： 找一个综合性的Web CTF题目（例如来自 [OverTheWire](https://overthewire.org/wargames/natas/) 的Natas关卡），尝试运用本周所学的所有Web技巧。

    2. **比赛策略**：

        - **先易后难**： 按分值从低到高，或按解题人数从多到少来做。

        - **分工合作（如果是团队）**： 明确各自方向。

        - **善用提示**： 关注题目名称、描述、附件文件名、标签，它们常常是关键词。

        - **永不放弃**： 查看网络请求/响应源代码，这是Web题的宝藏。

        - **学会求助**： 在比赛允许的范围内，善用Google、CTF Wiki和Writeups。

    3. **环境检查**： 确保你的比赛环境（虚拟机、工具、网络）都已就绪。

**其他方向 (概念了解)：OSINT与杂项**

- **学习目标**： 知道这些方向在考什么，遇到时知道从哪里入手。

- **学习内容**：

    - **OSINT**： 信息搜集。考察在公开渠道（如Google, GitHub, 社交媒体，图片元数据）寻找信息的能力。

    - **Misc**： 大杂烩。可能是日志分析、协议分析、编程题等。保持灵活思维。

### **资源汇总**

- **综合学习**：

    - [CTF Wiki](https://ctf-wiki.org/)： 你的圣经，遇到任何概念先去这里查。

    - [PortSwigger Web Security Academy](https://portswigger.net/web-security)： 最好的Web漏洞交互式教程。

- **靶场平台**：

    - [HackTheBox](https://www.hackthebox.com/)（部分免费）

    - [TryHackMe](https://tryhackme.com/)（对新手更友好）

    - [DVWA](https://github.com/digininja/DVWA) / [bWAPP](http://www.itsecgames.com/)（本地搭建）

- **练习平台**：

    - [CTFtime.org](https://ctftime.org/)： 查看近期比赛和往期题目。

    - [PicoCTF](https://picoctf.org/)： 最著名的新手友好CTF，题目存档可做。

**最后，给你几点临场建议：**

1. **保持冷静**： 遇到难题很正常，跳过去做别的。

2. **仔细阅读**： 题目描述和附件是解谜的关键。

3. **文档化**： 把你的解题过程、命令、payload记录下来，方便复盘和提交。

4. **享受过程**： CTF是学习和挑战的绝佳方式，即使没有拿到理想名次，你在这5天学到的东西也远超想象。

祝你比赛顺利，旗开得胜！
