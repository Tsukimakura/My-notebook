## Time & Power

先探查 data.npz 的字段和形状。

![[ctf101-misc2-15.png]]

进一步观察一下：

![[ctf101-misc2-16.png]]

检查每个位置尝试了哪些字符：

![[ctf101-misc2-17.png]]

基本能猜出来 input 字段就是爆破时每一个尝试的字符，input_id 就是爆破的 flag 的索引，power 是每一次尝试功耗随事件变化对应的 100 个采样点。

那大致思路就是：如果某个字符猜对，设备内部的比较过程可能略有不同，导致在某几个时间点的功耗会和猜错时不同。画出每次尝试对应的功耗变化图进行对比就行。

先对第一个字符的爆破画图尝试（把每次尝试的功率变化曲线叠加到一起，试图看出某一次的变化与其它明显不同）：

```python
import numpy as np
from matplotlib import pyplot as plt

data = np.load('data.npz')

pos = 0
mask = data["input_id"] == pos

chars = data["input"][mask]
traces = data["power"][mask]

plt.figure(figsize=(14, 6))

for char, trace in zip(chars, traces):
    plt.plot(trace, alpha=0.35, label=char)

plt.legend(ncol=4)
plt.savefig("position_0.png")
```

![[ctf101-misc2-18.png]]

![[ctf101-misc2-19.png]]
