#### 两种编译器如何实现 lambda 表达式，是否有较大区别

查看调用时的反编译、反汇编结果：

`g++`:

`ZNK3cmpMUlTyT_S0_iRbE_clIhEEDaS0_S0_iS1_(&cmp, *v5, v4, v11, &v8);`

![[ctf101-reverse1-7.png]]

`clang`:

`$_0::operator()<unsigned char>(&cmp, *v6, (unsigned __int8)v16[v8], v8, &v15);`

![[ctf101-reverse1-8.png]]

`cmp` 是 lambda 闭包对象，传进 `rdi` 的是 `&cmp`（第一个参数），即隐藏的 `this` 指针，符合成员函数调用的参数顺序。不是普通函数的函数指针调用（`mov rax, ...  call rax`）。

实现基本一致，没有很大区别。

同样还原 `cypher_crypt`

![[ctf101-reverse1-28.png]]

```c
void cipher_crypt(
    unsigned char *state,
    const unsigned char *input,
    int length,
    unsigned char *output
)
{
    unsigned char i = 0;
    unsigned char j = 0;

    for (int index = 0; index < length; index++)
    {
        i = (unsigned char)(i + 1);

        // 注意这里有额外的 +1
        j = (unsigned char)(state[i] + j + 1);

        unsigned char temp = state[i];
        state[i] = state[j];
        state[j] = temp;

        output[index] =
            state[(unsigned char)(state[i] + state[j])]
            ^ input[index];
    }
}
```

是 RC4 的魔改版，相比标准 RC4 `j = j + state[i]` 多加 1。

已知：输入 + 状态表 → cipher_crypt → 输出，还不知道状态表最初如何从密钥 `kEy3rd` 生成。查看 cipher_init：

![[ctf101-reverse1-29.png]]

```c
void cipher_init(
    unsigned char state[256],
    const unsigned char *key,
    int key_len
)
{
    unsigned char j = 0;

    for (int i = 0; i < 256; i++)
    {
        state[i] = (unsigned char)i;
    }

    for (int i = 0; i < 256; i++)
    {
        j = (unsigned char)(
            j + state[i] + key[i % key_len]
        );

        unsigned char temp = state[i];
        state[i] = state[j];
        state[j] = temp;
    }
}
```

- 与标准 RC4 的 KSA 一致

组合得到完整算法：

```c
void cipher_crypt(
    unsigned char state[256],
    const unsigned char *input,
    int length,
    unsigned char *output
)
{
    unsigned char i = 0;
    unsigned char j = 0;

    for (int index = 0; index < length; index++)
    {
        i = (unsigned char)(i + 1);

        // 与标准 RC4 的区别：多了 +1
        j = (unsigned char)(j + state[i] + 1);

        unsigned char temp = state[i];
        state[i] = state[j];
        state[j] = temp;

        unsigned char stream =
            state[(unsigned char)(state[i] + state[j])];

        output[index] = input[index] ^ stream;
    }
}
```
