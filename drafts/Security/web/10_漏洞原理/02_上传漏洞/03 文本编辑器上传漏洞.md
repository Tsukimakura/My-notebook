# 文本编辑器上传漏洞

> 编辑器上传漏洞通常指在网站集成的第三方富文本编辑器（如 **UEditor、FCKeditor、KindEditor、CKEditor** 等）中发现的配置不当或代码缺陷导致的上传漏洞。

- **识别编辑器及其版本**：

    - 查看 HTML 源代码中的路径（如 `/js/ueditor/`）。

    - 查看编辑器的“关于”页面或 `README.md`、`CHANGELOG` 文件。

- **寻找后台处理脚本**：

    - 利用 Burp Suite 抓包，看点击“上传图片”时请求发向了哪个路径（如 `controller.php` 或 `upload_json.asp`）。

- **测试已知 POC**：

    - 根据版本号搜索公开的漏洞利用代码（Exploit）。

- **尝试绕过策略**：

    - 尝试修改 MIME 类型。

    - 尝试 `%00` 截断。

    - 尝试构造畸形目录。
