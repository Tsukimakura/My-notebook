## Chapter 1: Introduction

**1.1 Problem Description**

The objective of this project is to process two separate binary search trees, denoted as $T_1$ and $T_2$, and an integer target $N$. The core task is to find all unique pairs of numbers $A$ (from $T_1$) and $B$ (from $T_2$) such that $A + B = N$.

**1.2 Background of the Algorithms**

The Binary Search Tree (BST) is a fundamental data structure defined recursively: for any given node, all keys in its left subtree are strictly smaller, and all keys in its right subtree are greater than or equal to the node's key.

To solve the $A+B=N$ problem efficiently without exceeding time limits, we rely on the inherent properties of BSTs:

1. **In-Order Traversal** of a BST naturally yields elements in strictly ascending order. This guarantees our output is formatted correctly without needing an explicit sorting step.

2. **Binary Search** allows us to find a target element in $O(\log K)$ average time, making the pair-matching process highly efficient.

## Chapter 2: Algorithm Specification

**2.1 Specifications of Main Data Structures**

The basic component is a standard BST node.

```c
typedef struct treeNode {
    struct treeNode *left;
    struct treeNode *right;
    int element;
} tree;
```

**2.2 Efficient Tree Construction Algorithm**

To avoid an $O(K^2)$ Time Limit Exceeded (TLE) error, the tree is constructed using a two-pass iterative approach with $O(K)$ complexity. Heap allocation is used to prevent Stack Overflow for large inputs.

**Pseudo-code: `CreateTree_Efficient(K)`**

```text
Algorithm CreateTree_Efficient(K):
    Input: K, the number of nodes in the tree
    Output: Pointer to the root of the constructed BST

    If K == 0 then return NULL

    Allocate array 'nodes' of size K on the heap
    Allocate array 'parents' of size K on the heap
    root_idx = -1

    // First Pass: Initialization
    For i from 0 to K - 1:
        Read element and parent_idx from standard input
        nodes[i].element = element
        parents[i] = parent_idx
        nodes[i].left = NULL
        nodes[i].right = NULL
        If parent_idx == -1 then
            root_idx = i

    // Second Pass: Linkage
    For i from 0 to K - 1:
        p = parents[i]
        If p == -1 then
            continue  // Skip the root node to prevent Out-Of-Bounds error

        If nodes[i].element < nodes[p].element then
            nodes[p].left = address of nodes[i]
        Else
            nodes[p].right = address of nodes[i]

    Free 'parents' array
    Return address of nodes[root_idx]
```

**2.3 Search and Traversal Algorithm**

This algorithm traverses $T_1$ to pick $A$, calculates the required $B = N - A$, and searches $T_2$ for $B$. It includes built-in deduplication logic using a `pre` variable.

**Pseudo-code: `InTraverse_Print(root1, root2, num, flag, pre)`**

```text
Algorithm InTraverse_Print(root1, root2, num, flag, pre):
    Input: root1 (current node of T1), root2 (root of T2), num (Target N),
           flag (boolean pointer), pre (pointer to last printed A)

    If root1 is NULL then return

    // Traverse left subtree
    InTraverse_Print(root1.left, root2, num, flag, pre)

    A = root1.element
    B = num - A

    // Search for B in T2 using standard BST Search (O(log N))
    If SearchTree(root2, B) is True:
        // Deduplication: Only print if it's the first match OR A is different from the last printed A
        If flag is True OR pre != A:
            If flag is True:
                Print "true"
                flag = False

            Print formatted equation: num = A + B
            pre = A  // Update tracking variable

    // Traverse right subtree
    InTraverse_Print(root1.right, root2, num, flag, pre)
```

## Chapter 3: Testing Results

### 3.1 Test Data Design and Rationale

To rigorously evaluate the robustness and correctness of the algorithm, the test data was specifically designed to cover normal operations, boundary conditions, and extreme structural scenarios. The rationale behind the test data selection is as follows:

1. **Standard Comprehensive Case:** Designed to verify basic tree construction, accurate $A+B=N$ matching, ascending order output, and the suppression of duplicate equations.

2. **No-Match Case:** Designed to test the boolean tracking logic (`flag`) to ensure the program correctly identifies when no pairs satisfy the sum condition and outputs `false`.

3. **Extreme Skewed Tree Case:** Designed to stress-test the algorithm's performance and recursion depth. In this case, both trees degrade into linked lists (each node only has a left child). This forces the $O(\log N_2)$ binary search to degrade to its worst-case $O(N_2)$ complexity, verifying that the program won't crash due to stack overflow and still produces correct logic.

## Chapter 4: Analysis and Comments

**4.1 Analysis of Complexities**

- **Time Complexity:**

	- Building $T_1$ and $T_2$ takes $O(N_1) + O(N_2)$ time using the optimized two-pass array mapping method.

    - The In-Order traversal visits every node in $T_1$, resulting in $N_1$ operations.

    - For each visited node, searching $T_2$ takes $O(\log N_2)$ on average (or $O(N_2)$ in the worst-case skewed tree scenario).

    - **Overall Average Time Complexity:** $O(N_1 + N_2 + N_1 \log N_2)$.

- **Space Complexity:**

    - Dynamic memory allocation (`malloc`) for storing the tree nodes and parent indices requires $O(N_1 + N_2)$ space on the heap.

    - The recursive call stack for the traversals requires $O(\log N_1 + \log N_2)$ space on average, up to $O(N_1 + N_2)$ in the worst-case skewed tree.

    - **Overall Space Complexity:** $O(N_1 + N_2)$.

**4.2 Comments on Further Possible Improvements**

1. **Iterative Traversals:** Currently, the In-Order and Pre-Order traversals are implemented recursively. While this is elegant, it poses a slight risk of stack overflow if the test cases involve an extremely deep, purely skewed tree (e.g., $10^5$ nodes in a single line). Rewriting the traversals iteratively using an explicit Stack data structure would guarantee absolute safety against stack overflow.

2. **Two-Pointers on Flattened Arrays:** Instead of searching $T_2$ for every element in $T_1$, we could perform In-Order traversals on both $T_1$ and $T_2$ to generate two sorted arrays. We could then use the classic "Two-Pointer Algorithm" (one pointer at the start of array 1, one at the end of array 2) to find all pairs in exactly $O(N_1 + N_2)$ time. This would drastically improve worst-case performance, changing the search time from $O(N_1 \times N_2)$ to strictly linear time.

### 2. `project2_funcs.c`

```c
#include <stdio.h>
#include <stdlib.h>
#include "project2.h"

/*
 * Function: createTree_efficient
 * Purpose: (Optimized O(N) Approach) Dynamically allocates memory for all nodes
 * and establishes parent-child linkages in exactly two linear passes over the input.
 */
tree *createTree_efficient(int n){
    // Edge case: if the tree has no nodes, return NULL immediately
    if(n == 0) return NULL;

    // Allocate memory for all nodes dynamically on the heap (avoids stack overflow)
    tree *nodes = malloc(n * sizeof(tree));
    // Allocate a temporary array to track the parent index for each node
    int *parents = malloc(n * sizeof(int));
    int root_idx = -1;

    // First Pass O(N): Read all data, initialize node values, and find the root
    for(int i = 0; i < n; i++){
        scanf("%d %d", &nodes[i].element, &parents[i]);
        nodes[i].left = nodes[i].right = NULL;
        // Identify the root node (it has no parent, denoted by -1)
        if(parents[i] == -1) root_idx = i;
    }

    // Second Pass O(N): Link nodes to their respective parents
    for(int i = 0; i < n; i++){
        int p = parents[i];

        // CRITICAL: The root node has no parent. Skip it to prevent Segmentation Fault.
        if(p == -1) continue;

        // Link the current node to its parent based on BST properties
        if(nodes[i].element < nodes[p].element){
            nodes[p].left = &nodes[i];
        }else{
            nodes[p].right = &nodes[i];
        }
    }

    // Free temporary array to prevent memory leaks
    free(parents);
    return (root_idx == -1) ? NULL : &nodes[root_idx];
}

/*
 * Function: searchTree
 * Purpose: Recursively searches for a target value 'n' within a BST.
 * Average Time Complexity: O(log N).
 */
int searchTree(int n, tree *root){
    // Base cases: reached a leaf's child, or successfully found the target
    if(root == NULL) return 0;
    if(n == root->element) return 1;

    // Recursive Step: Exploit BST property
    else if(n < root->element) return searchTree(n, root->left);
    else return searchTree(n, root->right);
}

/*
 * Function: inTraverse_print
 * Purpose: Performs In-Order traversal on T1. Calculates B = target - A,
 * searches T2 for B, and handles deduplication/printing.
 */
void inTraverse_print(tree *root1, tree *root2, int num, int *flag, int *pre){
    if(root1){
        // Traverse left subtree
        inTraverse_print(root1->left, root2, num, flag, pre);

        int n = root1->element;         // Candidate 'A'
        int searchfor = num - n;        // Required 'B'

        // If B exists in T2
        if(searchTree(searchfor, root2)){
            // DEDUPLICATION: Only print if it is the first match OR 'A' is not a duplicate
            if (*flag || *pre != n) {
                if (*flag) {
                    printf("true\n");
                    *flag = 0; // Toggle flag so "true" isn't printed again
                }

                // Print the formatted equation
                printf("%d = %d %c %d\n", num, n,
                    (searchfor < 0)?'-':'+', (searchfor < 0)?-searchfor:searchfor);

                // Update pre to suppress subsequent identical 'A's
                *pre = n;
            }
        }

        // Traverse right subtree
        inTraverse_print(root1->right, root2, num, flag, pre);
    }
}

/*
 * Function: preorder_print
 * Purpose: Pre-Order traversal (Root -> Left -> Right).
 * Uses 'flag' to prevent printing a leading space on the very first element.
 */
void preorder_print(tree *root, int flag){
    if(root){
        if(!flag) printf(" ");
        printf("%d", root->element);
        preorder_print(root->left, 0);
        preorder_print(root->right, 0);
    }
}
```

### 3. `project2_main.c`

```c
#include <stdio.h>
#include "project2.h"

int main(){
    int n1, n2, num;

    // flag = 1 means 'true' is not printed yet. It also tracks if any matches were found.
    int flag = 1;
    // Tracks the last printed value from T1 to skip duplicates
    int pre = 0;

    // Read and construct T1 dynamically
    scanf("%d", &n1);
    tree *root1 = createTree_efficient(n1);

    // Read and construct T2 dynamically
    scanf("%d", &n2);
    tree *root2 = createTree_efficient(n2);

    // Read target sum N
    scanf("%d", &num);

    // Traverse T1, search T2, and print matching equations in ascending order
    inTraverse_print(root1, root2, num, &flag, &pre);

    // If flag is still 1 after traversal, no pairs were found at all
    if(flag) printf("false\n");

    // Print pre-order sequences for both trees
    preorder_print(root1, 1);
    printf("\n");
    preorder_print(root2, 1);

    return 0;
}
```
