# Obsidian hotkeys

Obsidian 的快捷键非常多，而且支持完全自定义。为了让你快速上手，我将它们分为了 **“核心必记”、“编辑排版”和“界面操作”** 三个等级。

*(注：Windows/Linux 请用 `Ctrl`，macOS 请用 `Cmd`)*

## 1. 核心必记（记这两个就够用了）

如果你不想背太多，**只需要记住这两个**，它们能让你通过键盘完成几乎所有操作：

*   **`Ctrl / Cmd + P`**：**打开命令面板 (Command Palette)**
    *   *作用*：这是 Obsidian 的“上帝模式”。忘了快捷键？想调整设置？想导出 PDF？按这个键，输入你想做的事（如“导出”、“删除”），直接回车即可执行。
*   **`Ctrl / Cmd + O`**：**快速切换文件 (Quick Switcher)**
    *   *作用*：不用在左侧文件列表里翻找，直接输入文件名（支持模糊搜索），回车即打开笔记。

---

## 2. 高频编辑与排版（提升写作速度）

这些是 Markdown 通用或 Obsidian 特有的高频操作：

*   **`Ctrl / Cmd + E`**：**切换 编辑模式 / 阅读模式**
    *   *必用*：写完一段话，想看看渲染效果，或者想点链接时使用。
*   **`Ctrl / Cmd + L`**：**切换 列表 / 待办事项**
    *   *神技*：在普通文本前按一下变无序列表，再按一下变复选框，再按一下取消。
*   **`[[`**（直接输入双中括号）：**插入双向链接**
    *   *核心*：Obsidian 的灵魂，输入后选择已有笔记即可建立关联。
*   **`Ctrl / Cmd + B`**：加粗
*   **`Ctrl / Cmd + I`**：斜体
*   **`Ctrl / Cmd + K`**：插入普通网页链接 `[显示文本](URL)`

---

## 3. 界面与文件管理

*   **`Ctrl / Cmd + N`**：新建笔记
*   **`Ctrl / Cmd + W`**：关闭当前标签页
*   **`Ctrl / Cmd + Shift + F`**：**全局搜索**（在所有笔记中查找内容）
*   **`Ctrl / Cmd + ,`**：打开设置界面
*   **`Ctrl / Cmd + \`** (部分系统需手动设置)：拆分窗口（左右对照看笔记时很有用）

---

## 💡 进阶技巧：如何自定义快捷键？

Obsidian 最强大的地方在于你可以把**任何功能**绑定成快捷键（甚至是插件的功能）。

1. 按下 `Ctrl / Cmd + ,` 打开**设置**。
2. 点击左侧的 **“快捷键” (Hotkeys)**。
3. 在搜索框输入你想设置的功能（例如“模板”、“移动文件”）。
4. 点击右侧的 `+` 号录入你习惯的按键。

**推荐自定义的快捷键（默认可能没有）：**
*   **插入模板**：建议绑定为 `Alt + T`，配合 Templates 插件使用极爽。
*   **折叠/展开当前标题**：对于写长文非常有帮助。

编辑 `.md` (Markdown) 文件时，为了不打断写作思路，我们通常会混用**“通用组合键”**和**“Markdown 语法符号”**。

由于你正在使用 Obsidian，以下快捷键以 **Obsidian** 为主，同时也适用于 VS Code、Typora 等主流 Markdown 编辑器。

*(注：Windows 用 `Ctrl`，Mac 用 `Cmd`)*

## 1. 文本格式化（最通用，肌肉记忆）

这些快捷键和 Word、Google Docs 是一样的，几乎所有 Markdown 编辑器都支持：

*   **`Ctrl / Cmd + B`**：**加粗** (Bold) —— 自动插入 `**`
*   **`Ctrl / Cmd + I`**：*斜体* (Italic) —— 自动插入 `*`
*   **`Ctrl / Cmd + K`**：**插入链接** —— 自动生成 `[]()` 结构，且光标会在 URL 处等待粘贴。
*   **`Ctrl / Cmd + /`**：**注释** —— 选中文字按此键，会自动将其变为 `%%注释内容%%` (Obsidian) 或 HTML 注释 `<!-- -->` (其他编辑器)。

## 2. 结构与列表（极速排版）

在 Markdown 中，列表和层级的调整非常频繁：

*   **`Tab`**：**缩进 / 下一级** —— 光标在列表行首时，按一下变为子列表。
*   **`Shift + Tab`**：**取消缩进 / 上一级** —— 列表层级太深了，按这个退回来。
*   **`Ctrl / Cmd + Enter`**：**在下方插入行** —— 即使光标在段落中间，也能直接跳到下一行开始新段落（不用把光标移到行尾再回车）。
*   **`Ctrl / Cmd + L`** (Obsidian 特有)：**列表/复选框切换** —— 按一下变无序列表 `-`，再按一下变任务框 `- [ ]`，非常方便。

## 3. 行操作（写作神器，不用鼠标）

这组快捷键能极大地提升修改文章的效率，强烈建议掌握：

*   **`Alt / Opt + ↑` 或 `↓`**：**整行移动** —— 想把这段话挪到上面去？不用剪切粘贴，按住 Alt 按方向键直接“搬运”整行文字。
*   **`Ctrl / Cmd + D`** (部分编辑器需设置) 或 **`Ctrl / Cmd + Shift + K`**：**删除整行** —— 快速清理不需要的段落。
*   **`Alt / Opt + Click`** (鼠标点击)：**多光标编辑** —— 在不同位置点几下，可以同时编辑多个地方（比如批量修改列表头）。

## 4. 标题与引用（符号比快捷键更快）

对于标题和引用，虽然有快捷键，但直接输入 Markdown 符号往往**比按组合键更快**：

*   **标题**：直接输入 `#` 加空格。
    *   `# ` = 一级标题
    *   `## ` = 二级标题
    *   以此类推，最多 6 级。
*   **引用**：直接输入 `> ` 加空格。
    *   效果：生成灰色的引用块。
*   **代码块**：输入三个反引号 **\`\`\`** 然后回车。
    *   效果：插入代码编辑区域。

## 5. Obsidian 特有且高频的编辑键

*   **`[[`**：触发双向链接（输入即弹出笔记列表）。
*   **`![[`**：嵌入图片或笔记预览。
*   **`Ctrl / Cmd + Shift + V`**：**纯文本粘贴** —— 当你从网页复制带格式的文字时，用这个粘贴，会自动清除乱七八糟的格式，只保留文字。

## 💡 总结建议

如果你只想记 3 个最能提升效率的：
1. **`Ctrl + K`**（插链接）
2. **`Alt + 上下箭头`**（移动整行，排版神器）
3. **`[[`**（直接打符号链接笔记）
