    一、 一致收敛性

    1. 函数列及其点态收敛

    1.1 函数列与收敛域的定义

    • 定义 1（函数列）： 设 \(E \subset \mathbb{R}\)，且 \(f_1, f_2, \dots, f_n, \dots\) 是一组定义在 \(E\) 上的函数。我们称该函数集为定义在 \(E\) 上的一个函数列，记作 \(\{f_n\}\) 或 \(f_n \ (n=1, 2, \dots)\)。

    • 定义 2（点态收敛与收敛域）： 在定义 1 的条件下，给定一点 \(x_0 \in E\)：

      • 如果数列 \(\{f_n(x_0)\}\) 收敛（或发散），则称函数列 \(\{f_n\}\) 在点 \(x_0\) 处收敛（或发散）。

      • 集合 \(\{x \in E : \{f_n\} \text{ 在点 } x \text{ 处收敛}\}\) 称为函数列 \(\{f_n\}\) 的收敛域。

    1.2 极限函数

    给定 \(D \subset E\)，若对于 \(\forall x \in D\)，函数列 \(\{f_n\}\) 都在点 \(x\) 处收敛，则可以定义一个函数 \(f: D \to \mathbb{R}\)，映射关系为 \(x \mapsto \lim_{n \to \infty} f_n(x)\)。

    即：

    \[ f(x) = \lim_{n \to \infty} f_n(x), \quad x \in D \]

    • 称 \(f\) 为 \(\{f_n\}\) 在 \(D\) 上的极限函数。

    • 此时也称函数列 \(\{f_n\}\) 在 \(D\) 上收敛于 \(f\)（或称为点态收敛于 / 逐点收敛于 \(f\)）。

    点态收敛的 \(\varepsilon-N\) 语言表述：

    \[ \{f_n\} \text{ 在 } D \text{ 上逐点收敛于 } f \iff \forall x \in D, \forall \varepsilon > 0, \exists N \in \mathbb{Z}^+, \text{ s.t. 当 } n \ge N \text{ 时, 有 } |f_n(x) - f(x)| < \varepsilon \]

    (注：在点态收敛中，正整数 \(N\) 既依赖于 \(\varepsilon\)，也依赖于选取的点 \(x\)。即 \(N = N(\varepsilon, x)\)。)

    【例题】 研究函数列 \(f_n(x) = x^n\) 在 \([0, 1]\) 上的收敛性。

    解答： 当 \(x \in [0, 1)\) 时，\(\lim_{n \to \infty} x^n = 0\)；当 \(x = 1\) 时，\(\lim_{n \to \infty} 1^n = 1\)。

    因此，该函数列在 \([0, 1]\) 上逐点收敛于极限函数 \(f(x)\)：

    \[ f(x) = \begin{cases} 0, & x \in [0, 1) \\ 1, & x = 1 \end{cases} \]

    2. 函数列的一致收敛

    2.1 一致收敛的定义

    设函数列 \(\{f_n\}\) 与函数 \(f\) 都在定义域 \(D\) 上有定义。

    若 \(\forall \varepsilon > 0, \exists N \in \mathbb{Z}^+\)，s.t. 当 \(n \ge N\) 时，对 \(\forall x \in D\)，都有 \(|f_n(x) - f(x)| < \varepsilon\)，则称 \(\{f_n\}\) 在 \(D\) 上一致收敛于 \(f\)。

    • 记作： \(f_n(x) \rightrightarrows f(x) \ (n \to \infty, x \in D)\) 或 \(f_n \stackrel{D}{\rightrightarrows} f\)。

      (注：在一致收敛中，正整数 \(N\) 只依赖于 \(\varepsilon\)，与 \(x\) 的选取无关。即存在一个对所有 \(x \in D\) 都生效的“公共 \(N\)”。)

    2.2 点态收敛与一致收敛的关系

    \[ \text{一致收敛} \implies \text{逐点收敛} \]

    (注：逆命题不成立，逐点收敛推不出一致收敛，详见下文的反例。)

    2.3 不一致收敛的等价条件

    由定义取反，\(\{f_n\}\) 在 \(D\) 上不一致收敛于 \(f\) 的等价命题为：

    \[ \exists \varepsilon_0 > 0, \forall N \in \mathbb{Z}^+, \exists n \ge N \text{ 且 } \exists x \in D, \text{ s.t. } |f_n(x) - f(x)| \ge \varepsilon_0 \]

    【例题】 \(f_n(x) = x^n\) 的收敛性探讨

    情形一：在区间 \([0, 1)\) 上不一致收敛

    • 分析： 极限函数为 \(f(x) = 0\)。

    • 证明： 取 \(\varepsilon_0 = \frac{1}{2}\)。对 \(\forall N \in \mathbb{Z}^+\)，取 \(n = N + 1 \ge N\)。

      令 \(x = \sqrt[n]{\frac{1}{2}} \in [0, 1)\)。

      此时 \(|f_n(x) - f(x)| = \left| \left( \sqrt[n]{\frac{1}{2}} \right)^n - 0 \right| = \frac{1}{2} \ge \varepsilon_0\)。

      故 \(f_n(x) = x^n\) 在 \([0, 1)\) 上不一致收敛于 \(0\)。

    情形二：在闭子区间 \([0, 1-\delta]\) 上一致收敛 (\(0 < \delta < 1\))

    • 分析： 要使 \(|x^n - 0| < \varepsilon\)，只需 \((1-\delta)^n < \varepsilon \iff n \ln(1-\delta) < \ln \varepsilon \iff n > \frac{\ln \varepsilon}{\ln(1-\delta)}\) （注意 \(\ln(1-\delta) < 0\)）。

    • 证明： \(\forall \varepsilon \in (0, 1)\)，令 \(N = \left[ \frac{\ln \varepsilon}{\ln(1-\delta)} \right] + 1\)。

      当 \(n \ge N\) 时，对 \(\forall x \in [0, 1-\delta]\)，有：

      \[ |x^n - 0| \le (1-\delta)^n \le (1-\delta)^N < \varepsilon \]

      故 \(f_n(x) = x^n\) 在 \([0, 1-\delta]\) 上一致收敛于 \(0\)。

    2.4 内闭一致收敛

    • 定义： 设函数列 \(\{f_n\}\) 与 \(f\) 都在区间 \(I\) 上有定义。若对于任意闭区间 \([a, b] \subset I\)，\(\{f_n\}\) 在 \([a, b]\) 上都一致收敛于 \(f\)，则称 \(\{f_n\}\) 在 \(I\) 上内闭一致收敛于 \(f\)。

    • 结论： \(f_n(x) = x^n \ (n \ge 1)\) 在 \((0, 1)\) 上内闭一致收敛于 \(f(x) = 0\)。

    2.5 函数列一致收敛的判别准则

    方法一：柯西准则

    函数列在 \(D\) 上一致收敛的充要条件是：

    \[ f_n \stackrel{D}{\rightrightarrows} f \iff \forall \varepsilon > 0, \exists N \in \mathbb{Z}^+, \text{ s.t. 当 } m, n \ge N \text{ 时, 对 } \forall x \in D, \text{ 都有 } |f_n(x) - f_m(x)| < \varepsilon \]

    (注：柯西准则的优势在于不需要提前知道极限函数 \(f(x)\) 是什么，只需判断序列内部的稳定性。)

    方法二：上确界判别法 (\(M_n\) 判别法)

    设 \(\{f_n\}\) 与 \(f\) 都在 \(D\) 上有定义。\(\forall n \ge 1\)，令该误差的上确界为 \(M_n\)：

    \[ M_n = \sup_{x \in D} |f_n(x) - f(x)| \]

    定理： \(f_n \stackrel{D}{\rightrightarrows} f\) 当且仅当 \(\lim_{n \to \infty} M_n = 0\)。

    【例题】 利用 \(M_n\) 判别法证明一致收敛

    题目： 设 \(f_0(x)\) 在 \([0, a]\) 上连续。令 \(f_n(x) = \int_0^x f_{n-1}(t) dt \ (n=1, 2, \dots)\)。

    证明： \(\{f_n(x)\}\) 在 \([0, a]\) 上一致收敛于 \(0\)。

    证明过程：

    1. 有界性估计： 因为 \(f_0(x)\) 在闭区间 \([0, a]\) 上连续，由有界性定理，存在常数 \(K > 0\)，使得对于 \(\forall x \in [0, a]\)，都有 \(|f_0(x)| \le K\)。

    2. 递推寻找通项上界：

      • \(|f_1(x)| = \left| \int_0^x f_0(t) dt \right| \le \int_0^x |f_0(t)| dt \le Kx\)

      • \(|f_2(x)| = \left| \int_0^x f_1(t) dt \right| \le \int_0^x |f_1(t)| dt \le \int_0^x Kt dt = K \frac{x^2}{2}\)

      • 使用数学归纳法不难得出：对 \(\forall n \ge 1\)，都有 \(|f_n(x)| \le K \frac{x^n}{n!}\)

    3. 计算 \(M_n\) 并取极限：

      我们要研究 $\{f_n(x)\}$ 是否一致收敛于 $0$，故计算上确界：

$$

      M_n = \sup_{x \in [0, a]} |f_n(x) - 0| = \sup_{x \in [0, a]} |f_n(x)| $$

      由步骤 2 可知，在 $[0, a]$ 上：

$$

      |f_n(x)| \le K \frac{x^n}{n!} \le K \frac{a^n}{n!} $$

      因此，上确界 $M_n \le K \frac{a^n}{n!}$。

    4. 得出结论：

      由于 \(\lim_{n \to \infty} \frac{a^n}{n!} = 0\) （指数增长与阶乘增长的基础极限结论），所以由夹逼定理可知：

      \[ \lim_{n \to \infty} M_n = 0 \]

      根据上确界判别法，\(\{f_n(x)\}\) 在 \([0, a]\) 上一致收敛于 \(0\)。证明完毕。

    3. 函数项级数及其点态收敛

    3.1 函数项级数与部分和的定义

    • 定义（函数项级数）： 设 \(E \subset \mathbb{R}\)，\(\{u_n(x)\}\) 是定义在 \(E\) 上的一个函数列。我们称表达式（或形式和）：

      \[ u_1(x) + u_2(x) + \dots + u_n(x) + \dots, \quad x \in E \]

      为定义在 \(E\) 上的函数项级数，记作 \(\sum_{n=1}^{\infty} u_n(x)\) 或简记为 \(\sum u_n(x)\)。

    • 定义（部分和函数列）： 令 \(S_n(x) = \sum_{k=1}^n u_k(x) \ (x \in E, n=1, 2, \dots)\)。

      称函数列 \(\{S_n(x)\}\) 为函数项级数 \(\sum u_n(x)\) 的部分和函数列。

    3.2 收敛域与和函数

    • 点态收敛： 设 \(x_0 \in E\)，若数列 \(\{S_n(x_0)\}\) 在点 \(x_0\) 处收敛（或发散），则称函数项级数 \(\sum u_n(x)\) 在点 \(x_0\) 处收敛（或发散）。

    • 收敛域： 函数项级数所有收敛点的集合，定义为 \(\sum u_n(x)\) 的收敛域 \(D\) (\(D \subset E\))。

    • 和函数： 若 \(\sum u_n(x)\) 在 \(D\) 上收敛，其部分和函数列的极限函数记为 \(S(x)\)，即 \(\lim_{n \to \infty} S_n(x) = S(x)\)。则称 \(S(x)\) 为该级数在 \(D\) 上的和函数，记作：

      \[ \sum_{n=1}^{\infty} u_n(x) = S(x), \quad x \in D \]

    4. 函数项级数的一致收敛

    4.1 级数一致收敛的定义

    设 \(\sum u_n(x)\) 是定义在 \(D\) 上的函数项级数，其部分和函数列为 \(\{S_n(x)\}\)。

    若部分和函数列 \(\{S_n(x)\}\) 在 \(D\) 上一致收敛于和函数 \(S(x)\)，则称函数项级数 \(\sum u_n(x)\) 在 \(D\) 上一致收敛。

    逻辑等价链条：

    \(\sum u_n(x)\) 在 \(D\) 上一致收敛

    \(\iff\) 其部分和函数列 \(\{S_n(x)\}\) 在 \(D\) 上一致收敛于 \(S(x)\)

    \(\iff \forall \varepsilon > 0, \exists N \in \mathbb{Z}^+\), 当 \(n \ge N\) 时, 对 \(\forall x \in D\), 都有 \(|S_n(x) - S(x)| < \varepsilon\)。

    4.2 函数项级数一致收敛的柯西准则

    将函数列的柯西准则应用到部分和函数列 \(S_n(x)\) 上：

    \(|S_m(x) - S_n(x)| = \left| \sum_{k=n+1}^m u_k(x) \right|\) （假设 \(m > n\)）。

    为了书写方便，通常令 \(m = n + p\) (\(p \in \mathbb{Z}^+\))，柯西准则可表述为：

    定理： \(\sum u_n(x)\) 在 \(D\) 上一致收敛 当且仅当

    \[ \forall \varepsilon > 0, \exists N \in \mathbb{Z}^+, \text{ 当 } n \ge N \text{ 时, 对 } \forall p \in \mathbb{Z}^+ \text{ 以及 } \forall x \in D, \text{ 都有 } \left| \sum_{k=n+1}^{n+p} u_k(x) \right| < \varepsilon \]

    4.3 一致收敛的必要条件

    利用柯西准则（取 \(p=1\)），可以直接推导出一个重要的必要条件：

    命题： 若 \(\sum u_n(x)\) 在 \(D\) 上一致收敛，则一般项 \(u_n(x)\) 在 \(D\) 上一致收敛于 \(0\)。

    即：\(u_n(x) \rightrightarrows 0 \ (n \to \infty, x \in D)\)。

    (注：这与常数项级数收敛则通项趋于0的逻辑完全一致，只是升级到了“一致”的层面。)

    4.4 余项与上确界判别法

    级数的余项

    定义 \(\sum u_n(x)\) 的第 \(n\) 个余项为：

    \[ R_n(x) = S(x) - S_n(x) = \sum_{k=n+1}^{\infty} u_k(x) \]

    \(M_n\) 判别法的级数版本

    注意到：\(\sum u_n(x)\) 在 \(D\) 上一致收敛

    \(\iff S_n(x) \stackrel{D}{\rightrightarrows} S(x)\)

    \(\iff \lim_{n \to \infty} \sup_{x \in D} |S_n(x) - S(x)| = 0\)

    \(\iff \lim_{n \to \infty} \sup_{x \in D} |R_n(x)| = 0\)

    【例题】 几何级数 \(\sum x^n\) 的一致收敛性分析

    题目： 求幂级数 \(\sum_{n=0}^{\infty} x^n\) 的收敛域，并判断它在收敛域内是否一致收敛。

    解答与严密分析：

    第一步：求收敛域与和函数

    该级数的部分和（前 \(n\) 项和，从 \(k=0\) 到 \(n-1\)）为：

    \[ S_n(x) = \sum_{k=0}^{n-1} x^k = \begin{cases} \frac{1-x^n}{1-x}, & x \neq 1 \\ n, & x = 1 \end{cases} \]

    • 当 \(|x| < 1\) 时，\(\lim_{n \to \infty} x^n = 0\)，此时 \(S_n(x) \to \frac{1}{1-x} \ (n \to \infty)\)。

    • 当 \(|x| \ge 1\) 时，\(|x^n| \ge 1\)，通项不趋于 0 (\(x^n \not\to 0\))，由级数收敛的必要条件知，级数发散。

    • 结论： 级数的收敛域为 \((-1, 1)\)，且在 \((-1, 1)\) 上的和函数为 \(S(x) = \frac{1}{1-x}\)。

    第二步：判断在 \((-1, 1)\) 上是否一致收敛（利用上确界）

    我们要计算误差函数 \(|S_n(x) - S(x)|\) 的上确界：

    \[ |S_n(x) - S(x)| = \left| \frac{1-x^n}{1-x} - \frac{1}{1-x} \right| = \left| \frac{-x^n}{1-x} \right| = \frac{|x|^n}{1-x}, \quad \text{其中 } x \in (-1,1),\; 1-x>0 \]

    此时需要求 \(\sup_{x \in (-1, 1)} \frac{|x|^n}{1-x}\)。

    为了证明其不一致收敛，我们不需要求出精确的上确界，只需要在 \((-1, 1)\) 内找到一个特定的点列 \(x_n\)，使得当 \(n \to \infty\) 时，误差趋于正无穷（或某个不为 0 的常数）即可。

    • 构造放缩： 取 \(x_n = 1 - \frac{1}{n}\)。显然当 \(n \ge 2\) 时，\(x_n \in (0, 1) \subset (-1, 1)\)。

    • 代入该点，计算此时的误差值：

      \[ \left| S_n\left(1 - \frac{1}{n}\right) - S\left(1 - \frac{1}{n}\right) \right| = \frac{\left(1 - \frac{1}{n}\right)^n}{1 - \left(1 - \frac{1}{n}\right)} = \frac{\left(1 - \frac{1}{n}\right)^n}{\frac{1}{n}} = n \cdot \left(1 - \frac{1}{n}\right)^n \]

    • 求极限分析： 我们知道重要极限 \(\lim_{n \to \infty} \left(1 - \frac{1}{n}\right)^n = \frac{1}{e}\)。

      因此，当 \(n \to \infty\) 时：

      \[ n \cdot \left(1 - \frac{1}{n}\right)^n \sim n \cdot \frac{1}{e} \to +\infty \]

    • 这说明上确界 \(\sup_{x \in (-1, 1)} |S_n(x) - S(x)| \ge +\infty\) (实际就是无穷大)，显然不等于 \(0\)。

    • 最终结论： \(\lim_{n \to \infty} \sup_{x \in (-1, 1)} |S_n(x) - S(x)| \neq 0\)。因此，级数 \(\sum_{n=0}^{\infty} x^n\) 在其收敛域 \((-1, 1)\) 内不一致收敛。

    5. 函数项级数一致收敛的判别法

    5.1 魏尔斯特拉斯判别法 (Weierstrass M-判别法)

    这是判断一致收敛最常用、最基础的方法（也称为优级数判别法）。

    定理

    设 \(\sum u_n(x)\) 是定义在 \(D\) 上的函数项级数。若存在一个收敛的正项常数级数 \(\sum M_n\)（称为 \(\sum u_n(x)\) 的优级数），使得对于 \(\forall n \ge 1\) 以及 \(\forall x \in D\)，都有：

    \[ |u_n(x)| \le M_n \]

    则函数项级数 \(\sum u_n(x)\) 在 \(D\) 上绝对且一致收敛。

    证明（基于柯西准则）

    要证 \(\sum u_n(x)\) 一致收敛，只需证满足一致收敛的柯西准则。

    • 因为正项常数级数 \(\sum M_n\) 收敛，由常数级数的柯西准则：

      \(\forall \varepsilon > 0, \exists N \in \mathbb{Z}^+\), 当 \(n \ge N\) 时, 对 \(\forall p \in \mathbb{Z}^+\), 有 \(\sum_{k=n+1}^{n+p} M_k < \varepsilon\)。

    • 对于原函数项级数，利用绝对值不等式放缩：

      对 \(\forall x \in D\), 有 \(\left| \sum_{k=n+1}^{n+p} u_k(x) \right| \le \sum_{k=n+1}^{n+p} |u_k(x)| \le \sum_{k=n+1}^{n+p} M_k < \varepsilon\)。

    • 结论成立。

    【例题】 证明 \(\sum_{n=1}^{\infty} \frac{\sin nx}{n^2}\) 在 \(\mathbb{R}\) 上一致收敛。

    分析： 对 \(\forall n \ge 1\) 及 \(\forall x \in \mathbb{R}\)，有 \(\left| \frac{\sin nx}{n^2} \right| \le \frac{1}{n^2}\)。

    因为常数项级数 \(\sum \frac{1}{n^2}\) 收敛（\(p=2 > 1\) 的 \(p\)-级数），由 W-判别法知原级数在 \(\mathbb{R}\) 上一致收敛。

    推论： 若数列的级数 \(\sum a_n\) 绝对收敛，则三角级数 \(\sum a_n \sin nx\) 和 \(\sum a_n \cos nx\) 都在 \(\mathbb{R}\) 上一致收敛。

    5.2 狄利克雷与阿贝尔判别法

    当无法找到收敛的优级数时（例如交错级数或包含正余弦的级数），需要用到这两个判别法。它们专门处理形如 \(\sum u_n(x)v_n(x)\) 的乘积形式的级数。

    狄利克雷判别法

    若满足以下三个条件，则 \(\sum u_n(x)v_n(x)\) 在 \(D\) 上一致收敛：

    1. 部分和一致有界： \(\sum u_n(x)\) 的部分和 \(S_n(x) = \sum_{k=1}^n u_k(x)\) 在 \(D\) 上一致有界。即 \(\exists M > 0, \text{ s.t. } \forall n \ge 1 \text{ 及 } \forall x \in D, \text{ 有 } |S_n(x)| \le M\)。

    2. 单调性： \(\forall x \in D\)，数列 \(\{v_n(x)\}\) 关于 \(n\) 单调。

    3. 一致收敛于 0： \(v_n(x) \rightrightarrows 0 \ (n \to \infty, x \in D)\)。

    证明思路： 核心是利用 Abel 变换（分部求和法）。由条件 1 知 \(|\sum_{k=n+1}^{n+p} u_k(x)| = |S_{n+p}(x) - S_n(x)| \le 2M\)。再结合条件 2 和 3，通过 Abel 引理可以将和式的绝对值放缩为常数乘以 \(v_n(x)\) 的界，进而由 \(v_n(x) \rightrightarrows 0\) 证明柯西准则成立。

    阿贝尔判别法

    若满足以下三个条件，则 \(\sum u_n(x)v_n(x)\) 在 \(D\) 上一致收敛：

    1. 一致收敛： \(\sum u_n(x)\) 在 \(D\) 上一致收敛。

    2. 单调性： \(\forall x \in D\)，数列 \(\{v_n(x)\}\) 关于 \(n\) 单调。

    3. 一致有界： 数列 \(\{v_n(x)\}\) 在 \(D\) 上一致有界（\(\exists M > 0, \text{ s.t. } \forall n, \forall x, |v_n(x)| \le M\)）。

    【例题】 若常数级数 \(\sum a_n\) 收敛，则幂级数 \(\sum a_n x^n\) 在 \([0, 1]\) 上一致收敛。

    • (证明略，直接令 \(u_n(x) = a_n\), \(v_n(x) = x^n\)，应用 A-判别法即可)。

    【例题】 Dirichlet 判别法的应用

    题目： 若常数数列 \(\{a_n\}\) 单调且趋于 \(0\)，证明级数 \(\sum a_n \cos nx\) 在 \([\delta, 2\pi - \delta]\) 上一致收敛（其中 \(0 < \delta < \pi\)）。

    解析：

    令 \(u_n(x) = \cos nx\), \(v_n(x) = a_n\)。

    1. 验证 \(\{v_n(x)\}\)：因为 \(a_n \searrow 0\)，它与 \(x\) 无关，故 \(v_n(x)\) 单调且在区间上一致收敛于 0。

    2. 验证 \(u_n(x)\) 的部分和一致有界：

      利用三角恒等式求和：

      \[ |S_n(x)| = \left| \sum_{k=1}^n \cos kx \right| = \left| \frac{\sin(n+\frac{1}{2})x - \sin\frac{x}{2}}{2\sin\frac{x}{2}} \right| \]

      利用绝对值不等式放缩分子：\(|\sin(n+\frac{1}{2})x - \sin\frac{x}{2}| \le |\sin(n+\frac{1}{2})x| + |\sin\frac{x}{2}| \le 1 + 1 = 2\)。

      因此：\(|S_n(x)| \le \frac{2}{2\left|\sin\frac{x}{2}\right|} = \frac{1}{\left|\sin\frac{x}{2}\right|}\)。

      因为 \(x \in [\delta, 2\pi - \delta]\)，故 \(\frac{x}{2} \in [\frac{\delta}{2}, \pi - \frac{\delta}{2}]\)。在这个闭区间上，正弦函数取到最小值为 \(\sin\frac{\delta}{2} > 0\)。

      从而 \(|S_n(x)| \le \frac{1}{\sin\frac{\delta}{2}}\)。

      这是一个与 \(n\) 和 \(x\) 都无关的常数 \(M\)，即部分和一致有界。

      满足 Dirichlet 判别法条件，原级数一致收敛。

    【例题】 证明级数不一致收敛 (Cauchy 准则的否定)

    题目： 证明 \(\sum_{n=1}^{\infty} \frac{\cos nx}{n}\) 在 \((0, 2\pi)\) 上不一致收敛。

    证明（构造法）：

    根据一致收敛的柯西准则的否定，我们需要证明：

    \[ \exists \varepsilon_0 > 0, \forall N \in \mathbb{Z}^+, \exists m > n \ge N, \exists x \in (0, 2\pi), \text{ s.t. } \left| \sum_{k=n+1}^m \frac{\cos kx}{k} \right| \ge \varepsilon_0 \]

    1. 取定变量： \(\forall N \in \mathbb{Z}^+\)，令 \(n = N\)，\(m = 2N\)。

    2. 巧妙构造 \(x\)： 观察通项 \(\cos kx\)，我们需要在一个范围内让所有的 \(\cos kx\) 都大于某个正数。取 \(x = \frac{\pi}{6N}\)。显然当 \(N \ge 1\) 时，\(x \in (0, 2\pi)\)。

    3. 分析相角范围： 对于求和的角标 \(k\)，其范围是 \(N+1 \le k \le 2N\)。

      此时，$kx$ 的范围是：

$$

      (N+1) \cdot \frac{\pi}{6N} \le kx \le 2N \cdot \frac{\pi}{6N} $$

      即 $kx \in \left[ \frac{\pi}{6} + \frac{\pi}{6N}, \frac{\pi}{3} \right] \subset \left(0, \frac{\pi}{2}\right)$。

    4. 放缩项值： 在第一象限内，余弦函数是单调递减的。因此在这个区间内：

      $$

      \cos kx \ge \cos\left(\frac{\pi}{3}\right) = \frac{1}{2} $$

    5. 计算部分和的下界：

      $$

      \left| \sum_{k=N+1}^{2N} \frac{\cos kx}{k} \right| = \sum_{k=N+1}^{2N} \frac{\cos kx}{k} \ge \sum_{k=N+1}^{2N} \frac{1/2}{k} $$

      将分母统一放大为最大的角标 $2N$（使得整个分式变小）：

$$

      \sum_{k=N+1}^{2N} \frac{1/2}{k} \ge \sum_{k=N+1}^{2N} \frac{1/2}{2N} = N \cdot \left( \frac{1/2}{2N} \right) = \frac{1}{4} $$

    6. 得出结论： 取 \(\varepsilon_0 = \frac{1}{4} > 0\)。对于任意的 \(N\)，总能找到特定的项数范围和特定的点 \(x\)，使得误差 \(\ge \frac{1}{4}\)。因此该级数在 \((0, 2\pi)\) 上不一致收敛。

    二、 一致收敛函数列与函数项级数的性质

    一致收敛性可以保证极限运算的交换律（例如极限与极限交换、极限与积分交换、极限与求导交换）。

    首先讨论函数列的连续性、可积性和可微性。

    1. 极限与连续性

    1.1 极限换序定理

    设函数列 \(\{f_n\}\) 在 \((a, x_0) \cup (x_0, b)\) 上一致收敛于 \(f\)。且对 \(\forall n \ge 1\)，存在极限 \(\lim_{x \to x_0} f_n(x) = A_n\)。

    则数列 \(\{A_n\}\) 收敛，且极限函数 \(f(x)\) 在 \(x_0\) 处的极限也存在，且两者相等。即：

    \[ \lim_{x \to x_0} \lim_{n \to \infty} f_n(x) = \lim_{n \to \infty} \lim_{x \to x_0} f_n(x) \]

    (注：证明思路分两步。第一步利用柯西准则证明 \(\{A_n\}\) 收敛到 \(A\)；第二步利用 \(\frac{\varepsilon}{3}\) 放缩技巧（见下）证明 \(f(x) \to A\)。)

    1.2 极限函数的连续性

    • 定理： 若函数列 \(\{f_n\}\) 在区间 \(I\) 上一致收敛于 \(f\)，且每个 \(f_n\) 在 \(I\) 上都连续，则极限函数 \(f\) 在 \(I\) 上也连续。

    • 核心证明逻辑（\(\frac{\varepsilon}{3}\) 技巧）：

      要证 \(f\) 在任一点 \(x_0 \in I\) 连续。利用三角不等式强行插入中间项：

      \[ |f(x) - f(x_0)| \le |f(x) - f_N(x)| + |f_N(x) - f_N(x_0)| + |f_N(x_0) - f(x_0)| \]

      • 第 1 项和第 3 项：由 \(f_n \rightrightarrows f\)，可找到足够大的公共 \(N\)，使得这两项都 \(< \frac{\varepsilon}{3}\)。

      • 第 2 项：固定上述 \(N\) 后，由于 \(f_N(x)\) 是连续函数，当 \(x\) 充分接近 \(x_0\) 时，该项 \(< \frac{\varepsilon}{3}\)。

        三项相加即得 \(|f(x) - f(x_0)| < \varepsilon\)。

    1.3 重要推论与应用

    • 逆否命题（用于证伪一致收敛）： 若 \(\{f_n\}\) 都在 \(I\) 上连续，且 \(f_n \to f\)（逐点收敛），但极限函数 \(f\) 在 \(I\) 上不连续，则 \(\{f_n\}\) 在 \(I\) 上必定不一致收敛。

    • 内闭一致收敛的扩展： 若 \(\{f_n\}\) 在区间 \(I\) 上内闭一致收敛，且 \(f_n\) 连续，则 \(f\) 在 \(I\) 上连续。

      • 例： \(f_n(x) = x^n\) 在 \((-1, 1)\) 上内闭一致收敛，因此其极限函数 \(f(x) = 0\) 在 \((-1, 1)\) 上连续。

    2. 可积性

    2.1 积分与极限交换定理

    设 \(\{f_n\}\) 在 \([a, b]\) 上一致收敛于 \(f\)，且每个 \(f_n\) 在 \([a, b]\) 上可积（黎曼可积）。

    则极限函数 \(f\) 在 \([a, b]\) 上也可积，且满足：

    \[ \int_a^b f(x) dx = \lim_{n \to \infty} \int_a^b f_n(x) dx \]

    (即：一致收敛条件下，极限号可以跨过积分号)

    证明 \(f\) 是可积的：

    利用达布和（振幅 \(\omega\)）的黎曼可积充要条件。

    对任意区间划分，极限函数 \(f\) 的振幅 \(\omega_i^f\) 与 \(f_N\) 的振幅 \(\omega_i^{f_N}\) 之间满足关系：\(\omega_i^f \le \omega_i^{f_N} + \frac{2\varepsilon}{b-a}\)。

    从而 \(\sum \omega_i^f \Delta x_i \le \sum \omega_i^{f_N} \Delta x_i + \frac{2\varepsilon}{b-a} \sum \Delta x_i \le \varepsilon' + 2\varepsilon\)。由此证明 \(f\) 可积。

    2.2 一致收敛是充分条件，但非必要条件

    【反例】 设 \(f_n(x)\) 在 \([0, 1]\) 上定义，图像是一个底边长为 \(\frac{1}{n}\)，高为 \(\alpha_n\) 的等腰三角形，其余部分为 0。

    • 逐点极限： \(\lim_{n \to \infty} f_n(x) = 0\)，即极限函数 \(f(x) \equiv 0\)。因此 \(\int_0^1 f(x) dx = 0\)。

    • 积分的极限： 三角形面积为 \(\int_0^1 f_n(x) dx = \frac{1}{2} \cdot \frac{1}{n} \cdot \alpha_n = \frac{\alpha_n}{2n}\)。

    • 结论对比：

      • 积分与极限可交换 \(\iff \lim_{n \to \infty} \frac{\alpha_n}{n} = 0\)。

      • \(\{f_n\}\) 一致收敛于 \(0 \iff \lim_{n \to \infty} \alpha_n = 0\)（由上确界 \(M_n = \alpha_n\) 易知）。

        如果令 \(\alpha_n = \sqrt{n}\)，此时不满足一致收敛条件（\(\sqrt{n} \to \infty\)），但满足可交换条件（\(\frac{\sqrt{n}}{n} \to 0\)）。这说明即使不一致收敛，积分和极限也可能可以交换。

    3. 可微性

    可微性是要求最苛刻的。仅仅 \(f_n \rightrightarrows f\) 无法保证 \(f\) 可导（即使每个 \(f_n\) 都可导）。需要导函数列的一致收敛。

    3.1 定理（依赖导数连续）

    若 \(\{f_n\}\) 定义在 \([a, b]\) 上，满足：

    1. \(\forall n \ge 1\)，\(f_n\) 在 \([a, b]\) 上有连续的导函数 \(f_n'\)；

    2. \(\{f_n\}\) 逐点收敛于 \(f\)；

    3. 导函数列 \(\{f_n'\}\) 在 \([a, b]\) 上一致收敛于 \(g\)。

      结论： \(f\) 在 \([a, b]\) 上可导，且 \(f'(x) = g(x)\)。

      (证明极简：因为 \(f_n'\) 连续且一致收敛，由前述定理知 \(g\) 连续。利用牛顿-莱布尼茨公式 \(f_n(x) - f_n(a) = \int_a^x f_n'(t) dt\)，两边取极限即可把问题转化为积分定理。)

    3.2 推论（只需可导，无需导数连续）

    若 \(\{f_n\}\) 定义在 \([a, b]\) 上，满足：

    1. \(\forall n \ge 1\)，\(f_n\) 在 \([a, b]\) 上可导（不要求导函数连续）；

    2. 存在一点 \(x_0 \in [a, b]\)，使得数列 \(\{f_n(x_0)\}\) 收敛；

    3. 导函数列 \(\{f_n'\}\) 在 \([a, b]\) 上一致收敛于 \(g\)。

      结论： \(\{f_n\}\) 在 \([a, b]\) 上必定一致收敛于某函数 \(f\)，且 \(f'(x) = g(x)\)。

    推论的证明（两次应用拉格朗日中值定理）：

    • 第一步：证 \(\{f_n\}\) 一致收敛。

      利用柯西准则考察 \(|f_n(x) - f_m(x)|\)。强行减去再加回在 \(x_0\) 处的值，构造出一个辅助函数 \(h(x) = f_n(x) - f_m(x)\)。

      \[ |f_n(x) - f_m(x)| \le |(f_n(x) - f_m(x)) - (f_n(x_0) - f_m(x_0))| + |f_n(x_0) - f_m(x_0)| \]

      对前面的式子应用拉格朗日中值定理：等于 \(|f_n'(\xi) - f_m'(\xi)| \cdot |x - x_0|\)。因为导函数一致收敛，所以这部分可以压得很小；加上后面 \(x_0\) 处的收敛性，从而证明原函数列一致收敛。

    • 第二步：证 \(f'(x) = g(x)\)（极限换序）。

      定义差商函数 \(\varphi_n(t) = \frac{f_n(t) - f_n(x)}{t - x}\)。要证明极限可以交换：\(\lim_{t \to x} \lim_{n \to \infty} = \lim_{n \to \infty} \lim_{t \to x}\)。

      根据第十一节的极限换序定理，需要证明 \(\varphi_n(t)\) 关于 \(t\) 一致收敛。

      再次对差商的分子应用拉格朗日中值定理：

      \[ |\varphi_n(t) - \varphi_m(t)| = \left| \frac{(f_n(t) - f_m(t)) - (f_n(x) - f_m(x))}{t - x} \right| = |f_n'(\eta) - f_m'(\eta)| \]

      因为 \(f_n'\) 一致收敛，所以 \(|f_n'(\eta) - f_m'(\eta)| < \varepsilon\)。证明了差商函数的一致收敛性，从而可以合法地交换极限。

    接下来讨论函数项级数的连续性、逐项求积与逐项求导的性质，这些性质可由函数列的相应性质推出。（函数项级数的本质就是其部分和函数列）

    4. 级数和函数的连续性

    4.1 闭区间内

    若函数项级数 \(\sum_{n=1}^\infty u_n(x)\) 在区间 \([a, b]\) 上一致收敛，且各项 \(u_n(x)\) 都在 \([a, b]\) 上连续，则其和函数 \(S(x) = \sum_{n=1}^\infty u_n(x)\) 在 \([a, b]\) 上连续。

    此时，求极限与无穷求和可交换顺序：

    \[ \sum_{n=1}^\infty \left( \lim_{x \to x_0} u_n(x) \right) = \lim_{x \to x_0} \left( \sum_{n=1}^\infty u_n(x) \right) \]

    4.2 任意区间推广（内闭一致收敛）

    若 \(\sum_{n=1}^\infty u_n(x)\) 在任意区间 \(I\) 上内闭一致收敛（即对 \(I\) 内的任意闭子区间均一致收敛），且各项 \(u_n(x)\) 在 \(I\) 上连续，则和函数 \(S(x)\) 在区间 \(I\) 上连续。

    5. 级数的逐项求积

    5.1 闭区间内

    若 \(\sum_{n=1}^\infty u_n(x)\) 在区间 \([a, b]\) 上一致收敛，且各项 \(u_n(x)\) 连续，则级数可在 \([a, b]\) 上逐项求积：

    \[ \sum_{n=1}^\infty \int_a^b u_n(x) dx = \int_a^b \left( \sum_{n=1}^\infty u_n(x) \right) dx \]

    5.2 任意区间推广（内闭一致收敛）

    若 \(\sum_{n=1}^\infty u_n(x)\) 在任意区间 \(I\) 上内闭一致收敛，且各项连续，则对于区间 \(I\) 内的任意闭子区间 \([\alpha, \beta]\)，级数可逐项求积：

    \[ \int_\alpha^\beta \sum_{n=1}^\infty u_n(x) dx = \sum_{n=1}^\infty \int_\alpha^\beta u_n(x) dx \]

    注：此推广仅限于闭子区间上的定积分。对于无穷区间或开区间上的反常积分，内闭一致收敛不足以作为极限与积分号交换的充分条件。

    6. 级数的逐项求导

    6.1 闭区间内

    若满足以下三个条件：

    • 各项 \(u_n(x)\) 在 \([a, b]\) 上均有连续的导函数 \(u_n'(x)\)；

    • 存在一点 \(x_0 \in [a, b]\)，使得级数 \(\sum_{n=1}^\infty u_n(x_0)\) 收敛；

    • 导函数级数 \(\sum_{n=1}^\infty u_n'(x)\) 在 \([a, b]\) 上一致收敛。

    则原级数 \(\sum_{n=1}^\infty u_n(x)\) 在 \([a, b]\) 上必定一致收敛，且其和函数可导，可逐项求导：

    \[ \sum_{n=1}^\infty \left( \frac{d}{dx} u_n(x) \right) = \frac{d}{dx} \left( \sum_{n=1}^\infty u_n(x) \right) \]

    6.2 任意区间推广（内闭一致收敛）

    若各项 \(u_n(x)\) 在区间 \(I\) 上导数连续，原级数在某点 \(x_0 \in I\) 处收敛，且导函数级数 \(\sum_{n=1}^\infty u_n'(x)\) 在区间 \(I\) 上内闭一致收敛。

    则原级数在 \(I\) 上内闭一致收敛，且在 \(I\) 上的任意一点均可逐项求导。

    定理的理论意义

    一致收敛分析性质定理的核心理论价值在于：在无法求出函数项级数和函数 \(S(x)\) 的解析表达式的情况下，只需验证该级数满足一致收敛或内闭一致收敛的条件，即可由各项函数序列的性质，直接推断出未知的和函数 \(S(x)\) 必然具备连续、可积或可微等解析性质。
