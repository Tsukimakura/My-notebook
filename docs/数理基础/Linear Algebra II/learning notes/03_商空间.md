# 一、 商空间的基本定义与代数结构

## 1. 核心概念：陪集 (Coset) 与商空间

设 $V$ 是在数域 $\mathbb{F}$ 上的一个线性空间，$U$ 是 $V$ 的一个子空间（记作 $U \le V$）。

- **陪集定义**：对于任意向量 $v \in V$，集合 $v + U = \{v + u \mid u \in U\}$ 称为 $U$ 在 $V$ 中的一个**陪集**。

- **商空间定义**：所有这些陪集构成的集合称为 $V$ 模 $U$ 的**商空间**，记作 $V/U$。

    $$
V/U = \{v + U \mid v \in V\}
    $$

## 2. 陪集的等价条件

两个陪集相等的充要条件是它们的代表元之差属于子空间 $U$：

$$
v_1 + U = v_2 + U \iff v_1 - v_2 \in U
$$

_(注：这说明陪集的代表元的选取不是唯一的，只要两个向量的“差”在 $U$ 内，它们就代表同一个陪集。)_

## 3. 商空间上的线性运算

为了使集合 $V/U$ 本身也构成一个线性空间，我们需要在陪集之间定义加法和数乘运算：

- **加法**：$(a + U) + (b + U) = (a + b) + U$

- **数乘**：$\lambda(a + U) = \lambda a + U \quad (\forall \lambda \in \mathbb{F})$

    _(注：商空间的零元素就是 $0 + U = U$ 本身。)_

---

## 二、 自然映射及其性质

为了建立原空间 $V$ 与商空间 $V/U$ 之间的联系，我们引入自然映射。

## 1. 映射定义

定义映射 $\pi : V \to V/U$，其规则为：

$$
\pi(v) = v + U
$$

即，将 $V$ 中的任意向量投影到它所在的陪集上。

## 2. $\pi$ 的线性性质证明

**定理**：自然映射 $\pi$ 是一个线性映射。

**证明**：对于任意标量 $\lambda_1, \lambda_2 \in \mathbb{F}$ 和任意向量 $v_1, v_2 \in V$，有：

$$
\pi(\lambda_1 v_1 + \lambda_2 v_2) = (\lambda_1 v_1 + \lambda_2 v_2) + U
$$

根据商空间的加法和数乘定义，可将其展开为：

$$
= (\lambda_1 v_1 + U) + (\lambda_2 v_2 + U)
$$

$$
= \lambda_1(v_1 + U) + \lambda_2(v_2 + U)
$$

$$
= \lambda_1\pi(v_1) + \lambda_2\pi(v_2)
$$

故 $\pi$ 保持了加法和数乘，是线性映射。

## 3. $\pi$ 的核

**定理**：$\ker \pi = U$。

**推导过程**：映射 $\pi$ 的核是指所有映射到商空间零元素（即 $U$）的原空间向量的集合。

$$
\ker \pi = \{v \in V \mid \pi(v) = U\}
$$

$$
\ker \pi = \{v \in V \mid v + U = 0 + U\}
$$

根据陪集的等价条件，$v + U = 0 + U \iff v - 0 \in U \iff v \in U$。

因此，$\ker \pi = U$。

---

## 三、 商空间的维数公式

## 1. 维数公式推导 (基于秩-零化度定理)

已知自然映射 $\pi : V \to V/U$ 是满射，因此它的像空间（值域）即为整个商空间：$\text{range } \pi = V/U$。

根据线性映射的**秩-零化度定理：**

$$
\dim V = \dim(\ker \pi) + \dim(\text{range } \pi)
$$

代入已知条件 $\ker \pi = U$ 和 $\text{range } \pi = V/U$，得到：

$$
\dim V = \dim U + \dim V/U
$$

移项即可得到**商空间的维度公式**：

$$
\dim V/U = \dim V - \dim U
$$

### 2. 维度公式的构造性证明 (寻找商空间的基)

除了定理推导，通过直接构造基也能证明上述维度公式。

**第一步：基的扩充**

设 $\dim U = m$，$\dim V = m+n$。

取 $U$ 的一组基 $u_1, \dots, u_m$，将其扩充为整个空间 $V$ 的一组基：$u_1, \dots, u_m, u_{m+1}, \dots, u_{m+n}$。

**目标**：证明扩充出来的向量对应的陪集 $u_{m+1}+U, \dots, u_{m+n}+U$ 是商空间 $V/U$ 的一组基。

**第二步：证明“生成性”**

对于商空间中的任意元素 $v + U$。因为 $v \in V$，它可以由 $V$ 的基线性表出：

$$
v = \sum_{i=1}^{m+n} k_i u_i
$$

代入陪集：

$$
v + U = \left( \sum_{i=1}^{m+n} k_i u_i \right) + U
$$

$$
= \left( \sum_{i=1}^{m} k_i u_i + \sum_{i=m+1}^{m+n} k_i u_i \right) + U
$$

因为 $u_1, \dots, u_m$ 是 $U$ 的基，所以前半部分的求和 $\sum_{i=1}^{m} k_i u_i \in U$，它在陪集加法中会被 $U$ “吸收”掉（相当于加上了零元素）：

$$
v + U = \sum_{i=m+1}^{m+n} k_i u_i + U = \sum_{i=m+1}^{m+n} k_i (u_i + U)
$$

这说明任意陪集都能由这 $n$ 个陪集线性表出。

**第三步：证明“线性无关”**

令这 $n$ 个陪集的线性组合为商空间的零元素 $U$：

$$
\sum_{i=m+1}^{m+n} k_i (u_i + U) = U
$$

$$
\implies \left( \sum_{i=m+1}^{m+n} k_i u_i \right) + U = U
$$

这意味着括号内的求和向量必定属于 $U$：

$$
\implies \sum_{i=m+1}^{m+n} k_i u_i \in U
$$

既然它属于 $U$，它就可以被 $U$ 的基 $u_1, \dots, u_m$ 线性表出：

$$
\sum_{i=m+1}^{m+n} k_i u_i = -\sum_{i=1}^{m} k_i u_i
$$

（此处引入负号是为了方便移项）。将等式右侧移到左侧：

$$
\sum_{i=1}^{m+n} k_i u_i = 0
$$

因为 $u_1, \dots, u_{m+n}$ 是 $V$ 的一组基，它们本身是线性无关的。这就要求上式中所有的系数必须全为 $0$：

$$
\forall i \in \{1, \dots, m+n\}, \quad k_i = 0
$$

既然所有的 $k_i = 0$，当然也有 $k_{m+1} = \dots = k_{m+n} = 0$。

这证明了 $u_{m+1}+U, \dots, u_{m+n}+U$ 是线性无关的。

**结论**：这 $n$ 个陪集既能生成商空间，又线性无关，因此它们是 $V/U$ 的一组基。商空间的维度为 $n$，恰好等于 $\dim V - \dim U$。证毕。

## 四、 线性映射与商空间：诱导映射 (第一同构定理)

## 1. 诱导映射 $\tilde{T}$ 的定义

设 $T \in \mathcal{L}(V, W)$ 是一从空间 $V$ 到空间 $W$ 的线性映射。用 $\text{null } T$ 表示 $T$ 的零空间（即核，$\ker T$）。

可以定义一个从**商空间** $V/\text{null } T$ 到 $W$ 的新映射，记为 $\tilde{T}$：

$$
\tilde{T}: V/\text{null } T \to W
$$

其作用规则定义为：

$$
\tilde{T}(v + \text{null } T) = Tv
$$

## 2. $\tilde{T}$ 的映射良定义性

因为商空间中的同一个陪集可以有无数种不同的代表元表达形式（例如 $v_1 + U = v_2 + U$），在定义映射时，必须证明：**无论选取哪个代表元，映射的结果必须唯一。**

**证明**：

假设 $v_1 + \text{null } T = v_2 + \text{null } T$ （即它们代表同一个陪集）。

根据陪集相等的等价条件：

$$
v_1 - v_2 \in \text{null } T
$$

根据零空间的定义，任何属于零空间的向量，经过 $T$ 映射后都等于零向量：

$$
T(v_1 - v_2) = 0
$$

利用 $T$ 的线性性质展开：

$$
T(v_1) - T(v_2) = 0 \implies T(v_1) = T(v_2)
$$

因此，$\tilde{T}(v_1 + \text{null } T)$ 和 $\tilde{T}(v_2 + \text{null } T)$ 的结果是完全相等的，证明了 $\tilde{T}$ 是良定义的。

## 3. $\tilde{T}$ 的线性性质证明

我们要证明 $\tilde{T}$ 保持加法和数乘。对于任意标量 $\lambda_1, \lambda_2 \in \mathbb{F}$ 和商空间中的元素：

$$
\tilde{T} \left( (\lambda_1 v_1 + \text{null } T) + (\lambda_2 v_2 + \text{null } T) \right)
$$

根据商空间的线性运算规则合并：

$$
= \tilde{T} \left( (\lambda_1 v_1 + \lambda_2 v_2) + \text{null } T \right)
$$

应用 $\tilde{T}$ 的定义法则：

$$
= T(\lambda_1 v_1 + \lambda_2 v_2)
$$

利用原映射 $T$ 的线性性质：

$$
= \lambda_1 T(v_1) + \lambda_2 T(v_2)
$$

最后，再次转换回 $\tilde{T}$ 的表达形式：

$$
= \lambda_1 \tilde{T}(v_1 + \text{null } T) + \lambda_2 \tilde{T}(v_2 + \text{null } T)
$$

这严格证明了 $\tilde{T}$ 是一个线性映射。

## 4. $\tilde{T}$ 的核与单射性

**定理**：诱导映射 $\tilde{T}$ 是一个单射（核只包含零元）。

**证明**：要找出所有映射到 $W$ 中零向量的陪集。

对 $\forall (v + \text{null } T) \in \text{null } \tilde{T}$，有：

$$
\tilde{T}(v + \text{null } T) = 0
$$

根据定义，这等效于 $T(v) = 0$。

既然 $T(v) = 0$，那么 $v$ 必定属于 $\text{null } T$。

如果代表元 $v \in \text{null } T$，那么它生成的陪集就是零元素的陪集：

$$
v + \text{null } T = 0 + \text{null } T
$$

所以，$\text{null } \tilde{T} = \{0 + \text{null } T\}$。核中只有零元，证明了 $\tilde{T}$ 必然是**单射**。

## 5. $\tilde{T}$ 的值域与第一同构定理

**定理**：$\text{range } \tilde{T} = \text{range } T$。

**推导**：

根据定义，$\tilde{T}$ 的值域为所有可能的像：

$$
\text{range } \tilde{T} = \{ \tilde{T}(v + \text{null } T) \mid v \in V \} = \{ T(v) \mid v \in V \} = \text{range } T
$$

**核心结论：线性代数第一同构定理**

综上所述，如果我们把 $\tilde{T}$ 的目标空间限制为它的值域 $\text{range } T$，那么 $\tilde{T}$ 既是满射也是单射。

因此，$\tilde{T}$ 构成了一个**双射**（即线性同构）。商空间与像空间是同构的，记作：

$$
V/\text{null } T \cong \text{range } T
$$

**维度推论：

既然两个空间同构，它们的维数必然相等：

$$
\dim(\text{range } T) = \dim(V/\text{null } T)
$$

$$
\dim(\text{range } T) = \dim V - \dim(\text{null } T)
$$

移项，就得到了**从商空间视角推导出的秩-零化度定理**：

$$
\dim V = \dim(\text{null } T) + \dim(\text{range } T)
$$
