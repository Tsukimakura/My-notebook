# 期中复习安排 · 方法、练习与检查

[期中目录](index.md) · [2023 真题](paper-2023.md) · [真题解答](solutions-2023.md) · [迁移练习](transfer-practice.md)

## 先确定要练什么

范围为第 1–14 章，包含电磁波；各部分比例未知。复习时使用[公式页](formula-sheet-2023.md)，主要训练四件事：**识别模型、说明条件、列出方程、检查结果**。2023 年四道大题是练习样本，电路、振荡和波仍须单独练。

先用 20 分钟尝试迁移练习 [1](transfer-practice.md#check-1)、[4](transfer-practice.md#check-4)、[7](transfer-practice.md#check-7)、[10](transfer-practice.md#check-10)，暂不看解答。分别记录自己停在“概念”“首个方程”还是“运算”；后续优先补对应一环。

## 一轮约 13 小时，分两至三天完成

表中是净学习时间，休息另计。90 分钟的学习块可分为：20 分钟查讲义与公式条件、50 分钟独立解题、20 分钟纠错重做。较短的块按相同比例缩减。卡住约 8 分钟时，只查当前缺失的定义或步骤，再关上解答继续。

## 只剩约 6 小时时

用 60 分钟按下表写完各类的首式与条件；100 分钟做迁移练习；90 分钟限时做旧卷；60 分钟只补诊断出的错误；30 分钟专练 RLC 与波；20 分钟复述最后的检查项。少做重复计算，每类仍至少完成一题，尤其保留旧卷没有覆盖的振荡和波。

## 看到题目，第一步写什么

| 题目特征 | 首式 / 判断 | 随后检查 |
| --- | --- | --- |
| 球、圆柱、平面分布 | 先判断对称性；可用时写 $\oint\mathbf E\cdot d\mathbf A=Q_{\rm enc}/\epsilon$ | $\epsilon$ 与所计电荷匹配；无对称性时不能把 $E$ 提出积分 |
| 给 $V$、$\mathbf E$ 或 $\rho$ 互求 | $\mathbf E=-\nabla V$，$\rho_q=\epsilon_0\nabla\cdot\mathbf E$ | 静电场还须 $\nabla\times\mathbf E=0$；积分常数由边界给出 |
| 导体与接地 | 金属内 $\mathbf E=0$，表面 $V=V_c$；接地 $V_c=0$，孤立固定 $Q$ | 镜像只放在物理求解域外；总电荷条件是否满足 |
| 电容、漏电、充放电 | 先由场求 $V$，再求 $C=Q/V$、$R=V/I$；节点方程联立 $i=\pm\dot q$ | 连接决定固定 $Q$ 还是固定 $V$；$RC$、$L/R$ 的量纲都是时间 |
| 运动电荷与电流受力 | $q(\mathbf E+\mathbf v\times\mathbf B)$ 或 $\int I\,d\boldsymbol\ell\times\mathbf B$ | 电荷符号；磁力不做功不等于整套装置没有功率交换 |
| 旋转带电体 | $dq=\sigma_s dA$ 或 $\rho_qdV$，$dI=dq/T$ | 面电荷与体电荷；$d\mu=dI\times$ 环所围面积 |
| 感应与发电装置 | 固定环路 $\mathcal E=-\dot\Phi_B$；运动部分加 $\mathbf u\times\mathbf B$ | 先定法向和正绕向；能流能否闭合，$P_{\rm mech}=I\mathcal E$ |
| 自感、互感、振荡 | 写磁通链及端电压；$L\ddot q+R\dot q+q/C=0$ 或其受迫式 | 电流与电容电压的连续性；固定电流的电源也可能做功 |
| 正弦稳态 | $Z_R=R$，$Z_L=j\omega L$，$Z_C=1/(j\omega C)$ | 峰值/RMS、支路电流、相位；不要把过渡过程套成稳态相量 |
| 时变场与波 | 含位移电流的 Ampère–Maxwell；波中 $\mathbf B=\hat{\mathbf k}\times\mathbf E/c$ | 单一真空行波才可直接用 $E=cB$；静电和近场不能照搬 |

## 答题时的五个检查

1. **区域与对象：**金属、介质、空腔还是外部？求场、势、磁通还是总量？
2. **条件：**静态/稳态/时变？接地/孤立？开路/闭路？哪些量固定？
3. **方向：**积分正向、$\mathbf r$ 的源到场点方向、端电压顺序、$i=\pm\dot q$ 是否一致？
4. **量纲与极限：**$\sigma\to0$、$d\to\infty$、$\omega\to0$、$t=0,\infty$ 是否合理？
5. **守恒：**电荷是否连续，机械功、电源做功、场能和焦耳热是否记全？

剩余时间优先重做曾错的小问。达到可独立写出每类首式、解释适用条件并通过方向和量纲检查后，再增加运算量。
