# 基础/技巧

- 求极限函数： $n \to \infty$ 时的函数极限

- 不等式的放缩技巧
	- 构造中间项与三角不等式： $|A - B| = |A - C + C - B| \le |A - C| + |C - B|$ 这一基础放缩技巧。

- 向量的叉乘计算

- 基本初等函数的积分、 定积分的分步积分法

- 积分限全是常数，且被积函数能分离变量（化为各自独立函数的乘积）时，累次积分可转化为单变量积分的乘积。

- 分段点/奇点的偏导数求法： 对于在某点表达式发生变化或含有根号、绝对值的函数，求偏导数必须回到**一元导数的定义**去求，不能直接套用求导公式（因为直接求导在分母为0时无意义）

- 可微性的必要条件
	- 可微 $\Rightarrow$ 连续、 可微 $\Rightarrow$ 偏导数存在、 可微 $\Rightarrow$ 任意方向的方向导数存在

- 可微性的充分条件
	- 偏导数连续 $\Rightarrow$ 可微

- 级数的拆分： 将复杂的系数化简为基本初等函数的级数形式。如： $S(x) = \sum_{n=1}^{\infty} \left(n + \frac{1}{n}\right) x^n = \sum_{n=1}^{\infty} n x^n + \sum_{n=1}^{\infty} \frac{x^n}{n}$

- 等比级数： 掌握 $\sum_{n=0}^{\infty} x^n = \frac{1}{1-x}$ 及其变形 $\sum_{n=1}^{\infty} x^n = \frac{x}{1-x}$。

- 变上限积分求导

- 定积分的对称性质： $\int_{0}^{\pi} x f(\sin x) \,\mathrm{d}x = \frac{\pi}{2} \int_{0}^{\pi} f(\sin x) \,\mathrm{d}x$

- 遇到 $\sqrt{1 \pm \sin x}$ 或 $\sqrt{1 \pm \cos x}$，利用倍角/半角公式凑成完全平方。凑出平方后，千万记得结合积分区间判断正负

- 三角级数部分和一致有界的放缩技巧

	对于形如 $A_n(x) = \sum_{k=1}^n \cos(kx)$ 或 $\sum_{k=1}^n \sin(kx)$ 的三角和式，证明其在特定闭区间上一致有界：

	1. 化积为和（裂项相消）：

	    - **技巧：** 为求和式乘以辅助因子 $2\sin\frac{x}{2}$（或适当变形的三角项）。

	    - **目的：** 利用积化和差公式将级数转化为形式上两两抵消的数列和，从而求出部分和的闭式表达式。

	    - **结果形式：** 最终化为包含形如 $\frac{\sin(\cdot)\cos(\cdot)}{\sin(x/2)}$ 的紧凑分式。

	2. 常数化分子（绝对放缩）：

	    - **技巧：** 利用三角函数的有界性 $|\sin \alpha| \le 1, |\cos \beta| \le 1$。

	    - **目的：** 消除表达式中随 $n$ 增长的变量，将部分和放大至一个仅与 $x$ 有关的上界，即 $|A_n(x)| \le \frac{1}{|\sin(x/2)|}$。

	3. 内闭定界（区间避奇）：

	    - 技巧： 在考察的一致收敛区间（通常为 $(0, 2\pi)$）内，任取闭子区间 $[a, b] \subset (0, 2\pi)$。

	    - 目的： 避开使分母 $\sin\frac{x}{2} = 0$ 的奇点（$x=0, 2\pi$）。利用闭区间连续函数必有非零最小值的性质，确定常数 $m = \min(\sin\frac{a}{2}, \sin\frac{b}{2}) > 0$。

	    - 最终结论： 得到完全独立于 $n$ 和 $x$ 的一致上界 $M = \frac{1}{m}$，从而证明一致有界性。

- 题设中“差分级数 $\sum(b_{n+1}-b_n)$ 绝对收敛”，隐性地传达两个重要信息：一是差分的和有限（可用于放缩控制），二是数列 $\{b_n\}$ 自身必定有界。

- 二重极限的计算与放缩技巧： 考察如何证明一个二重极限为0。最常用的方法是“有界函数 $\times$ 无穷小”或者使用极坐标替换放缩

- “化二元为一元”的思想： 证明多元函数问题时，最常用的技巧就是固定一个变量，将另一个变量看作一元函数进行处理。

- 拉格朗日中值定理： 题目中出现“导数/偏导数有界”的条件，通常利用中值定理将“函数值的差”转化为“自变量的差 $\times$ 导数”，从而利用有界性进行放缩。

- 数列极限与等价无穷小

- 闭区间上连续函数的有界性定理

- **变限积分的绝对值放缩：** $\left| \int_a^b g(t) dt \right| \le \int_a^b |g(t)| dt$

- **数学归纳法：** 处理递推积分序列（尤其是涉及阶乘出现时）

- 第一型曲线积分（对弧长）的计算   $\times 2$
	- 参数方程化法： $\int_L f(x,y,z)\mathrm{d}s = \int_{\alpha}^{\beta} f(x(t), y(t), z(t)) \sqrt{x'(t)^2 + y'(t)^2 + z'(t)^2} \mathrm{d}t$。要熟练掌握弧长微元 $\mathrm{d}s$ 的计算。
	- 显式方程： $\mathrm{d}s = \sqrt{1 + (y')^2} \,\mathrm{d}x$

- 第二型曲线积分（对坐标）的计算
	- 格林公式 $\oint_{\partial D} P dx + Q dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy$ （**注意方向** -- 对区域右手定则/沿线左侧、曲线的积分方向）  $\times 3$
		- 先试探偏导函数 $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}$
		- 补线法（构造闭合曲线，结果再减去补的）

- 第二型曲面积分（对坐标）的计算
	- 高斯公式 $\iint_{\partial \Omega} P dydz + Q dzdx + R dxdy = \iiint_\Omega \left( \frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z} \right) dxdydz$   $\times 2$
		- 补面法（注意方向与原曲面协调）-- $\iint_\Sigma = \iiint_\Omega - \iint_{\Sigma_1}$
		- 利用几何体的对称性快速消去某些积分项
		- 注意曲面侧的正负号判定

- 二重积分的计算
	- 极坐标变换
		- 雅可比行列式 $|J| = r$，微元变为 $r dr d\theta$（$\mathrm{dx}\mathrm{dy} = r\,\mathrm{dr}\mathrm{d}\theta$）
		- 注意 $r , \theta$ 的积分区域
			- 极点在区域外部（$\theta$ 型）：$\int_\alpha^\beta d\theta \int_{r_1(\theta)}^{r_2(\theta)} f \cdot r dr$。
		    - 极点在区域内部：$\int_0^{2\pi} d\theta \int_0^{r(\theta)} f \cdot r dr$。
		    - 极点在区域边界上：$\int_\alpha^\beta d\theta \int_0^{r(\theta)} f \cdot r dr$。
	- 带绝对值的二重积分： 绝对值无法直接积分，要找到使得绝对值内部为 $0$ 的分界线（通常是一条曲线），将积分区域一分为二。
	- 二重积分化为累次积分（X/Y型区域）

- 三重积分的计算
	- 球坐标变换（适用球体、球壳、或顶点在原点的圆锥面）  $\times 3$
		- 雅可比行列式 $|J| = r^2\sin\varphi$，微元 $dV = r^2\sin\varphi dr d\varphi d\theta$
	- 柱坐标变换
		- 雅可比行列式 $|J| = r$， 微元 $dV = r dr d\theta dz$

- 方向导数的定义与计算 $\lim_{t \to 0^+} \frac{f(x_0+t\cos\alpha, y_0+t\sin\alpha) - f(x_0,y_0)}{t}$
	- 方向导数计算公式 $\frac{\partial f}{\partial l} = f_x\cos\alpha + f_y\sin\alpha$ 的**前提条件是函数在该点可微**
	- 计算方向导数必须适用**单位**方向向量

- 证明函数在某点不可微
	- F1： 不同路径趋近的极限值不同 --> 极限不存在 --> 函数不连续
	- F2： 证明偏导数不存在（不能用求导公式，必须回到**一元函数的偏导数定义**去求：$f_x(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x, y_0) - f(x_0,y_0)}{\Delta x}$
	- F3： 利用全微分定义构造极限（假设检验点为原点 $(0,0)$）： $L = \lim_{(x,y) \to (0,0)} \frac{f(x,y) - f(0,0) - [f_x(0,0)x + f_y(0,0)y]}{\sqrt{x^2+y^2}}$，证明该极限不为0或不存在 -- 特殊路径趋近

- 幂级数
	- 计算收敛域
		- $A = \lim_{n \to \infty} \sqrt[n]{|a_n|}$（根值法） 或 $A = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right|$（比值法）， $R = \frac{1}{A}$
		- 单独检验端点
	- 分析性质
		- 逐项可导（端点可能由收敛变发散）： 用于处理系数中带有 $n$ （分子上）的级数，如 $\sum n x^n$
		- 逐项可积（端点可能由发散变收敛）： 用于处理系数中带有 $1/n$ （分母上）的级数，如 $\sum \frac{x^n}{n}$

- 隐函数 $\times 2$
	- 存在唯一性与连续性：1. $F(x_0, y_0) = 0$；2. $F$ 及 $F_y$ 在邻域内连续；3. 因变量偏导数非零 $F_y(x_0, y_0) \neq 0$
	- 可微性： 在存在性条件下证明 $F_x$ 在邻域内连续
	- 隐函数求导
		- 一阶导数公式为 $f'(x) = -\frac{F_x(x,y)}{F_y(x,y)}$
		- 隐函数求导（两边同时对某变量求导） -- 注意复合函数求导的链式法则
	- 多元隐函数定理
		- $n$ 元方程 $F(x_1, \dots, x_n, y) = 0$
		- 初始点处 $F=0$、所有一阶偏导数连续，且对因变量的偏导数 $F_y \neq 0$，则局部存在唯一连续可微的隐函数 $y = f(x_1, \dots, x_n)$。其偏导数公式为：$f_{x_i} = -\frac{F_{x_i}}{F_y}$

- 傅里叶级数 $\times 3$
	- 半区间延拓化为全区间展开 -- 根据级数形式（只有正弦项/余弦项）对函数进行奇/偶延拓
	- 任意周期函数的傅里叶系数公式
		- 系数公式： $a_n = \frac{1}{l} \int_{-l}^{l} f(x) \cos \frac{n\pi x}{l} dx \quad (n \ge 0)$， $b_n = \frac{1}{l} \int_{-l}^{l} f(x) \sin \frac{n\pi x}{l} dx \quad (n \ge 1)$
		- 展开公式： $f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos \frac{n\pi x}{l} + b_n \sin \frac{n\pi x}{l} \right)$
	- 奇/偶函数（正/余弦级数）的系数公式
		- 化为半区间积分
		- 余弦级数： $a_n = \frac{2}{l} \int_0^l f(x) \cos \frac{n\pi x}{l} dx$，$b_n = 0$
		- 正弦级数： $a_n = 0$，$b_n = \frac{2}{l} \int_0^l f(x) \sin \frac{n\pi x}{l} dx$
	- 狄利克雷收敛定理 -- 若 $f(x)$ 以 $2\pi$ 为周期，且在 $[-\pi, \pi]$ 上**按段可导**（或按段光滑），则其傅里叶级数处处收敛，且收敛值为： $\frac{f(x+0) + f(x-0)}{2}$ （对连续点就是 $f(x)$）   $\times 2$

- 一致收敛下的连续性 -- 一致收敛的连续函数列，其极限函数必连续。对于级数，各项连续且一致收敛，则和函数连续。

- 条件极值与拉格朗日乘数法   $\times 2$
	- 在 $m$ 个约束条件 $\varphi_k(x_1, \dots, x_n) = 0$ 之下求目标函数 $f(x_1, \dots, x_n)$ 的极值
	- 构造拉格朗日函数：$L = f + \sum_{k=1}^m \lambda_k \varphi_k$（$\lambda_k$ 为乘子）
	- 各变量偏导为零：$L_{x_i} = 0 \quad (1 \le i \le n)$， 各乘子偏导为零（即原约束）：$\varphi_j = 0 \quad (1 \le j \le m)$。
	- 计算技巧： 如把原变量用 $\lambda$ 表示，再带入原约束。
