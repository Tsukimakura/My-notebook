# 人工智能引论：图示来源与复现

## 图示来源

本目录的 13 组图示为本笔记原创绘制。图结构和教学数值依据课程资料，排版与绘图代码重新制作；没有嵌入课件的照片、标识或截图。

| 文件名（不含扩展名） | 内容 | 依据 |
| --- | --- | --- |
| `ai-method-map` | AI 方法与系统框架 | 第一周、绪论及第一节课堂的知识体系 |
| `turing-machine` | 纸带、读写头与有限控制器 | 绪论中的计算模型，概念示意 |
| `family-knowledge-graph` | 已知亲属关系与待补全边 | 第二章知识图谱例题 |
| `foil-learning-loop` | 单条规则的细化与新事实推断 | 第二章 FOIL 算法说明 |
| `bayesian-network` | 多云、洒水、下雨与地湿 | 第二章概率图模型 |
| `causal-structures-and-intervention` | 三种关系结构与删入边干预 | 第二章因果推理 |
| `simpson-reversal` | 分组、总体与共同权重恢复率 | 第二章恢复人数表，保留精确分数 |
| `state-graph-and-search-tree` | 两条路径与重复目标状态 | 为解释第三节搜索框架新设的小例图 |

`*.svg` 是可编辑矢量源图，文字仍可编辑；`*.webp` 是笔记引用的展示资源。本项目未提供独立的开放许可文件；图示与脚本保留项目作者权利，未另行授予开放许可。课程原始 PPTX、截图与论文的权利属于各自权利人。

## 复现

前三节课的 8 组图示，在项目根目录运行：

```bash
python3 scripts/generate_ai_intro_figures.py
```

需要 Matplotlib、NumPy 与 Pillow。脚本使用本机 Noto Sans CJK 字体路径；其他环境需安装相应字体或修改脚本中的 `FONT`。这些是生成插图的可选依赖，阅读笔记或构建站点不需要运行该脚本。

## 数值与语义

恢复率图用 $234/270,55/80,81/87,192/263$，总体用 $289/350,273/350$，调整使用男性权重 $0.51$ 与女性权重 $0.49$。调整柱的因果解释依赖正文中的模型条件。

家庭图红色虚线表示待查询关系。FOIL 图描绘单条规则的内层细化流程，外层顺序覆盖见正文。因果图干预示意的红色虚线与叉表示被删除的入边；其余边保留。
