# 01_空间平面与直线

## 一、 方程表达（构型基础）

### 1. 平面方程的 4 种形态

- **点法式**：已知点 $P_0(x_0, y_0, z_0)$ 和法向量 $\vec{n} = (A, B, C)$。

    $$
A(x - x_0) + B(y - y_0) + C(z - z_0) = 0
    $$

- **一般式**：$Ax + By + Cz + D = 0$。

- **截距式**：与坐标轴交点截距为 $a, b, c$。

    $$
\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1
    $$

- **三点式（混合积为0）**：已知不共线三点 $P_1(x_1, y_1, z_1)$、$P_2(x_2, y_2, z_2)$、$P_3(x_3, y_3, z_3)$。

	由共面向量的混合积为0，可得 $3 \times 3$ 行列式等于 0：

	$$
\begin{vmatrix} x - x_1 & y - y_1 & z - z_1 \\ x_2 - x_1 & y_2 - y_1 & z_2 - z_1 \\ x_3 - x_1 & y_3 - y_1 & z_3 - z_1 \end{vmatrix} = 0
	$$

	或者转化为等价的 $4 \times 4$ 行列式等于 0：

	$$
\begin{vmatrix} x & y & z & 1 \\ x_1 & y_1 & z_1 & 1 \\ x_2 & y_2 & z_2 & 1 \\ x_3 & y_3 & z_3 & 1 \end{vmatrix} = 0
	$$

### 2. 直线方程的 3 种形态

- **点向式/参数方程（核心）**：已知点 $P_0$ 和方向向量 $\vec{s} = (l, m, n)$。

    $$
\frac{x - x_0}{l} = \frac{y - y_0}{m} = \frac{z - z_0}{n} \implies \begin{cases} x = x_0 + lt \\ y = y_0 + mt \\ z = z_0 + nt \end{cases}
    $$

- **一般式（两平面交线）**：

    $\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_2 = 0 \end{cases}$ （条件：系数矩阵秩为2，法向量叉乘不为 $\vec{0}$）

- **两点式**：方向向量直接取 $\vec{P_1P_2}$。

### 3. 平面束方程（高级技巧）

过直线（由两平面一般式给出）的所有平面集合：

$$
\lambda(F_1) + \mu(F_2) = 0
$$

_(做题技巧：通常令 $\lambda = 1$，仅求 $\mu$ 即可快速解题)_

## 二、 位置关系判定（利用矩阵秩 $r$）

将点、线、面关系转化为线性方程组。系数矩阵记为 $A$，增广矩阵记为 $\bar{A}$。

- **$r(A) = r(\bar{A})$** $\implies$ **有交集**（交点、交线或重合）。

- **$r(A) \neq r(\bar{A})$** $\implies$ **无交集**（平行或异面）。

| **几何对象**                                      | **考察模型**                                   | **r(A),r(Aˉ)**   | **几何关系**               |
| --------------------------------------------- | ------------------------------------------ | ---------------- | ---------------------- |
| **面 vs 面**<br><br>  <br><br>($2 \times 3$ 矩阵) | $\pi_1, \pi_2$                             | $r=2, \bar{r}=2$ | **相交**（交线）             |
|                                               |                                            | $r=1, \bar{r}=2$ | **平行**                 |
|                                               |                                            | $r=1, \bar{r}=1$ | **重合**                 |
| **线 vs 面**<br><br>  <br><br>($3 \times 3$ 矩阵) | 视直线为两平面<br><br>  <br><br>加待测面 $\pi_3$      | $r=3, \bar{r}=3$ | **相交于一点**              |
|                                               |                                            | $r=2, \bar{r}=3$ | **线面平行**               |
|                                               |                                            | $r=2, \bar{r}=2$ | **线在面内**               |
| **线 vs 线**<br><br>  <br><br>($4 \times 3$ 矩阵) | $L_1$ (面1,2)<br><br>  <br><br>$L_2$ (面3,4) | $r=3, \bar{r}=4$ | **异面 (Skew)** (无解且不平行) |
|                                               |                                            | $r=3, \bar{r}=3$ | **相交于一点**              |
|                                               |                                            | $r=2, \bar{r}=3$ | **线线平行**               |
|                                               |                                            | $r=2, \bar{r}=2$ | **重合**                 |

## 三、 计算（距离与夹角）

### 1. 距离公式

- **点到平面的距离**：代入点坐标，除以法向量模长。

    $$
d = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}
    $$

- **平行平面间的距离**（化为同法向量后求常数项之差）：

    $$
d = \frac{|D_1 - D_2|}{\sqrt{A^2 + B^2 + C^2}}
    $$

- **两条异面直线的距离**（投影法）：

    $$
d = \frac{|\vec{P_0P_1} \cdot (\vec{s_1} \times \vec{s_2})|}{|\vec{s_1} \times \vec{s_2}|}
    $$

    _(分子为三点与两方向向量构成的混合积，分母为公垂线方向向量的模长)_

### 2. 空间夹角计算

- **面与面（二面角）**：求两法向量的夹角余弦。

    $$
\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|}
    $$

- **线与面（易错点：用正弦）**：线面夹角与向量夹角互余。

    $$
\sin\theta = \frac{|\vec{n} \cdot \vec{s}|}{|\vec{n}||\vec{s}|}
    $$

## 四、 解题工具

1. **直线：一般式 $\to$ 点向式**

        - **求方向**：$\vec{s} = \vec{n_1} \times \vec{n_2}$ （两平面的法向量叉乘）。

        - **求定点**：令 $z=0$ （或 $x=0, y=0$），解二元一次方程组求出一个具体的点。

    	- 或初等变换求出参数方程再转化

2. **定比分点公式**（用于线段比例切分）：

    $$
x = \frac{x_1 + \lambda x_2}{1 + \lambda}, \quad y = \frac{y_1 + \lambda y_2}{1 + \lambda}, \quad z = \frac{z_1 + \lambda z_2}{1 + \lambda}
    $$

    _(当 $\lambda=1$ 时即为中点坐标公式)_
