# 基础/思想方法

- 线性映射（变换）矩阵化

- 子空间的三个判定条件：非空（包含零向量）、对加法封闭、对数乘封闭。

- 直积空间 $V \times W$ 的维数等于各自维数之和

- 相似
	- 存在可逆矩阵 $P$，使得 $B = P A P^{-1}$
	- 可对角化/化为若当标准型的含义
	- 相似矩阵的特征多项式相同（特征值和代数重数完全一致）
	- 相似不改变矩阵的秩
	- 对于可对角化的矩阵，几何重数=代数重数

- 与向量空间的关系转化为与向量空间的基的关系（如求解正交补空间，与即空间的基正交）

- 连续小问的关联

- 将多项式转化为参数的方程

- 向量的线性无关性证明： 利用“左乘矩阵的特定次幂消去低次项”是证明由同一个向量迭代生成的向量组（Krylov序列）线性无关的标准手法。

- 矩阵的秩与像空间维数的等价关系： $r(A) = \dim(\text{Im}(A))$

- Jordan 基的几何意义： 将抽象的算子 $T$ 转化为具体基向量的映射关系（即 $T\epsilon_i = \epsilon_{i-1}$ 或 $0$）。 -- 处理不变子空间

- **元素全为 $1$ 的方阵（或秩为 1 的矩阵）的幂次规律：** 对于 $n$ 阶全 1 矩阵 $J_n$，存在性质 $J_n^2 = n J_n$，进而推导出 $J_n^k = n^{k-1} J_n$。

- 任何一个投影算子（幂等算子） $P$ 都会自然地诱导出空间的一个直和分解：$V = \ker(P) \oplus \text{Im}(P)$。并且有重要性质 $\text{Im}(P) = \ker(I - P)$

- **矩阵乘法的迹性质：** $\text{Tr}(AB) = \text{Tr}(BA)$，$\text{Tr}(A^T) = \text{Tr}(A)$。特别地，$\text{Tr}(AA^T)$ 是矩阵所有元素平方和

- $n$ 阶实对称矩阵空间的维数是 $\frac{n(n+1)}{2}$

# 考点梳理

- 伴随算子，以及自伴矩阵/正规矩阵等相关矩阵
	- 在单位正交基下，$T^*$ 的矩阵是 $T$ 的矩阵的**共轭转置**（$C = \bar{A}^T$）。实空间中即为转置矩阵 $A^T$。
	- 自伴算子 $T = T^*$，特征值必为实数
	- 正规算子 $TT^* = T^*T$，模长保持：$\lVert Tv \rVert = \lVert T^*v \rVert$；若 $Tv = \lambda v$，则 $T^*v = \bar{\lambda}v$。
	- 零空间与值域的正交补关系
		- $\ker(T^*) = (\text{im } T)^\perp$，$\text{im}(T^*) = (\ker T)^\perp$，$\ker(T) = (\text{im } T^*)^\perp$，$\text{im}(T) = (\ker T^*)^\perp$
	- 运算性质：思考共轭转置的运算性质
	- 对称矩阵 = 自伴算子 的前提：**必须在标准正交基下**

- 特征值与特征方程、特征多项式
	- 利用 $|\lambda I - A| = 0$ 求解特征多项式2
	- Cayley-Hamilton Theorem -- 算子 $T$ 满足其自身的特征多项式

- 复数域内的方程求解

- 谱定理（算子在**标准正交基**下可对角化的充要条件（$\dim V < \infty$））

|**空间类型**|**前提条件**|**对角化的等价条件**|
|---|---|---|
|**复内积空间**|$T$ 是**正规算子**|$V$ 存在一组标准正交基，使 $T$ 的矩阵为**对角矩阵**。|
|**实内积空间**|$T$ 是**自伴算子**|$V$ 存在一组由 $T$ 的**特征向量**组成的标准正交基，使 $T$ 为**对角矩阵**。|


- 正交补与正交投影
	- 几何意义（等式 $\langle f, g \rangle = \langle h, g \rangle$ 对所有 $g \in V$ 成立，核心几何意义就是“误差向量 $(f-h)$ 与整个子空间 $V$ 垂直”）
	- 最佳逼近定理（空间的正交分解与正交补、正交投影的计算）
	- 求解正交补空间 -- 与原空间的基正交   2
	- **只有自伴算子（对称阵）** 才具备 $W$ 不变推导 $W^\perp$ 也不变的优良性质

- （标准）正交基
	- 利用内积是否两两为 0 检验（基的）正交性
	- 施密特正交化（注意单位化的时机减小计算量）

- 幂零矩阵/变换
	- 识别矩阵的高次幂，$B^8X = O$，则 $B$ 是幂零矩阵
	- 存在某个正整数 $k$，使得 $B^k = O$
	- 幂零指数不超过空间维数
	- 与**特征值全为 0**等价3
	- 矩阵 $B$ 的特征多项式为 $f(\lambda) = \lambda^n$
	- 幂零若当块 -- 超对角线上全部为1，其他全0
	- 循环子空间与基的构造： 利用一个向量 $X$ 被矩阵连续左乘产生的序列 $\{X, AX, A^2X, \dots \}$ 来构造线性无关的向量组。

- 极小多项式与 Jordan 标准型
	- 极小多项式相应特征值项的次数决定了最大 Jordan 块的大小
	- 某特征值的代数重数决定对角线上它的数量
	- 几何重数决定了该特征值被分成的 Jordan 块的数量
	- Jordan 块的标准形式： 对角线上全部为特征值，超对角线上全部为1，其他全0
	- 极小多项式整除所有零化多项式，是次数最低的首一零化多项式
	- 对于任意一个 $k$ 阶的**特征值为 0**的 Jordan 块 $J_k(0)$，它的秩为 $k-1$。
	- 如果 $A = \text{diag}(A_1, A_2, \dots, A_k)$ 是分块对角阵，那么 $A$ 的极小多项式是各个子块 $A_i$ 极小多项式的**最小公倍式**。
	- 极小多项式中 $(\lambda - \lambda_i)^{m_i}$ 的最高次幂 $m_i$，刚好等于对应特征值 $\lambda_i$ 的**最大若尔当块的阶数**。
	- 只有当矩阵可对角化时，最小多项式才没有重根
	- 证明极小多项式： **首一性**、**化零性**、以及**最小性**（或整除性）

- 对偶映射的定义/矩阵表示和计算
	- 对任意 $T \in \mathcal{L}(V, W)$，其诱导出的对偶映射 $T': W' \to V'$ 的作用法则定义为 $T'(\varphi) \triangleq \varphi \circ T$
	- 有限维空间对应基下，原线性映射矩阵 $A$ 与其对偶映射矩阵 $A'$ 互为转置，即 $A' = A^T$

- 奇异值的定义与求解  2
	- 算子 $T$ 的奇异值是正算子 $\sqrt{T^*T}$ 的**所有特征值**（必为非负实数）
		- 实际计算可以先求 $T^*T$ 的特征值再对特征值开根

- 空间平面与直线
	- 平面束方程（代入直线外一点确定平面方程）
	- 直线的方向向量是确定它的两个平面的法向量的外积（一般方程化为点向式）3
	- 空间中点到直线距离的向量公式 $d = \frac{|\vec{M_0 P} \times \vec{v}|}{|\vec{v}|}$（向量法）3
	- 点到平面距离公式

- 内积空间
	- 识别连续函数空间（多项式空间）上标准内积的形式 $\int f(x)g(x)\mathrm{d}x$  3
	- 内积的性质 -- 正定性、第一/二位置加性、第一位置齐次性、第二位置共轭齐次性、共轭对称性
	- 里斯表示定理
	- 在有限维内积空间 $V$ 中，对任意线性泛函 $\varphi \in V'$，**存在唯一**的向量 $u \in V$，使得对 $\forall v \in V$，成立：$\varphi(v) = \langle v, u \rangle$，**$u$ 的构造式**（基于规范正交基 $e_i$）：$u = \sum_{i=1}^n \overline{\varphi(e_i)} e_i$。
	- 内积的公理化定义（证明内积）： 准确写出证明内积所需的四个条件（对称性、双线性、正定性），缺一不可

- 商空间
	- 商空间 $X / Y$ 的维数公式为 $\dim(X / Y) = \dim X - \dim Y$
	- 求商空间基的核心本质是**求原空间的直和补空间的基**

- 正算子与等距算子
	- **正算子**是**自伴算子**，且所有特征值非负
	- **等距算子**保范数（$\|Sv\| = \|v\|$）、保内积（$\langle Su, Sv \rangle = \langle u, v \rangle$）、将任意标准正交基映射为标准正交基、$S^* S = SS^* = I$ （**正规算子**，$S^* = S^{-1}$）、伴随算子 $S^*$ 也是等距算子
