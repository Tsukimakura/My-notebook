## 一、 基础设定

- **数域**：讨论基于实数域或复数域，统一记作 $\mathbb{F} = \mathbb{R}$ 或 $\mathbb{C}$。
    
- **线性算子**：设 $T$ 为有限维向量空间 $V$ 上的线性算子，记作 $T \in \mathscr{L}(V)$。
    

---

## 二、 不变子空间

### 1. 不变子空间的定义

设 $W$ 是 $V$ 的子空间（记作 $W \le V$）。如果对于子空间 $W$ 中的任意向量 $v$，其经过算子 $T$ 映射后的结果 $Tv$ 仍然属于 $W$，即：

$$\forall v \in W, \ Tv \in W$$

则称子空间 $W$ 为算子 $T$ 的**不变子空间**。

### 2. 经典实例

- **零子空间 $\{0\}$**：因为 $T(0) = 0 \in \{0\}$。
    
- **全空间 $V$**：因为 $T$ 的到达域是 $V$，显然恒成立。
    
- **零空间 $\text{null } T$**：$\forall v \in \text{null } T$，有 $Tv = 0 \in \text{null } T$。
    
- **值域 $\text{range } T$**：$\forall v \in V$，$Tv$ 根据定义天然落在 $\text{range } T$ 中。
    

_【例 】多项式空间的微分算子_

设 $D: \mathscr{P}(\mathbb{R}) \to \mathscr{P}(\mathbb{R})$ 为求导算子，定义为 $D(p(x)) = p'(x)$。

对于任意非负整数 $n$，最高次数不超过 $n$ 的多项式空间 $\mathscr{P}_n(\mathbb{R})$ 是 $D$-不变的，因为求导会降低多项式的次数。此外，$\text{null } D = \mathbb{R}$（常数项多项式）。

### 3. 算子可交换性与不变子空间

**性质**：若存在另一个线性算子 $S$，且 $S$ 与 $T$ 满足复合运算的交换律（即 $ST = TS$），则 **$\text{range } S$ 是 $T$ 的不变子空间**。

**证明**：

$\forall Sv \in \text{range } S$，应用 $T$ 作用得 $T(Sv) = (TS)v = (ST)v = S(Tv) \in \text{range } S$。

### 4. 限制算子与商算子

若 $W$ 是 $T$-不变子空间，基于 $W$ 可以定义两个新的重要算子：

1. **限制算子** $T|_W : W \to W$
    
    由于 $W$ 是不变的，算子 $T$ 限制在 $W$ 上仍然是一个良好定义的线性算子。
    
1. **商算子** $T/W : V/W \to V/W$
    
    定义为：$(T/W)(v+W) = Tv + W$。
    
    - **良定义性证明**：若 $v_1+W = v_2+W$，则 $v_1-v_2 \in W$。由于 $W$ 是 $T$-不变的，故 $T(v_1-v_2) \in W$，即 $Tv_1 - Tv_2 \in W$。从而 $Tv_1+W = Tv_2+W$。
        
	- **线性证明**：
	
    $$\begin{aligned} (T/W)\big(\lambda_1(v_1 + W) + \lambda_2(v_2 + W)\big) &= (T/W)\big((\lambda_1 v_1 + \lambda_2 v_2) + W\big) \\ &= T(\lambda_1 v_1 + \lambda_2 v_2) + W \\ &= \lambda_1 Tv_1 + \lambda_2 Tv_2 + W \\ &= \lambda_1(T/W)(v_1 + W) + \lambda_2(T/W)(v_2 + W) \end{aligned}$$


**【例】不变子空间的直和补**

**问题**：如果 $U$ 是 $T$-不变子空间，是否一定存在另一个不变子空间 $W$，使得 $V = U \oplus W$？（答案：**不一定**）

**反例**：设 $T \in \mathscr{L}(\mathbb{F}^2)$，定义 $T(x, y) = (y, 0)$。

设 $U = \{(x, 0) | x \in \mathbb{F}\}$。

1. $U$ 是 $T$-不变的：因为 $T(x, 0) = (0, 0) \in U$。此时限制算子 $T|_U = 0$。
    
2. 空间 $\mathbb{F}^2$ 中 $U$ 的所有代数补空间形式为 $W_k = \{(ky, y) | y \in \mathbb{F}\}$。
    
3. 检验 $W_k$ 的不变性：$T(ky, y) = (y, 0)$。若要求 $(y, 0) \in W_k$，则必须有 $(y, 0) = (ky', y')$，推导得出 $y' = 0 \implies y = 0$。因此，对于非零向量，$W_k$ 不是不变子空间。不存在满足条件的不变补空间。

## 三、 本征值与本征向量

### 1. 定义

对于 $\forall T \in \mathscr{L}(V)$，若存在标量 $\lambda \in \mathbb{F}$ 及**非零向量** $v \in V \ (v \neq 0)$，满足：

$$Tv = \lambda v$$

则称 $\lambda$ 为算子 $T$ 的**本征值（特征值）**，$v$ 为对应的**本征向量（特征向量）**。

### 2. 实例解析

_旋转算子_：$T \in \mathscr{L}(\mathbb{F}^2)$，$T(w, z) = (-z, w)$。

- **当 $\mathbb{F} = \mathbb{R}$ 时**：假设存在本征值 $\lambda \in \mathbb{R}$，则 $(-z, w) = \lambda(w, z)$。即 $-z = \lambda w$ 且 $w = \lambda z$。代入得 $w = -\lambda^2 w \implies (\lambda^2+1)w = 0$。若 $w=0$ 则 $z=0$，但**本征向量不能为零向量**，故必有 $\lambda^2+1=0$。在实数域无解，**故实空间中此算子无本征值**。
    
- **当 $\mathbb{F} = \mathbb{C}$ 时**：$\lambda^2+1=0 \implies \lambda = \pm i$。当 $\lambda = i$ 时，$w = iz, z = -iw$，对应的本征向量形如 $t(i, 1) \ (t \neq 0)$。
    

### 3. 本征值的等价刻画

**定理：** 设有限维空间 $\dim V < \infty$，$T \in \mathscr{L}(V)$，$\lambda \in \mathbb{F}$。以下命题等价：

1. $\lambda$ 是 $T$ 的本征值。
    
2. 算子 $T - \lambda I$ 不是单射。
    
3. 算子 $T - \lambda I$ 不是满射。
    
4. 算子 $T - \lambda I$ 不可逆。
    

_推导逻辑_：$Tv = \lambda v \iff (T - \lambda I)v = 0 \iff v \in \text{null}(T - \lambda I)$。既然 $v \neq 0$，说明零空间非平凡，故不是单射（有限维空间下单射、满射、可逆互为等价）。

### 4. 本征向量的线性无关性

**定理**：属于**不同本征值**的本征向量是**线性无关**的。

- **证明（极小反例法）**：设 $\lambda_1, \dots, \lambda_m$ 互不相同，对应的本征向量 $v_1, \dots, v_m$ 线性相关。
    
    选取其中长度最短的线性相关关系（假设前 $t$ 个向量相关）：
    
    $l_1v_1 + l_2v_2 + \dots + l_t v_t = 0 \quad (\text{其中 } l_i \neq 0)$
    
    两边同时作用算子 $T$：$l_1\lambda_1v_1 + \dots + l_t\lambda_t v_t = 0$
    
    将原式两边同时乘以 $\lambda_t$：$l_1\lambda_tv_1 + \dots + l_t\lambda_t v_t = 0$
    
    两式相减得：
    
    $l_1(\lambda_1 - \lambda_t)v_1 + \dots + l_{t-1}(\lambda_{t-1} - \lambda_t)v_{t-1} = 0$
    
    因为 $\lambda_i$ 互不相同且 $l_i \neq 0$，这构成了一个更短的非平凡线性关系，与假设矛盾！故必定线性无关。
    

**推论**：若 $\dim V < \infty$，则算子 $T$ 互不相同的本征值个数 $m \le \dim V$。

## 四、 多项式算子与极小多项式

### 1. 算子的多项式

设 $p(x) \in \mathscr{P}(\mathbb{F})$，多项式 $p(x) = a_0 + a_1 x + \dots + a_m x^m$ 作用于算子 $T$ 定义为：

$$p(T) = a_0 I + a_1 T + \dots + a_m T^m$$

**性质**：由于多项式乘法满足交换律 $p(x)q(x) = q(x)p(x)$，故算子多项式也满足交换律：$p(T)q(T) = q(T)p(T)$。

### 2. 复数域上本征值的存在性

**定理**：对于任意有限维复向量空间（$\mathbb{F} = \mathbb{C}, \dim V < \infty$），$T \in \mathscr{L}(V)$ 必定存在至少一个本征值。

**证明**：

设 $\dim V = n$。任取 $v \in V, v \neq 0$。

考虑 $n+1$ 个向量：$v, Tv, T^2v, \dots, T^nv$。由维度定理，它们必定线性相关。

因此存在不全为 $0$ 的系数，使得：$l_0v + l_1Tv + \dots + l_m T^m v = 0 \ (m \le n, l_m \neq 0)$。

定义多项式 $p(x) = l_0 + l_1x + \dots + l_mx^m$，则有 $p(T)v = 0$。

根据代数基本定理，在复数域中将 $p(x)$ 分解为一次因式：

$p(x) = l_m (x - \lambda_1) \dots (x - \lambda_m)$

因此：$l_m(T - \lambda_1 I) \dots (T - \lambda_m I)v = 0$。

由于 $v \neq 0$，这一串算子作用下去最终变成了零向量，这意味着必定在某一步，一个非零向量被算子 $(T - \lambda_i I)$ 映射成了零向量。

即存在非零向量 $u$ 使得 $(T - \lambda_i I)u = 0 \implies Tu = \lambda_i u$。故 $\lambda_i$ 是本征值。

### 3. 零化多项式与极小多项式

由于有限维空间中 $\mathscr{L}(V)$ 的维数也是有限的（$n^2$），必定存在多项式使得 $p(T) = \mathbf{0}$ （即算子映射任何向量都为 0）。

- 集合 $I = \{ q(x) \in \mathscr{P}(\mathbb{F}) | q(T) = 0 \}$ 是非空的。
    
- 在集合 $I$ 中，存在一个**次数最低的首一多项式**，称为 $T$ 的**极小多项式**，记作 $q(x)$。
    
- **唯一性与整除性**：若有任意多项式 $f(x)$ 使得 $f(T) = 0$。利用多项式带余除法：
    
    $f(x) = s(x)q(x) + r(x)$，其中 $r(x) = 0$ 或 $\deg r < \deg q$。
    
    代入算子 $T$ 得 $0 = f(T) = s(T)q(T) + r(T) = 0 + r(T) \implies r(T) = 0$。
    
    因为 $q(x)$ 已经是使算子为零的最低次多项式，故 $r(x)$ 只能为 $0$恒等式。即**极小多项式 $q(x)$ 整除任何零化多项式 $f(x)$**。由此也容易证明极小多项式是唯一的。

## 五、 准素分解（空间分解）定理

> 通过分析线性算子的零化多项式的代数结构，可以将其所在的整个线性空间进行严密的几何分解。

设 $f(T) = 0$，且 $f(x)$ 可以分解为互素多项式的乘积：$f(x) = p_1(x)^{e_1} \dots p_r(x)^{e_r}$（其中 $p_i(x)$ 为不可约多项式）。

则全空间 $V$ 可以分解为不变子空间的直和：

$$V = V_1 \oplus V_2 \oplus \dots \oplus V_r$$

其中 $V_i = \text{null } p_i(T)^{e_i}$，且每个 $V_i$ 都是 $T$-不变子空间。

【证明】

**第一步：子空间独立性的确立**

**目标**：证明若 $v_1 + v_2 + \dots + v_r = 0$（其中 $v_i \in V_i$），则必有 $v_1 = v_2 = \dots = v_r = 0$。

对于每一个 $i \in \{1, \dots, r\}$，定义多项式 $f_i(x)$ 为剔除第 $i$ 个特征因子后的乘积：

$$f_i(x) = \frac{f(x)}{p_i(x)^{e_i}} = \prod_{j \neq i} p_j(x)^{e_j}$$

根据子空间 $V_j = \text{null } p_j(T)^{e_j}$ 的定义：

- **对于 $j \neq i$**：多项式 $f_i(x)$ 包含了因子 $p_j(x)^{e_j}$。因此，当 $f_i(T)$ 作用于 $v_j \in V_j$ 时，由于算子可交换，有：
    
    $$f_i(T)v_j = \left( \prod_{k \neq i, j} p_k(T)^{e_k} \right) \cdot \underbrace{p_j(T)^{e_j} v_j}_{0} = 0$$
    

将算子 $f_i(T)$ 作用于已知等式 $v_1 + v_2 + \dots + v_r = 0$ 的两边：

$$f_i(T)(v_1 + v_2 + \dots + v_i + \dots + v_r) = f_i(T)(0)$$

利用上述性质，等式左边除了第 $i$ 项外全部变为零：

$$0 + 0 + \dots + f_i(T)v_i + \dots + 0 = 0 \implies f_i(T)v_i = 0$$


现在得到了关于 $v_i$ 的两个约束条件：

1. $p_i(T)^{e_i} v_i = 0$ （由 $v_i \in V_i$ 的定义所得）
    
2. $f_i(T) v_i = 0$ （由上述推导所得）
    

由于 $p_i(x)^{e_i}$ 与 $f_i(x)$ 是**互素**的（它们没有共同的不可约因子），根据多项式的裴蜀定理，存在多项式 $a(x)$ 和 $b(x)$ 使得：

$$a(x)p_i(x)^{e_i} + b(x)f_i(x) = 1$$

代入算子 $T$ 并作用于 $v_i$：

$$a(T)\underbrace{p_i(T)^{e_i} v_i}_{0} + b(T)\underbrace{f_i(T) v_i}_{0} = I(v_i) = v_i$$

由此得出 $v_i = 0$。

**结论**

由于上述推导对任意 $i$ 均成立，我们证明了当子空间向量之和为零时，每个分量必须为零。这满足了直和的充分必要条件，确立了子空间的独立性：

$$V_1 + V_2 + \dots + V_r = V_1 \oplus V_2 \oplus \dots \oplus V_r$$

**第二步：空间和的证明 ($V = V_1 + V_2 + \dots + V_r$)**

为了证明全空间 $V$ 中的任意向量都能由这些子空间中的向量拼凑而成，需要借助**多项式的裴蜀定理**。

**1. 构造互素多项式族**

令 $f_i(x)$ 为总零化多项式 $f(x)$ 剔除第 $i$ 个因子后剩余的部分：

$$f_i(x) = \frac{f(x)}{p_i(x)^{e_i}} = \prod_{j \neq i} p_j(x)^{e_j}$$

由于各个 $p_i(x)$ 是彼此不同的不可约多项式，那么多项式族 $(f_1(x), f_2(x), \dots, f_r(x))$ 的最大公因式为 $1$。

**2. 引入裴蜀恒等式并转化为算子**

根据多项式理论，既然最大公因式为 $1$，必定存在一组多项式 $u_1(x), \dots, u_r(x)$，使得它们的线性组合恒等于 $1$：

$$u_1(x)f_1(x) + u_2(x)f_2(x) + \dots + u_r(x)f_r(x) = 1$$

将线性算子 $T$ 代入上述恒等式，常数 $1$ 变为恒等算子 $I$，得到算子等式：

$$u_1(T)f_1(T) + u_2(T)f_2(T) + \dots + u_r(T)f_r(T) = I$$

**3. 对任意向量进行分解**

对于空间 $V$ 中的**任意向量 $v$**，将上述算子等式两边同时作用于 $v$：

$$v = I(v) = u_1(T)f_1(T)v + u_2(T)f_2(T)v + \dots + u_r(T)f_r(T)v$$

现在，向量 $v$ 被拆分成了 $r$ 个项的和。我们将其中的第 $i$ 项记为 $v_i$，即 $v_i = u_i(T)f_i(T)v$。

**4. 验证分量 $v_i$ 的空间归属**

我们需要证明这个构造出来的 $v_i$ 确实属于对应的子空间 $V_i$（即证明它能被 $p_i(T)^{e_i}$ 零化）。

将算子 $p_i(T)^{e_i}$ 作用于 $v_i$，由于多项式算子之间满足乘法交换律，有：

$$\begin{aligned} p_i(T)^{e_i}v_i &= p_i(T)^{e_i}u_i(T)f_i(T)v \\ &= u_i(T) \left[ p_i(T)^{e_i} f_i(T) \right] v \\ &= u_i(T)f(T)v \end{aligned}$$

因为 $f(T) = \mathbf{0}$ 是算子 $T$ 的零化多项式，所以 $u_i(T)f(T)v = 0$。

这完美地证明了 $v_i \in \text{null } p_i(T)^{e_i}$，即 **$v_i \in V_i$**。

**结论**

综上所述，任意向量 $v \in V$ 都可以成功分解为各个 $V_i$ 中向量的和，这就证明了 $V = V_1 + V_2 + \dots + V_r$。

再结合第一步中已经证明的子空间独立性，即可正式确立全空间的不变子空间直和关系：

$$V = \bigoplus_{i=1}^r V_i$$

## 六、 算子可对角化的条件

### 1. 极小多项式判定准则

**定理**：设 $T \in \mathscr{L}(V)$，则 $T$ 是可对角化的 **当且仅当** $T$ 的极小多项式 $p(x)$ 没有重根（即由互不相同的线性因式组成）。

形式化表述：

$$p(x) = (x - \lambda_1)(x - \lambda_2) \dots (x - \lambda_r), \quad \text{其中 } \lambda_i \neq \lambda_j \ (i \neq j)$$

### 2. 证明

- **充分性 ($\Leftarrow$) 证明**：
    
    已知极小多项式 $p(x) = (x - \lambda_1) \dots (x - \lambda_r)$。根据准素分解定理，全空间可以分解为：
    
    $$V = V_1 \oplus V_2 \oplus \dots \oplus V_r$$
    
    其中 $V_i = \text{null}(T - \lambda_i I)$。
    
    这意味着，对于任意 $v \in V_i$，都有 $(T - \lambda_i I)v = 0 \implies Tv = \lambda_i v$。即 $V_i$ 正是对应于本征值 $\lambda_i$ 的**本征子空间**。
    
    在每个 $V_i$ 中取一组基 $\{\varepsilon_{i1}, \dots, \varepsilon_{im_i}\}$，将所有这些基合并起来 $\{\varepsilon_{11}, \dots, \varepsilon_{rm_r}\}$，由于是直和，这必定构成全空间 $V$ 的一组基。由于这组基完全由本征向量组成，故算子 $T$ 在这组基下是可对角化的。
    
- **必要性 ($\Rightarrow$) 证明**：
    
    已知 $T$ 是可对角化的，则存在一组基，使得 $T$ 的矩阵表现为对角阵 $\text{diag}(\lambda_1 E_{m_1}, \dots, \lambda_r E_{m_r})$（将相同的本征值归在一起，$E$ 为单位阵）。
    
    构造多项式 $P(x) = (x - \lambda_1) \dots (x - \lambda_r)$（没有重根）。
    
    将对角阵代入该多项式进行检验，由于对角阵的多项式运算等于对角线上各元素分别进行多项式运算，我们发现对于每一个分块 $\lambda_i E_{m_i}$，因式 $(x - \lambda_i)$ 会使其变为零块，从而整个矩阵变为零阵。
    
    因此 $P(T) = \mathbf{0}$，且因为本征值必须是极小多项式的根，所以极小多项式必然就是这个没有重根的 $P(x)$。
    

### 3. 应用实例

通过观察多项式方程，可以直接判断矩阵（算子）的对角化性质：

- **幂等矩阵 $A^2 = A$**：对应的零化多项式为 $x^2 - x = 0 \implies x(x - 1) = 0$。根为 $0, 1$，无重根。必然可对角化，相似于形如 $\begin{pmatrix} E_r & 0 \\ 0 & 0 \end{pmatrix}$ 的矩阵。
    
- **对合矩阵 $A^2 = E$**：对应的零化多项式为 $x^2 - 1 = 0 \implies (x - 1)(x + 1) = 0$。根为 $1, -1$，无重根。必然可对角化，相似于形如 $\begin{pmatrix} E_s & 0 \\ 0 & -E_t \end{pmatrix}$ 的矩阵。
    
- **方程 $A^2 - 2A - 3E = \mathbf{0}$**：对应多项式 $x^2 - 2x - 3 = 0 \implies (x - 3)(x + 1) = 0$。根为 $3, -1$，无重根。必然可对角化。

## 七、 复数域上的上三角化定理

在复数域中，虽然不是所有算子都能对角化，但**所有**线性算子都可以化为**上三角矩阵**。

**定理**：设 $\mathbb{F} = \mathbb{C}$ 且 $\dim V < \infty$，$T \in \mathscr{L}(V)$。则必定存在 $V$ 的一组基 $v_1, \dots, v_n$，使得算子 $T$ 在该基下的矩阵表示为上三角矩阵：

$$\mathcal{M}(T) = \begin{pmatrix} \lambda_1 & * & \dots & * \\ 0 & \lambda_2 & \dots & * \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \lambda_n \end{pmatrix}$$

**证明（利用商空间进行数学归纳法）**：

1. **归纳基础**：当 $\dim V = 1$ 时，任取非零向量 $v$ 构成基，$Tv = \lambda v$，矩阵就是一个标量，显然是上三角的。
    
2. **归纳假设**：假设对于所有 $\dim = n$ 的复向量空间，定理成立。
    
3. **递推步（证明 $\dim V = n+1$ 成立）**：
    
    - 由于是在复数域 $\mathbb{C}$ 上，算子 $T$ 必定存在至少一个本征值 $\lambda_1$ 及对应的本征向量 $v_1$（即 $Tv_1 = \lambda_1 v_1$）。
        
    - 令 $U = \text{span}(v_1)$。由于 $v_1$ 是本征向量，$U$ 显然是一个一维的 $T$-不变子空间。
        
    - 构造商空间 $V/U$。其维数为 $\dim(V/U) = \dim V - \dim U = (n+1) - 1 = n$。
        
    - 在商空间上定义商算子 $T/U$。由归纳假设，存在 $V/U$ 的一组基 $v_2+U, \dots, v_{n+1}+U$，使得 $T/U$ 在这组基下的矩阵是上三角阵 $(a_{ij})$。
        
    - 这意味着对于这组基，有：
        
        $(T/U)(v_i+U) = a_{2i}(v_2+U) + \dots + \lambda_i(v_i+U)$
        
        即：$T v_i + U = (a_{2i}v_2 + \dots + \lambda_i v_i) + U$
        
    - 这等价于：$T v_i - (a_{2i}v_2 + \dots + \lambda_i v_i) \in U$。
        
    - 由于 $U = \text{span}(v_1)$，所以存在标量 $a_{1i}$ 使得：
        
        $T v_i - (a_{2i}v_2 + \dots + \lambda_i v_i) = a_{1i}v_1 \implies T v_i = a_{1i}v_1 + a_{2i}v_2 + \dots + \lambda_i v_i$
        
    - 这说明了 $Tv_i$ 可以被 $v_1, v_2, \dots, v_i$ 线性表出。
        
    - 最后，我们需要验证 $\{v_1, v_2, \dots, v_{n+1}\}$ 是 $V$ 的一组基（即验证它们线性无关）：
        
        设 $l_1v_1 + l_2v_2 + \dots + l_{n+1}v_{n+1} = 0$。
        
        将其映射到商空间 $V/U$ 中：$l_1(v_1+U) + l_2(v_2+U) + \dots + l_{n+1}(v_{n+1}+U) = 0+U$。
        
        因为 $v_1 \in U$，所以 $v_1+U = 0+U$，式子化简为：$l_2(v_2+U) + \dots + l_{n+1}(v_{n+1}+U) = 0+U$。
        
        由于 $v_2+U, \dots, v_{n+1}+U$ 是商空间的基（线性无关），必定有 $l_2 = \dots = l_{n+1} = 0$。
        
        代回原式得 $l_1v_1 = 0$，又因 $v_1 \neq 0$，故 $l_1 = 0$。
        
        因此这组向量线性无关，构成了 $V$ 的一组基。且在这个基下，$T$ 的矩阵严格表现为上三角形式。证毕。

## 八、 上三角矩阵的等价刻画

从向量和子空间的角度给出上三角阵的等价条件。

**定理**：设 $T \in \mathscr{L}(V)$，存在 $V$ 的一组基 $v_1, \dots, v_n$。以下三个命题是等价的：

1. 算子 $T$ 在该基下的矩阵是**上三角矩阵**。
    
2. 对于任意 $j \in \{1, 2, \dots, n\}$，均有 $T v_j \in \text{span}(v_1, \dots, v_j)$。
    
3. 对于任意 $j \in \{1, 2, \dots, n\}$，子空间 $\text{span}(v_1, \dots, v_j)$ 都是 **$T$-不变子空间**。
    

**等价性证明：**

- **(1) $\implies$ (2)**：
    
    已知 $T$ 是上三角阵，根据基和矩阵的定义：
    
    $T(v_1, \dots, v_n) = (v_1, \dots, v_n) \begin{pmatrix} a_{11} & \dots & a_{1n} \\ 0 & \ddots & \vdots \\ 0 & 0 & a_{nn} \end{pmatrix}$
    
    观察第 $j$ 列，可直接得出 $Tv_j = a_{1j}v_1 + a_{2j}v_2 + \dots + a_{jj}v_j$。显然这个结果向量属于 $\text{span}(v_1, \dots, v_j)$。
    
- **(2) $\implies$ (3) （数学归纳法）**：
    
    - 当 $j=1$ 时，$Tv_1 \in \text{span}(v_1)$，故 $\text{span}(v_1)$ 是不变子空间。
        
    - 假设当 $j=k$ 时，$\text{span}(v_1, \dots, v_k)$ 是不变子空间。
        
    - 当 $j=k+1$ 时，空间可分解为 $\text{span}(v_1, \dots, v_{k+1}) = \text{span}(v_1, \dots, v_k) \oplus \text{span}(v_{k+1})$。
        
        由条件 (2) 已知 $T(v_{k+1}) \in \text{span}(v_1, \dots, v_{k+1})$。
        
        对于前 $k$ 个向量生成的空间，由归纳假设，映射后依然落在其中，显然也属于更大的 $\text{span}(v_1, \dots, v_{k+1})$。
        
        由此证明了新的生成空间依然是 $T$-不变的。
        
- **(3) $\implies$ (1)**：
    
    已知 $\text{span}(v_1, \dots, v_j)$ 是不变子空间，则映射基向量 $v_j$ 得到的结果 $Tv_j$ 必包含在该空间内。
    
    即 $Tv_j = a_{1j}v_1 + \dots + a_{jj}v_j$。这意味着在表示矩阵的第 $j$ 列中，第 $j$ 行以下的元素必定全为 $0$。对所有 $j$ 均成立，故矩阵为上三角矩阵。

## 九、 上三角矩阵的进一步性质

### 1. 上三角矩阵的可逆性判定

**定理**：假设 $T \in \mathscr{L}(V)$ 在某组基下的矩阵 $\mathcal{M}(T)$ 是上三角矩阵，形如：

$$\mathcal{M}(T) = \begin{pmatrix} \lambda_1 & * & \dots & * \\ 0 & \lambda_2 & \dots & * \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \lambda_n \end{pmatrix}$$

则 **$T$ 是可逆算子 $\iff$ 对角线上的所有元素 $\lambda_i \neq 0 \ (1 \le i \le n)$**。

**证明思路**：

- 若存在 $\lambda_i = 0$，则限制在子空间 $\text{span}(v_1, \dots, v_i)$ 上的算子不是单射（其零空间维数 $\ge 1$），这意味着整个算子 $T$ 存在非零的零空间向量，故 $T$ 不可逆。
    
- 反之，若所有 $\lambda_i \neq 0$，则算子在每一步扩张的子空间上都是满射且单射的，最终导出整体可逆。
    

### 2. 对角线元素即为本征值

**定理**：假设 $T \in \mathscr{L}(V)$ 在某组基下的矩阵是上三角矩阵，则该**上三角矩阵主对角线上的元素恰好是 $T$ 的所有本征值**。

**证明**：

考察算子 $T - \lambda I$。由于 $T$ 是上三角矩阵，$\lambda I$ 也是对角阵，因此 $\mathcal{M}(T - \lambda I)$ 依然是上三角矩阵，其形式为：

$$\mathcal{M}(T - \lambda I) = \begin{pmatrix} \lambda_1 - \lambda & * & \dots & * \\ 0 & \lambda_2 - \lambda & \dots & * \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \dots & \lambda_n - \lambda \end{pmatrix}$$

根据上述可逆性判定定理，算子 $T - \lambda I$ **不可逆**当且仅当其对角线上至少有一个元素为 0。

即存在某个 $i$，使得 $\lambda_i - \lambda = 0 \implies \lambda = \lambda_i$。

又因为 $T - \lambda I$ 不可逆等价于 $\lambda$ 是 $T$ 的本征值，故结论成立。

## 十、 本征子空间与空间的直和

为了更系统地研究对角化，将属于同一本征值的所有本征向量集合起来，考察其空间结构。

### 1. 本征子空间的定义

**定义**：设 $T \in \mathscr{L}(V)$，$\lambda \in \mathbb{F}$。属于 $\lambda$ 的 **本征子空间** 定义为：

$$E(\lambda, T) = \{v \in V \mid Tv = \lambda v\} = \text{null}(T - \lambda I)$$

显然，$E(\lambda, T)$ 是一个子空间，它由零向量和所有属于本征值 $\lambda$ 的本征向量组成。且 $E(\lambda, T)$ 显然是 $T$-不变子空间。

### 2. 本征子空间的直和性质

**定理**：若 $\lambda_1, \dots, \lambda_m$ 是算子 $T \in \mathscr{L}(V)$ 的互异本征值，则对应的本征子空间之和是**直和**，即：

$$E(\lambda_1, T) + \dots + E(\lambda_m, T) = E(\lambda_1, T) \oplus \dots \oplus E(\lambda_m, T)$$

**证明逻辑**：

根据直和的等价条件，只需证明：若 $v_1 + v_2 + \dots + v_m = 0$（其中 $v_i \in E(\lambda_i, T)$），则必然有 $v_1 = v_2 = \dots = v_m = 0$。

这等价于证明“属于不同本征值的非零本征向量线性无关”（见前文“三、4. 本征向量的线性无关性”）。若存在某个 $v_i \neq 0$，将构成非平凡的线性关系，导致矛盾。

## 十一、 算子可对角化的等价刻画

**定理**：设 $\dim V = n$，且 $\lambda_1, \dots, \lambda_m$ 是 $T \in \mathscr{L}(V)$ 的所有互不相同的本征值。以下五个命题相互等价：

- **(a)** $T$ 是可对角化的。
    
- **(b)** $V$ 中存在一组由 $T$ 的**本征向量**组成的基。
    
- **(c)** 存在 $n$ 个一维的 $T$-不变子空间 $U_1, \dots, U_n$，使得 $V = U_1 \oplus \dots \oplus U_n$。
    
- **(d)** 全空间是所有本征子空间的直和：$V = E(\lambda_1, T) \oplus \dots \oplus E(\lambda_m, T)$。
    
- **(e)** 全空间的维数等于各本征子空间维数之和：$\dim V = \sum_{i=1}^m \dim E(\lambda_i, T)$。
    

**关键等价性推导**：

1. **(a) $\iff$ (b)**：定义使然。矩阵为对角阵 $\iff$ $T(v_i) = \lambda_i v_i$，即基向量均为本征向量。
    
2. **(b) $\iff$ (c)**：令 $U_i = \text{span}(v_i)$，由于 $v_i$ 是本征向量，$U_i$ 必然是一维不变子空间；反之，一维不变子空间的基向量必然是本征向量。
    
3. **(d) $\implies$ (a)**：在每个本征子空间 $E(\lambda_i, T)$ 中选取一组基 $v_{i1}, \dots, v_{ik_i}$。由于是直和，把所有这些基合在一起构成全空间 $V$ 的基。在这组基下，算子 $T$ 的矩阵表现为分块对角阵 $\text{diag}(\lambda_1 E_{k_1}, \dots, \lambda_m E_{k_m})$，即实现了对角化。
    
4. **(d) $\iff$ (e)**：根据子空间直和的维数公式直接得出。因为 $\sum E(\lambda_i, T)$ 已经是直和，其构成的子空间 $W$ 满足 $\dim W = \sum \dim E(\lambda_i, T)$。若该和等于 $\dim V$，则 $W = V$。
    
5. **(b) $\implies$ (d)**：由于 $V$ 中存在由特征向量组成的基，那么 $V$ 中的任意向量均可由这些特征向量线性表出，这意味着全空间 $V$ 是所有特征子空间的和，即 $V = E(\lambda_1, T) + \dots + E(\lambda_m, T)$。又因为属于不同特征值的特征向量总是线性无关的，即不同特征子空间之和必定是**直和**，故 $V = E(\lambda_1, T) \oplus \dots \oplus E(\lambda_m, T)$。

## 十二、 经典实例分析

### 例1：代数重数 > 几何重数（不可对角化）

设算子 $T \in \mathscr{L}(\mathbb{F}^2)$，定义为 $T(w, z) = (z, 0)$。

其在标准基下的矩阵为：

$$\mathcal{M}(T) = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$$

- 求解本征值：特征多项式 $\lambda^2 = 0 \implies \lambda = 0$（二重根）。
    
- 求解本征子空间 $E(0, T)$：解方程 $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} w \\ z \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$，得到 $z=0$。
    
- 因此，$E(0, T) = \{(w, 0) \mid w \in \mathbb{F}\}$。
    
- **结论**：本征子空间维数 $\dim E(0, T) = 1$。因为 $1 < \dim V = 2$，不满足定理中 **(e)** 的条件 $\dim V = \sum \dim E(\lambda_i, T)$，故该算子**不可对角化**。
    

### 例2：常规可对角化矩阵计算

考察矩阵：

$$A = \begin{pmatrix} 41 & 7 \\ -20 & 74 \end{pmatrix}$$

- **求本征值**：通过解 $\det(A - \lambda I) = 0$，求得互异的本征值 $\lambda_1 = 69, \lambda_2 = 46$。
    
- **求本征向量**：
    
    - 对 $\lambda_1 = 69$，解 $(A - 69I)x = 0$，得到本征向量 $v_1 = (1, 4)^T$。
        
    - 对 $\lambda_2 = 46$，解 $(A - 46I)x = 0$，得到本征向量 $v_2 = (7, 5)^T$。
        
- **结论**：由于算子有两个互异本征值，且 $\dim V = 2$，两个一维本征子空间直接撑起了全空间（满足等价条件 **e** 和 **d**），故 $A$ 必然可对角化。

## 十三、 $n$ 个互异本征值与对角化定理

### 1. 互异本征值判定准则

**定理**：设 $\dim V = n$，$T \in \mathscr{L}(V)$。如果算子 $T$ 拥有 $n$ 个**互不相同**的本征值 $\lambda_1, \lambda_2, \dots, \lambda_n$，则 $T$ 必然是**可对角化**的。

**证明**：

对于每一个本征值 $\lambda_i$，必定存在对应的非零本征向量 $v_i$，即 $T v_i = \lambda_i v_i$ 且 $v_i \neq 0$。

根据前文定理（**属于不同本征值的本征向量线性无关**），向量组 $v_1, v_2, \dots, v_n$ 是线性无关的。

由于空间 $V$ 的维数 $\dim V = n$，这 $n$ 个线性无关的本征向量恰好构成了全空间 $V$ 的一组基。

既然存在由本征向量组成的基，根据定理 5.41，算子 $T$ 必然可对角化。

### 2. 实例分析

**例**：设算子 $T$ 在某组基下的矩阵表示为上三角矩阵：

$$\mathcal{M}(T) = \begin{pmatrix} 2 & 1 & 0 \\ 0 & 5 & 3 \\ 0 & 0 & 8 \end{pmatrix}$$

**分析**：根据上三角矩阵的性质，主对角线上的元素即为矩阵的本征值。故 $\lambda_1 = 2, \lambda_2 = 5, \lambda_3 = 8$。

由于该算子处于 3 维空间，且拥有 3 个互不相同的本征值，该算子必定可对角化。
