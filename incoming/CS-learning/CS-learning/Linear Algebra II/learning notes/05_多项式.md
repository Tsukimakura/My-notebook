## 一、 多项式的基本概念与唯一性

### 1. 多项式与多项式函数

设 $\mathbb{F}$ 为一个域（通常 $\mathbb{K}$ 指代复数域 $\mathbb{C}$ 或实数域 $\mathbb{R}$），多项式的一般形式为：

$$f(x) = a_n x^n + \dots + a_1 x + a_0$$

- **未知元**
    
- **多项式的唯一性（系数决定多项式）**：
    
    对于两个多项式 $f(x) = \sum_{i=0}^n a_i x^i$ 与 $g(x) = \sum_{j=0}^m b_j x^j$，若它们相等，则必然有：
    
    $$m = n \quad \text{且} \quad a_i = b_i \ (\forall i)$$
    
- **多项式与多项式函数的区别**：
    
    将 $x$ 视作变量带入域中的值，则构成**多项式函数**。在无限域（如 $\mathbb{R}, \mathbb{C}$）中，两者一一对应；但在有限域中则不然。
    
    - **反例（有限域 $\mathbb{Z}_2$）**：设 $\mathbb{F} = \mathbb{Z}_2 = \{\overline{0}, \overline{1}\}$。作为形式多项式，$x \neq x^2 + x^3 + x^4$。但是作为多项式函数，当代入 $0$ 时 $0=0$，代入 $1$ 时 $1 = 1+1+1 = 1 \pmod 2$。两者作为函数恒等，但作为多项式不同。
        

### 2. 多项式的次数与零因子

通常情况下，多项式乘积的次数等于各自次数之和：

$$\partial(f(x)g(x)) = \partial(f(x)) + \partial(g(x))$$

- **前提条件**：系数域不能包含零因子。
    
- **反例（含零因子的环 $\mathbb{Z}_6$）**：设 $\mathbb{Z}_6 = \{\overline{0}, \overline{1}, \overline{2}, \overline{3}, \overline{4}, \overline{5}\}$。
    
    计算 $(2x^2 + x + 1)(3x) = 6x^3 + 3x^2 + 3x$。
    
    由于在 $\mathbb{Z}_6$ 中 $\overline{6} = \overline{0}$，因此结果为 $3x^2 + 3x$。
    
    此时 $\partial((2x^2+x+1)(3x)) = 2$，而 $\partial(2x^2+x+1) + \partial(3x) = 2 + 1 = 3$，等式不成立。

## 二、 多项式恒等定理

**定理**：设 $f(x), g(x)$ 为定义在域 $\mathbb{F}$ 上的多项式，若 $\forall z \in \mathbb{F}$，都有 $f(z) = g(z)$，则 $f(x)$ 与 $g(x)$ 的各项系数完全对应相等（前提 $\mathbb{F}$ 元素足够多，例如 $\mathbb{C}$）。

**等价命题**：若多项式 $P(x) = f(x) - g(x) = 0$ 对任意 $z$ 恒成立，则 $P(x)$ 必须是零多项式。

**分析证明思路（利用分析学中的不等式界放缩）**：

假设 $P(z) = a_0 + a_1 z + \dots + a_m z^m$，且不全为 $0$，不妨设最高次项系数 $a_m \neq 0$。

选取一个足够大的 $|z|$，使得最高次项占据绝对主导地位。取：

$$|z| = \frac{|a_0| + |a_1| + \dots + |a_{m-1}|}{|a_m|} + 1$$

此时对于低次项之和的绝对值，有：

$$|a_0 + a_1 z + \dots + a_{m-1} z^{m-1}| \le (|a_0| + |a_1| + \dots + |a_{m-1}|)|z|^{m-1} < |a_m| |z|^m$$

这说明当 $|z|$ 足够大时，低次项的加和无法抵消最高次项 $a_m z^m$，因此多项式函数值不可能恒为 $0$。由此反证得出，恒为零的函数的各项系数必须全为 $0$。

## 三、 带余除法（欧几里得除法）

**定理内容**：

设 $p(x), q(x) \in \mathbb{F}[x]$，且 $q(x) \neq 0$。则存在唯一的多项式 $h(x)$（商）和 $r(x)$（余式），使得：

$$p(x) = h(x)q(x) + r(x)$$

其中，要求 $r(x) = 0$ 或者 $\partial(r(x)) < \partial(q(x))$。

### 1. 唯一性的代数证明（反证法）

假设存在两组分解：

$$p(x) = h_1(x)q(x) + r_1(x) = h_2(x)q(x) + r_2(x)$$

移项得到：$(h_1(x) - h_2(x))q(x) = r_2(x) - r_1(x)$

若 $h_1(x) \neq h_2(x)$，则等式左边的次数 $\ge \partial(q(x))$；但等式右边的次数由于 $\partial(r_1), \partial(r_2) < \partial(q(x))$，必然满足次数 $< \partial(q(x))$。产生矛盾。

因此必须有 $h_1(x) = h_2(x)$，进而推导出 $r_1(x) = r_2(x)$。唯一性得证。

### 2. 存在性与唯一性的线性空间视角（同构映射）

设 $\partial(p(x)) = n$, $\partial(q(x)) = m$。考虑 $n \ge m$ 的情形。

构造线性空间 $\mathscr{P}_k(\mathbb{F})$ 表示次数不超过 $k$ 的多项式集合。

定义线性映射 $T: \mathscr{P}_{n-m}(\mathbb{F}) \times \mathscr{P}_{m-1}(\mathbb{F}) \to \mathscr{P}_n(\mathbb{F})$，其映射规则为：

$$T(s, r) = sq + r$$

- **线性性质验证**：
    
    $T(\lambda_1(s_1, r_1) + \lambda_2(s_2, r_2)) = T(\lambda_1 s_1 + \lambda_2 s_2, \lambda_1 r_1 + \lambda_2 r_2)$
    
    $= (\lambda_1 s_1 + \lambda_2 s_2)q + \lambda_1 r_1 + \lambda_2 r_2 = \lambda_1(s_1 q + r_1) + \lambda_2(s_2 q + r_2)$
    
    $= \lambda_1 T(s_1, r_1) + \lambda_2 T(s_2, r_2)$
    
- **核空间（零空间）**：
    
    若 $T(s, r) = 0$，即 $sq + r = 0 \implies sq = -r$。
    
    通过比较次数可知，若 $s \neq 0$，则 $\partial(sq) \ge m$，而 $\partial(-r) < m$，矛盾。
    
    因此必须有 $s = 0, r = 0$。即 $\text{null}(T) = \{(0, 0)\}$，说明 $T$ 是**单射**。
    
- **维度计算**：
    
    定义域维度：$\dim(\mathscr{P}_{n-m} \times \mathscr{P}_{m-1}) = \dim(\mathscr{P}_{n-m}) + \dim(\mathscr{P}_{m-1}) = (n - m + 1) + m = n + 1$
    
    到达域维度：$\dim(\mathscr{P}_n) = n + 1$
    
- **结论**：由于 $T$ 是相同有限维空间之间的单射，故 $T$ 必然是**满射**（同构）。这直接证明了对于任意 $p(x) \in \mathscr{P}_n$，必然存在唯一的 $(s, r)$ 使得 $p(x) = sq + r$，即带余除法成立。

## 四、 多项式的根与余数定理

### 1. 多项式的根

对于 $p(x) \in \mathscr{P}(\mathbb{F})$，若存在 $\lambda \in \mathbb{F}$ 使得 $p(\lambda) = 0$，则称 $x = \lambda$ 是多项式方程 $p(x) = 0$ 的根。

### 2. 余数定理

**定理**：对任意 $\lambda \in \mathbb{F}$，多项式 $p(x)$ 可以表示为：

$$p(x) = s(x)(x - \lambda) + p(\lambda)$$

**证明**：由带余除法，除以一次多项式 $(x-\lambda)$，余式必然是零次多项式（常数）$r \in \mathbb{F}$：

$p(x) = s(x)(x-\lambda) + r$

代入 $x = \lambda$，得到 $p(\lambda) = s(\lambda)(\lambda - \lambda) + r \implies r = p(\lambda)$。得证。

### 3. 因式定理

**推论**：$(x - \lambda)$ 是 $p(x)$ 的一个因子 $\iff$ $p(\lambda) = 0$（即 $\lambda$ 是根）。

- **必要性 ($\Rightarrow$)**：若 $(x-\lambda)$ 是因子，存在 $s(x)$ 使 $p(x) = s(x)(x-\lambda)$，代入 $\lambda$ 显然有 $p(\lambda) = 0$。
    
- **充分性 ($\Leftarrow$)**：若 $p(\lambda) = 0$，由余数定理 $p(x) = s(x)(x-\lambda) + p(\lambda) = s(x)(x-\lambda)$，即存在因子 $(x-\lambda)$。
    

### 4. 根的个数界限

**推论**：非零多项式的根的个数（计重数）不超过多项式的次数，即 $N \le \partial(p(x))$。

**数学归纳法证明**：

- **基础步骤**：当 $\partial(p(x)) = 0$ 时，$p(x) = a_0 \neq 0$。显然没有根，根的数量 $0 \le 0$ 成立。
    
- **归纳步骤**：假设结论对次数为 $n$ 的多项式成立。
    
    考虑 $\partial(p(x)) = n + 1$ 的情况：
    
    1. 若 $p(x)$ 在域中无根，则根的个数 $0 \le n+1$，显然成立。
        
    2. 若 $p(x)$ 存在一个根 $x = \lambda$，由因式定理，$p(x) = (x-\lambda)q(x)$。
        
        此时 $\partial(q(x)) = n$。根据归纳假设，$q(x)$ 的根的个数不超过 $n$。
        
        因此 $p(x)$ 的总根数 = 1 + $q(x)$ 的根数 $\le 1 + n$。归纳成立。
        

_(注：在代数闭包如 $\mathbb{C}$ 中，多项式可完全分解为 $p(z) = a_m(z-z_1)\dots(z-z_m)$，此时根的个数刚好等于其次数。)_

## 五、 复数域与实数域上的多项式因式分解

### 1. 复数域上的多项式与代数基本定理

在复数域 $\mathbb{C}$ 中，多项式具有最完美的分解形式。

- **代数基本定理**：对于任意非常数多项式 $f(x)$，在复数域 $\mathbb{C}$ 内一定存在至少一个零点（根）。
    
- **复数域因式分解定理**：由代数基本定理和因式定理可推导得出，任意 $n$ 次首一多项式 $f(x) = x^n + a_{n-1}x^{n-1} + \dots + a_0$ 在 $\mathbb{C}$ 上可以唯一分解为一次因式的乘积：
    
    $$f(x) = (x-x_1)(x-x_2)\dots(x-x_n)$$
    
    其中 $x_1, x_2, \dots, x_n \in \mathbb{C}$ 为多项式的 $n$ 个根（含重根）。
    

**【代数基本定理的分析学证明思路】`(*)`**

借用了单复变函数 $f(z)$ 的理论来证明代数基本定理。

- **刘维尔定理（Liouville's Theorem）**：若复变函数 $f(z)$ 在整个复平面 $\mathbb{C}$ 上解析（可导），而且存在常数 $M$ 使得全局有界 $|f(z)| \le M$，则 $f(z)$ 必定是一个常数 $C_0 \in \mathbb{C}$。
    
- **反证法证明代数基本定理**：
    
    假设多项式 $P(z) = a_n z^n + \dots + a_0$ 在 $\mathbb{C}$ 中无零点。
    
    则函数 $\frac{1}{P(z)}$ 在整个复平面上处处解析。
    
    因为多项式的最高次项主导行为，当 $|z| \to \infty$ 时，$\lim_{|z| \to \infty} |P(z)| = \infty$，从而：
    
    $$\lim_{|z| \to \infty} \frac{1}{|P(z)|} = 0$$
    
    根据极限定义，取 $\epsilon = 1$，必定存在 $N>0$，当 $|z| > N$ 时，有 $|\frac{1}{P(z)} - 0| < 1$。
    
    而在闭圆盘 $|z| \le N$ 内，解析函数 $\frac{1}{P(z)}$ 连续，必然有界，设上界为 $M$。
    
    综合上述两点，$\frac{1}{P(z)}$ 在整个复平面上是有界的。根据刘维尔定理，$\frac{1}{P(z)}$ 必须是一个常数 $C_0 \neq 0$，这意味着多项式 $P(z) = \frac{1}{C_0}$ 是常数多项式，与 $P(z)$ 是非常数多项式的前提矛盾。
    
    因此，假设不成立，$P(z)$ 在 $\mathbb{C}$ 中必有零点。
    

### 2. 实数域上的多项式因式分解

对于实系数多项式 $P(x) \in \mathbb{R}[x]$，其分解形式与复数域不同，会出现不可约的二次因式。

- **共轭复根定理**：若 $z_j \in \mathbb{C} \setminus \mathbb{R}$ 是实系数多项式 $P(x)$ 的一个复数根（即 $P(z_j) = 0$），对其取共轭，由于实数系数的共轭等于其自身，必然有 $P(\overline{z_j}) = 0$。即实系数多项式的虚根必然成对出现。
    
- **配对构造实系数二次式**：
    
    若存在一对共轭虚根 $z_j$ 和 $\overline{z_j}$，则 $P(x)$ 包含因式 $(x-z_j)(x-\overline{z_j})$。
    
    展开该式：
    
    $$(x-z_j)(x-\overline{z_j}) = x^2 - (z_j+\overline{z_j})x + z_j\overline{z_j}$$
    
    令 $b = -(z_j+\overline{z_j})$, $c = z_j\overline{z_j}$，显然 $b, c \in \mathbb{R}$。此时判别式 $\Delta = b^2 - 4c = (z_j-\overline{z_j})^2 < 0$。
    
- **实数域标准分解形式**：
    
    在实数域 $\mathbb{R}$ 上，任意多项式可以唯一分解为一次多项式和判别式小于零的二次多项式的乘积：
    
    $$P(x) = a_n (x-\lambda_1)\dots(x-\lambda_r)(x^2+b_1x+c_1)\dots(x^2+b_sx+c_s)$$
    
    其中 $\lambda_i \in \mathbb{R}$ 为实根，$b_i, c_i \in \mathbb{R}$ 且 $\Delta_i = b_i^2 - 4c_i < 0$。

## 六、 有理数域上的多项式与不可约性

### 1. $\mathbb{Q}[x]$ 与 $\mathbb{Z}[x]$ 的关系与高斯引理

- **结论**：多项式在有理数域 $\mathbb{Q}[x]$ 内可约，当且仅当它在整数环 $\mathbb{Z}[x]$ 内可约。
    
    设 $f(x) \in \mathbb{Z}[x]$，若其在 $\mathbb{Q}$ 上分解为 $f(x) = P_1(x)P_2(x)$，通过提取分母和公因数，可以将其转化为整数系数的分解。
    
- **高斯引理（Gauss's Lemma）**：两个本原多项式（系数的最大公约数为 $1$ 的整系数多项式）的乘积依然是本原多项式。这是上述结论成立的核心支撑。
    

### 2. 爱森斯坦判别法（Eisenstein's Criterion）

> 这是一种用于快速判断整系数多项式在有理数域 $\mathbb{Q}$ 上是否不可约的强大工具。

- **定理内容**：设整系数多项式 $P(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0 \in \mathbb{Z}[x]$。
    
    若**存在**一个**素数** $p$，满足以下三个条件：
    
    1. $p \nmid a_n$ （$p$ 不整除最高次项系数）
        
    2. $p \mid a_i, \quad (0 \le i \le n-1)$ （$p$ 整除除最高次项外的所有系数）
        
    3. $p^2 \nmid a_0$ （$p^2$ 不整除常数项）
        
        则 $P(x)$ 在有理数域 $\mathbb{Q}$ 上是**不可约多项式**。
        
- **证明过程（模 $p$ 反证法）**：
    
    假设 $P(x)$ 在 $\mathbb{Q}$ 上可约，由高斯引理，它在 $\mathbb{Z}[x]$ 上也可约，设分解为：
    
    $$P(x) = P_1(x)P_2(x)$$
    
    其中 $\partial(P_1), \partial(P_2) \ge 1$。
    
    将等式两边在域 $\mathbb{Z}_p$ （模 $p$ 剩余类环）下考虑，即所有系数模 $p$。
    
    由于 $p \mid a_i \ (0 \le i \le n-1)$，原多项式模 $p$ 后低次项全部消失，仅剩最高次项：
    
    $$\overline{P(x)} = \overline{a_n} x^n$$
    
    于是有 $\overline{a_n} x^n = \overline{P_1(x)}\cdot\overline{P_2(x)}$。
    
    因为 $\mathbb{Z}_p$ 是一个域，多项式环没有零因子，要使乘积为单项式 $x^n$ 的倍数，$\overline{P_1(x)}$ 和 $\overline{P_2(x)}$ 模 $p$ 之后必然也都只包含最高次项，其常数项必为 $\overline{0}$。
    
    即 $\overline{P_1(0)} = \overline{0}$ 且 $\overline{P_2(0)} = \overline{0}$，这意味着在整数域中 $p \mid P_1(0)$ 且 $p \mid P_2(0)$。
    
    由于原多项式的常数项 $a_0 = P_1(0)P_2(0)$。
    
    那么必然有 $p \cdot p \mid P_1(0)P_2(0)$，即 $p^2 \mid a_0$。
    
    这与判别法条件中的 $p^2 \nmid a_0$ **矛盾**，故原假设不成立，$P(x)$ 不可约。
    
- **典型应用：证明无理数**
    
    利用爱森斯坦判别法，可以方便地证明某些根式是无理数。
    
    例如考虑方程 $x^n - p_1 p_2 \dots p_k = 0$ （其中 $p_i$ 为互不相同的素数）。
    
    取素数 $p = p_1$：
    
    - $p_1 \nmid 1$ (最高次系数)
        
    - $p_1 \mid (p_1 p_2 \dots p_k)$ (常数项)
        
    - $p_1^2 \nmid (p_1 p_2 \dots p_k)$ (因为 $p_i$ 互不相同且仅出现一次)
        
        由爱森斯坦判别法，多项式 $x^n - p_1 p_2 \dots p_k$ 在 $\mathbb{Q}$ 上不可约，因此它没有有理根。
        
        由此推导出 $\sqrt[n]{p_1 p_2 \dots p_k}$ 必然是无理数。
