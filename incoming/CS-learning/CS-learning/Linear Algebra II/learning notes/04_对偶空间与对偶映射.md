# 一、 线性泛函与对偶空间的基本概念

## 1. 线性泛函

设 $V$ 是在数域 $\mathbb{F}$ 上的一个线性空间。

- **定义**：从线性空间 $V$ 映射到其底层数域 $\mathbb{F}$ 的线性映射称为**线性泛函**。即 $T \in \mathcal{L}(V, \mathbb{F})$。
    
- 它可以表示为变量的线性组合形式：
    
    $$T(x) = \lambda_1 x_1 + \lambda_2 x_2 + \dots + \lambda_n x_n = a$$
    

**线性泛函的例子**：

- **例 1 (矩阵乘法)**：$T: \mathbb{F}^n \to \mathbb{F}$，定义为 $T(X) = AX$。其中 $A$ 是一个 $1 \times n$ 的行矩阵 $(a_{ij})_{1 \times n}$，等价于系数向量 $(\lambda_1, \dots, \lambda_n)$。
    
- **例 2 (实数空间映射)**：$\varphi: \mathbb{R}^3 \to \mathbb{R}$，定义为 $\varphi(x, y, z) = 4x - 5y + 2z$。
    
- **例 3 (多项式空间映射)**：$\varphi: \mathcal{P}(\mathbb{R}) \to \mathbb{R}$（其中 $\mathcal{P}(\mathbb{R}) = \mathbb{R}[x]$ 是实系数多项式空间），定义为 $\varphi(p) = 3p'(5) + 7p(4)$。
    
    - _证明其线性性质_：
        
        $$\varphi(\lambda_1 p_1 + \lambda_2 p_2) = 3(\lambda_1 p_1'(5) + \lambda_2 p_2'(5)) + 7(\lambda_1 p_1(4) + \lambda_2 p_2(4))$$
        
        $$= \lambda_1(3p_1'(5) + 7p_1(4)) + \lambda_2(3p_2'(5) + 7p_2(4)) = \lambda_1 \varphi(p_1) + \lambda_2 \varphi(p_2)$$
        

## 2. 对偶空间

- **定义**：线性空间 $V$ 上所有线性泛函构成的集合本身也是一个线性空间，称为 $V$ 的**对偶空间**，记作 $V'$（或 $V^*$）。
    
    $$V' := \mathcal{L}(V, \mathbb{F})$$
    
- **维度定理**：已知线性映射空间的维度公式为 $\dim \mathcal{L}(V, W) = \dim V \cdot \dim W$。由于数域 $\mathbb{F}$ 作为一个一维空间（$\dim \mathbb{F} = 1$），可得：
    
    $$\dim V' = \dim V \cdot 1 = \dim V$$
    
    _(前提：$V$ 为有限维空间，即 $\dim V < \infty$)_

# 二、 对偶基

## 1. 对偶基的定义

设 $v_1, \dots, v_n$ 是有限维空间 $V$ 的一组基。我们定义映射 $\varphi_i$，使得对于 $V$ 中任意向量 $\sum_{j=1}^n a_j v_j$，都有：

$$\varphi_i \left( \sum_{j=1}^n a_j v_j \right) = a_i$$

（即 $\varphi_i$ 的作用是提取向量在第 $i$ 个基向量上的坐标）。

这等价于 **Kronecker Delta 属性**：

$$\varphi_i(v_j) = \delta_{ij} = \begin{cases} 1, & i=j \\ 0, & i \neq j \end{cases}$$

## 2. 证明 $\varphi_1, \dots, \varphi_n$ 是 $V'$ 的一组基

要证明它们构成基，需要证明它们既线性无关，又能生成整个对偶空间 $V'$。

**第一步：证明线性无关**

令 $a_1 \varphi_1 + \dots + a_n \varphi_n = \mathbf{0}$ 。

将这个零映射作用于 $V$ 的第 $i$ 个基向量 $v_i$ 上：

$$0 = \mathbf{0}(v_i) = (a_1 \varphi_1 + \dots + a_n \varphi_n)(v_i)$$

$$= a_1 \varphi_1(v_i) + \dots + a_i \varphi_i(v_i) + \dots + a_n \varphi_n(v_i)$$

因为只有 $\varphi_i(v_i) = 1$，其余均为 $0$，所以上式化简为：

$$0 = a_i$$

由于 $i$ 是任意的 ($i = 1, \dots, n$)，故所有的系数 $a_i$ 都为 0。证明了它们线性无关。

**第二步：证明生成性**

对于对偶空间中任意的一个泛函 $\forall \varphi \in V' = \mathcal{L}(V, \mathbb{F})$，我们断言它可被表示为：

$$\varphi = \varphi(v_1)\varphi_1 + \varphi(v_2)\varphi_2 + \dots + \varphi(v_n)\varphi_n = \sum_{i=1}^n \varphi(v_i)\varphi_i$$

_验证_：将等式两边同时作用于基向量 $v_j$：

左边 $= \varphi(v_j)$

右边 $= \varphi(v_1)\varphi_1(v_j) + \dots + \varphi(v_j)\varphi_j(v_j) + \dots + \varphi(v_n)\varphi_n(v_j) = \varphi(v_j)$

由于等式两边的映射在基向量上的取值完全相同，根据线性映射的唯一性，这两个映射完全相等。这证明了 $\varphi_1, \dots, \varphi_n$ 能够生成 $V'$。

**结论**：$\varphi_1, \dots, \varphi_n$ 构成了对偶空间 $V'$ 的一组基，称为 $v_1, \dots, v_n$ 的**对偶基**。

## 3. 对偶基的例子与反例

- **标准空间的对偶基**：对于 $\mathbb{F}^n$，设其标准基为 $e_1, \dots, e_n$。其对偶基 $\varphi_1, \dots, \varphi_n$ 的作用是：
    
    $$\varphi_i(x_1, x_2, \dots, x_n) = x_i$$
    
    也就是常见的“坐标函数”。
    
- **无限维情况下的反例** `(*)`：前述结论仅在有限维成立。设 $V = \mathbb{R}[x]$（无限维空间），基为 $1, x, \dots, x^n, \dots$
    
    如果定义 $\varphi_i(x^j) = \delta_{ij}$，那么这些 $\varphi_i$ 生成的子空间 $\text{Span}(\{\varphi_i \mid i=0, 1, \dots\}) \neq V'$。
    
    _反例证明_：考察积分泛函 $\varphi(f(x)) = \int_0^1 f(x)dx$。如果它能由有限个 $\varphi_i$ 表出（$\varphi = \sum_{i=0}^n a_i \varphi_i$），它对 $x^k$ ($k > n$) 的作用应为 0，但这与 $\int_0^1 x^k dx = \frac{1}{k+1} \neq 0$ 矛盾。这说明无限维空间的对偶空间比对偶基生成的空间“大”得多。

# 三、 对偶映射

## 1. 映射定义

对于任意一个线性映射 $T \in \mathcal{L}(V, W)$，我们可以诱导出一个对应的映射 $T'$，从 $W$ 的对偶空间映射回 $V$ 的对偶空间：

$$T': W' \to V'$$

- **定义法则**：对于任意的 $\varphi \in W'$，$T'(\varphi)$ 被定义为一个复合映射：
    
    $$T'(\varphi) \triangleq \varphi \circ T$$
    
    （由于 $T: V \to W$，$\varphi: W \to \mathbb{F}$，因此复合映射 $\varphi \circ T: V \to \mathbb{F}$，这恰好是 $V$ 上的一个线性泛函，即属于 $V'$）。
    

## 2. $T'$ 是线性映射的证明

对于标量 $\lambda_1, \lambda_2 \in \mathbb{F}$ 以及泛函 $\varphi_1, \varphi_2 \in W'$：

$$T'(\lambda_1 \varphi_1 + \lambda_2 \varphi_2) = (\lambda_1 \varphi_1 + \lambda_2 \varphi_2) \circ T$$

$$= \lambda_1(\varphi_1 \circ T) + \lambda_2(\varphi_2 \circ T)$$

$$= \lambda_1 T'(\varphi_1) + \lambda_2 T'(\varphi_2)$$

这证明了 $T'$ 也是一个线性映射。

## 3. 对偶映射的实例分析

设微分算子映射 $D: \mathcal{P}(\mathbb{R}) \to \mathcal{P}(\mathbb{R})$，定义为求导 $D(p(x)) = p'(x)$。

我们来考察它的对偶映射 $D': \mathcal{P}(\mathbb{R})' \to \mathcal{P}(\mathbb{R})'$。

- **情况 a**：设 $\varphi \in \mathcal{P}(\mathbb{R})'$ 定义为点值计算：$\varphi(p(x)) = p(3)$。
    
    计算对偶映射作用于它：
    
    $$D'(\varphi)(p) = (\varphi \circ D)(p) = \varphi(D(p)) = \varphi(p'(x)) = p'(3)$$
    
- **情况 b**：设 $\varphi$ 定义为定积分：$\varphi(p(x)) = \int_0^1 p(x)dx$。
    
    计算对偶映射作用于它：
    
    $$D'(\varphi)(p) = (\varphi \circ D)(p) = \varphi(D(p)) = \varphi(p'(x)) = \int_0^1 p'(x)dx = p(1) - p(0)$$

# 四、 对偶映射的代数性质

对偶映射操作本身具有非常完美的代数同构性质。设 $S, T \in \mathcal{L}(V, W)$，映射 $S \mapsto S'$ 是一个从 $\mathcal{L}(V, W)$ 到 $\mathcal{L}(W', V')$ 的线性映射，且满足以下性质：

## 性质 1: 加法保持

$$(S + T)' = S' + T'$$

**证明**：对于 $\forall \varphi \in W'$，

$$(S+T)'(\varphi) = \varphi \circ (S+T) = \varphi \circ S + \varphi \circ T = S'(\varphi) + T'(\varphi) = (S'+T')(\varphi)$$

## 性质 2: 数乘保持

$$(\lambda S)' = \lambda S'$$


## 性质 3: 复合映射的逆序律

若有复合映射 $V \xrightarrow{T} W \xrightarrow{S} U$，则其对偶映射满足：

$$(S \circ T)' = T' \circ S'$$

_(注意：对偶操作会反转复合的顺序。因为 $U' \xrightarrow{S'} W' \xrightarrow{T'} V'$)_

**证明**：对于 $\forall \varphi \in U'$，

$$(S \circ T)'(\varphi) = \varphi \circ (S \circ T)$$

由于映射的复合满足结合律：

$$= (\varphi \circ S) \circ T$$

根据对偶映射定义，内部的 $\varphi \circ S$ 等于 $S'(\varphi)$：

$$= S'(\varphi) \circ T$$

再次利用定义：

$$= T'(S'(\varphi)) = (T' \circ S')(\varphi)$$

因此，$(S \circ T)' = T' \circ S'$。证明完毕。

# 五、 零化子与对偶映射的深层关系

> 这部分内容揭示了原空间中的子空间与对偶空间中的子空间之间的联系，并探讨了线性映射及其对偶映射在“核”与“像”上的对称性。

## 1. 零化子的基本概念与实例

- **定义(零化子)**：
    
    设 $U$ 是线性空间 $V$ 的一个子集合 ($U \subseteq V$)。$U$ 的**零化子**记作 $U^0$，定义为：
    
    $$U^0 = \{\varphi \in V' \mid \varphi(u) = 0, \forall u \in U\}$$
    
    简而言之，$U^0$ 是 $V'$ 中使得 $U$ 内所有向量都被映射为 $0$ 的所有线性泛函的集合。
    
- **定理**：无论 $U$ 是否为子空间，其零化子 $U^0$ 必定是对偶空间 $V'$ 的一个子空间（即 $U^0 \le V'$）。
    
    _证明思路_：$\mathbf{0} \in U^0$ 显然成立。对于 $\forall \varphi_1, \varphi_2 \in U^0$ 及 $\forall u \in U$，有 $(\varphi_1 + \varphi_2)(u) = \varphi_1(u) + \varphi_2(u) = 0 + 0 = 0$。同理数乘也封闭。
    
- **零化子的具体计算实例**：
    
    - **多项式空间**：设 $U = x^2\mathbb{R}[x]$（即缺少常数项和一次项的多项式子空间）。考察泛函 $\varphi(p(x)) = p'(0)$ 是否属于 $U^0$。
        
        对于 $\forall p(x) \in U$，$p(x)$ 可表示为 $a_2x^2 + a_3x^3 + \dots$。其导数为 $p'(x) = 2a_2x + 3a_3x^2 + \dots$。代入 $x=0$ 得 $p'(0) = 0$。因此 $\varphi(p(x)) = 0$，证明了 $\varphi \in U^0$。
        
    - **标准空间**：设 $e_1, \dots, e_5$ 为 $\mathbb{R}^5$ 的标准基，$\varphi_1, \dots, \varphi_5$ 为对应的对偶基。令子空间 $U = \text{span}\{e_1, e_2\} = \{(x_1, x_2, 0, 0, 0) \mid x_i \in \mathbb{R}\}$。
        
        设 $\varphi = \sum_{i=1}^5 a_i \varphi_i \in U^0$。则对于 $\forall u \in U$：
        
        $$\left(\sum_{i=1}^5 a_i \varphi_i \right)(x_1, x_2, 0, 0, 0) = a_1 x_1 + a_2 x_2 = 0 \quad (\forall x_1, x_2 \in \mathbb{R})$$
        
        这要求 $a_1 = a_2 = 0$。从而得到 $U^0 = \text{span}\{\varphi_3, \varphi_4, \varphi_5\}$。
        

## 2. 零化子的维数公式

- **定理**：若 $V$ 为有限维空间 ($\dim V < \infty$)，且 $U \le V$，则有极其重要的维数公式：
    
    $$\dim V = \dim U + \dim U^0$$
    
    - **证法一：构造对偶基**
        
        设 $u_1, \dots, u_m$ 是 $U$ 的基，将其扩充为 $V$ 的基 $u_1, \dots, u_{m+n}$。设 $\varphi_1, \dots, \varphi_{m+n}$ 为其对偶基。
        
        可以证明后 $n$ 个对偶基向量 $\varphi_{m+1}, \dots, \varphi_{m+n}$ 恰好构成了 $U^0$ 的基。
        
        1. 根据对偶基性质，对于 $i \ge m+1$ 且 $1 \le j \le m$，$\varphi_i(u_j) = 0$，故这 $n$ 个泛函属于 $U^0$。
            
        2. 它们是线性无关的。
            
        3. 对于 $\forall \varphi \in U^0$，展开式 $\varphi = \sum_{k=1}^{m+n} \varphi(u_k)\varphi_k$ 中，由于 $\varphi$ 将 $U$ 中基向量均映射为 $0$（即 $k \le m$ 时 $\varphi(u_k)=0$），故前 $m$ 项消失，证明了这 $n$ 个对偶基向量能生成 $U^0$。
            
    - **证法二：运用包含映射**
        
        定义包含映射 $i: U \to V, i(u) = u$。考虑其对偶映射 $i': V' \to U'$，定义为 $i'(\varphi) = \varphi \circ i$。
        
        1. 考察 $i'$ 的核：$\text{null } i' = \{\varphi \in V' \mid \varphi \circ i = \mathbf{0}\} = \{\varphi \in V' \mid \varphi(u) = 0\} = U^0$。
            
        2. 考察 $i'$ 的像：$\text{range } i' = U'$（可通过直和分解构造原像证明其为满射）。
            
            对映射 $i'$ 应用秩-零化度定理：$\dim V' = \dim(\text{null } i') + \dim(\text{range } i')$。
            
            即 $\dim V' = \dim U^0 + \dim U'$。由于对偶空间维数等于原空间维数，即证 $\dim V = \dim U^0 + \dim U$。
            

## 3. 线性映射与对偶映射的关联

设 $V, W$ 均为有限维线性空间，且 $T \in \mathcal{L}(V, W)$。

- **定理：对偶映射核的性质**
    
    - **(a) 关系式**：$\text{null } T' = (\text{range } T)^0$
        
        _($T'$ 的零空间等于 $T$ 的值域的零化子)_。
        
        **证明**：
        
        $(\Rightarrow)$ 若 $\varphi \in \text{null } T'$，则 $T'(\varphi) = \varphi \circ T = \mathbf{0}$。这意味着对 $\forall v \in V, \varphi(T(v)) = 0$，即 $\varphi(\text{range } T) = 0$，因此 $\varphi \in (\text{range } T)^0$。
        
        $(\Leftarrow)$ 若 $\varphi \in (\text{range } T)^0$，则对于所有形如 $w = Tv$ 的向量，$\varphi(w) = 0$。即 $(\varphi \circ T)(v) = 0$，故 $T'(\varphi) = \mathbf{0}$，得 $\varphi \in \text{null } T'$。
        
    - **(b) 维数公式**：$\dim(\text{null } T') = \dim(\text{null } T) + \dim W - \dim V$
        
        **推导**：
        
        根据结论 (a) 以及零化子维数公式：$\dim(\text{null } T') = \dim((\text{range } T)^0) = \dim W - \dim(\text{range } T)$。
        
        再结合 $T$ 的秩-零化度定理 ($\dim(\text{range } T) = \dim V - \dim(\text{null } T)$) 代入，即可直接得到该公式。
    
- **定理：单满射的对偶等价性**
    
    **命题**：原映射 $T$ 是满射 $\iff$ 对偶映射 $T'$ 是单射。
    
    **推导**：
    
    根据单射的等价条件，$T'$ 是单射 $\iff \text{null } T' = \{\mathbf{0}\}$。
    
    应用定理 对偶映射核的性质 (a)，上述条件等价于 $(\text{range } T)^0 = \{\mathbf{0}\}$。
    
    在有限维空间中，一个子空间的零化子只含有零元素，当且仅当该子空间是整个目标空间，即 $\text{range } T = W$。
    
    这正是 $T$ 为满射的定义。得证。
    
- **定理：对偶映射像的性质**
    
    设 $V, W$ 均为有限维线性空间，且 $T \in \mathcal{L}(V, W)$。
    
    - **(a) 维数相等性质**：对偶映射的秩等于原映射的秩。
        
        $$\dim(\text{range } T') = \dim(\text{range } T)$$
        
        **证明**：
        
        利用线性映射的秩-零化度定理：$\dim(\text{range } T') = \dim W' - \dim(\text{null } T')$。
        
        由定理 对偶映射核的性质 (a) 知 $\text{null } T' = (\text{range } T)^0$，故：
        
        $= \dim W - \dim((\text{range } T)^0)$
        
        根据零化子维数公式，$\dim W - \dim(U^0) = \dim U$，将 $U$ 替换为 $\text{range } T$，直接得到：
        
        $= \dim(\text{range } T)$。
        
    - **(b) 空间关系式**：对偶映射的值域，等于原映射零空间的零化子。
        
        $$\text{range } T' = (\text{null } T)^0$$
        
        **证明**：
        
        **方法一：基于维数的快捷证明**
        
        首先证明 $\text{range } T' \subseteq (\text{null } T)^0$：
        
        对于 $\forall \varphi \in \text{range } T'$，根据像的定义，存在 $\psi \in W'$ 使得 $\varphi = T'(\psi) = \psi \circ T$。
        
        我们要证明 $\varphi$ 属于 $(\text{null } T)^0$，即证明对于 $\forall v \in \text{null } T$，$\varphi(v) = 0$：
        
        $$\varphi(v) = (\psi \circ T)(v) = \psi(T(v)) = \psi(\mathbf{0}) = 0$$
        
        这说明 $\varphi$ 确实零化了 $\text{null } T$，故 $\text{range } T' \subseteq (\text{null } T)^0$ 成立。
        
        接着比较两边的维数：
        
        左边维数：$\dim(\text{range } T') = \dim(\text{range } T) = \dim V - \dim(\text{null } T)$。
        
        右边维数：$\dim((\text{null } T)^0) = \dim V - \dim(\text{null } T)$。
        
        因为一个是另一个的子空间，且维数相等，所以在有限维空间中两者必然相等。
        
        **方法二：基于直和分解的构造性证明（映射本质）**
        
        不用维数公式，直接构造证明！即对于 $\forall \varphi \in (\text{null } T)^0$，我们要硬凑出一个 $\psi \in W'$，使得 $\varphi = T'(\psi) = \psi \circ T$。
        
        **步骤 1：空间的直和分解**
        
        将目标空间 $W$ 分解为 $T$ 的像空间与另一个子空间 $U$ 的直和：
        
        $$W = (\text{range } T) \oplus U$$
        
        这意味着 $W$ 中的任意向量都可以唯一地表示为 $Tv + u$ 的形式（其中 $v \in V, u \in U$）。
        
        **步骤 2：构造映射 $\psi$**
        
        定义 $\psi : W \to \mathbb{F}$，其规则为：
        
        $$\psi(Tv + u) = \varphi(v)$$
        
        我们需要验证这个定义是否是良定义的。因为同一个 $Tv$ 对应的 $v$ 可能不唯一（当 $T$ 不是单射时）。如果 $Tv_1 + u_1 = Tv_2 + u_2$，必须保证算出来的结果 $\varphi(v_1) = \varphi(v_2)$。
        
        推导：$Tv_1 - Tv_2 = u_2 - u_1$。因为是直和，左右两边分别属于 $\text{range } T$ 和 $U$，交集只有零向量，所以：
        
        $$T(v_1 - v_2) = \mathbf{0} \implies v_1 - v_2 \in \text{null } T$$
        
        因为前提是 $\varphi \in (\text{null } T)^0$，所以 $\varphi$ 能够零化这个差值：
        
        $$\varphi(v_1 - v_2) = 0 \implies \varphi(v_1) = \varphi(v_2)$$
        
        这完美地证明了 $\psi$ 的定义是无歧义的！
        
        **步骤 3：验证线性性质与结论**
        
        可以验证 $\psi$ 是一个线性泛函（即 $\psi \in W'$）：
        
        $$\psi(\lambda_1(Tv_1+u_1) + \lambda_2(Tv_2+u_2)) = \psi(T(\lambda_1v_1+\lambda_2v_2) + (\lambda_1u_1+\lambda_2u_2)) $$
        $$= \varphi(\lambda_1v_1+\lambda_2v_2) = \dots = \lambda_1\psi(\dots) + \lambda_2\psi(\dots)$$
        
        最后，验证它是否满足 $T'(\psi) = \varphi$：
        
        对于 $\forall v \in V$，$T'(\psi)(v) = \psi(T(v)) = \psi(T(v) + \mathbf{0}) = \varphi(v)$。
        
        构造成功，彻底证明了 $(\text{null } T)^0 \subseteq \text{range } T'$。
        
- **满单射的彻底对称**
	
	结合前面的定理，我们得到了一个非常优美、完全对称的等价关系：
	
	- 由对偶映射核的性质：$T$ 是满射 $\iff T'$ 是单射。
	    
	- 由对偶映射像的性质：$T$ 是单射 $\iff T'$ 是满射。
	    
	
	**单射推满射的证明逻辑：**
	
	$T$ 是单射
	
	$\iff \text{null } T = \{\mathbf{0}\}$
	
	$\iff (\text{null } T)^0 = V'$ _(零空间的零化子就是整个对偶空间)_
	
	根据定理 对偶映射像的性质 (b)，$(\text{null } T)^0 = \text{range } T'$。
	
	因此，$\text{range } T' = V'$ $\iff T'$ 是满射。

# 六、 对偶映射的矩阵表示：转置的实质

> **在有限维空间中，对偶映射的本质就是矩阵转置。**

## 1. 矩阵转置的定义

板书中引入了记号，将对偶映射的矩阵表示与原矩阵的转置联系起来：

$$A^T := A'$$

_(注：这里 $A'$ 表示矩阵 $A$ 所代表的线性映射的对偶映射对应的矩阵，它正好等于 $A$ 的转置 $A^T$。)_

## 2. 代数性质的对应

对偶映射的复合逆序律 $(S \circ T)' = T' \circ S'$。

将其翻译成矩阵语言，就是矩阵乘法转置法则：

$$(AC)' = C'A' \quad \text{即} \quad (AC)^T = C^T A^T$$

## 3. 对偶映射矩阵表示的证明

**命题**：设 $T \in \mathcal{L}(V, W)$。设 $T$ 在某组基下的矩阵表示为 $A$，其对偶映射 $T'$ 在对应对偶基下的矩阵表示为 $B$。证明 $B = A^T$（即 $b_{ji} = a_{ij}$ 对于 $\forall i, j$ 成立）。

**推导过程**：

**第一步：设定基、对偶基与矩阵表示**

- 设 $\alpha_1, \dots, \alpha_n$ 是空间 $V$ 的一组基，$\beta_1, \dots, \beta_m$ 是空间 $W$ 的一组基。
    
- 设它们对应的对偶基分别为 $\alpha_1', \dots, \alpha_n' \in V'$ 和 $\beta_1', \dots, \beta_m' \in W'$。
    
- 定义映射 $T$ 的矩阵为 $A = (a_{ij})_{m \times n}$。根据定义，这意味着将 $T$ 作用于 $V$ 的第 $j$ 个基向量时，有：
    
    $$T\alpha_j = (\beta_1, \dots, \beta_m) \begin{pmatrix} a_{1j} \\ \vdots \\ a_{mj} \end{pmatrix} = \sum_{k=1}^m a_{kj} \beta_k$$
    
- 同理，定义对偶映射 $T'$ 的矩阵为 $B = (b_{ij})_{n \times m}$。这意味着将 $T'$ 作用于 $W'$ 的第 $i$ 个对偶基向量时，有：
    
    $$T'(\beta_i') = (\alpha_1', \dots, \alpha_n') \begin{pmatrix} b_{1i} \\ \vdots \\ b_{ni} \end{pmatrix} = \sum_{k=1}^n b_{ki} \alpha_k'$$
    

**第二步：通过对偶基的性质建立等式两端**

将对偶空间中的泛函 $T'(\beta_i')$ 作用于原空间的基向量 $\alpha_j$ 上。用两种不同的路径来计算这个值。

- **路径一：利用矩阵 $B$ 的展开式**
    
    将上面得到的 $T'(\beta_i')$ 展开式直接作用于 $\alpha_j$：
    
    $$T'(\beta_i')(\alpha_j) = \left( \sum_{k=1}^n b_{ki} \alpha_k' \right) (\alpha_j) = \sum_{k=1}^n b_{ki} \alpha_k'(\alpha_j)$$
    
    根据对偶基的 Kronecker Delta 性质（只有当 $k=j$ 时 $\alpha_k'(\alpha_j) = 1$，其余为 0），该求和式中仅保留下第 $j$ 项：
    
    $$T'(\beta_i')(\alpha_j) = b_{ji}$$
    
- **路径二：利用对偶映射的定义与矩阵 $A$**
    
    根据对偶映射的定义法则 $T'(\varphi) \triangleq \varphi \circ T$，我们有：
    
    $$T'(\beta_i')(\alpha_j) = (\beta_i' \circ T)(\alpha_j) = \beta_i'(T\alpha_j)$$
    
    现在，将第一步中 $T\alpha_j$ 的展开式代入：
    
    $$\beta_i'(T\alpha_j) = \beta_i' \left( \sum_{k=1}^m a_{kj} \beta_k \right) = \sum_{k=1}^m a_{kj} \beta_i'(\beta_k)$$
    
    同样利用对偶基的 Kronecker Delta 性质（只有当 $k=i$ 时 $\beta_i'(\beta_k) = 1$，其余为 0），求和式中仅保留下第 $i$ 项：
    
    $$\beta_i'(T\alpha_j) = a_{ij}$$
    

**第三步：得出结论**

因为无论通过哪种路径，计算的都是同一个对象 $T'(\beta_i')(\alpha_j)$，所以两端必须相等：

$$b_{ji} = a_{ij}$$

这说明矩阵 $B$ 的第 $j$ 行第 $i$ 列的元素，正好等于矩阵 $A$ 的第 $i$ 行第 $j$ 列的元素。这正是矩阵转置的严格定义。因此，从代数上严密地证明了：

$$B = A^T$$

## 4. 对偶理论的应用：矩阵行秩与列秩的相等性

**推导过程**：

1. **维数定理**：
    $$\dim(\text{range } T) = \dim(\text{range } T')$$
    
2. **映射秩与矩阵秩的等价性**：线性映射值域的维数，就等于其对应矩阵的秩（记作 $r(A)$）。因此：
    
    $$r(A) = \dim(\text{range } T)$$
    
3. **对偶映射的矩阵秩**：同理，对偶映射 $T'$ 对应的矩阵是 $A'$（即 $A^T$），因此它的秩对应于：
    
    $$r(A') = \dim(\text{range } T')$$
    
4. **得出结论**：
    
    由于 $\dim(\text{range } T) = \dim(\text{range } T')$ 成立，直接将矩阵秩代入，便得到了：
    
    $$r(A) = r(A')$$
    
    即 $r(A) = r(A^T)$。
    

- 矩阵的行秩与列秩之所以相等，是由于**原空间映射的值域维数必然等于其对偶空间映射的值域维数**这一几何与代数对称性决定的。
