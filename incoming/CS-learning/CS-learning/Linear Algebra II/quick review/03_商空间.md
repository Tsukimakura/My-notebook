## 一、 陪集与商空间的代数结构

- **陪集 (Coset)**：设 $U$ 是 $V$ 的子空间，对任意 $v \in V$，其陪集定义为 $v + U = \{v + u \mid u \in U\}$。
    
- **陪集等价条件**：两个陪集相等 $v_1 + U = v_2 + U \iff v_1 - v_2 \in U$。
    
- **商空间**：由所有陪集构成的集合称为 $V$ 模 $U$ 的商空间，记作 $V/U = \{v + U \mid v \in V\}$。
    
- **商空间的线性运算**：加法定义为 $(a + U) + (b + U) = (a + b) + U$。
    
- **商空间的数乘**：数乘定义为 $\lambda(a + U) = \lambda a + U$。
    
- **商空间的零元素**：零元素即为子空间 $U$ 本身（即 $0 + U$）。

## 二、 自然映射及其性质

- **自然映射定义**：定义映射 $\pi : V \to V/U$，规则为 $\pi(v) = v + U$。
    
- **线性性质**：$\pi$ 必定是一个线性映射。
    
- **满射性质**：$\pi$ 的像空间为整个商空间，即 $\text{range } \pi = V/U$。
    
- **核空间**：自然映射的核为原空间的子空间 $U$，即 $\ker \pi = U$。
    

---

## 三、 商空间的维数公式

- **维数关系**：商空间的维数等于原空间维数减去子空间维数，公式为 $\dim V/U = \dim V - \dim U$。

## 四、 诱导映射与第一同构定理

- **诱导映射定义**：设 $T$ 是从 $V$ 到 $W$ 的线性映射，定义诱导映射 $\tilde{T}: V/\text{null } T \to W$，其作用规则为 $\tilde{T}(v + \text{null } T) = Tv$。
    
- **$\tilde{T}$ 的映射性质**：诱导映射 $\tilde{T}$ 是一个良定义的线性映射。
    
- **单射性质**：$\tilde{T}$ 必然是一个单射，其核只包含零元。
    
- **值域等价**：诱导映射的值域等于原映射的值域，即 $\text{range } \tilde{T} = \text{range } T$。
    
- **第一同构定理**：商空间与原映射的像空间线性同构，即 $V/\text{null } T \cong \text{range } T$。
    
- **秩-零化度定理**：由第一同构定理的维数相等关系，可直接得出核心公式 $\dim V = \dim(\text{null } T) + \dim(\text{range } T)$。
