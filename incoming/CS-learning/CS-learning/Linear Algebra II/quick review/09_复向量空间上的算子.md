## 一、 零空间理论与多项式基础

### 1. 零空间的升链与稳定性质

- **升链性质**：算子 $T$ 的幂次零空间构成升链：$\{0\} \subseteq \text{null } T \subseteq \text{null } T^2 \subseteq \dots$
    
- **稳定点**：若存在 $m$ 使得 $\text{null } T^m = \text{null } T^{m+1}$，则后续所有零空间不再扩大：$\text{null } T^m = \text{null } T^{m+k} \ (\forall k \ge 0)$。
    
- **直和分解**：在零空间稳定点 $k$ 处，全空间可分解为：**$V = \text{null } T^k \oplus \text{range } T^k$**。
    

### 2. 多项式最大公因式引理

- 若 $d(x)$ 是多项式组 $f_1(x), \dots, f_m(x)$ 的最大公因式，则必定存在多项式 $u_i(x)$，使得它们满足**裴蜀等式**：
    
    $$u_1(x)f_1(x) + \dots + u_m(x)f_m(x) = d(x)$$
    

## 二、 广义特征空间与不变子空间

### 1. 广义特征空间 $G(\lambda, T)$

- **定义**：$G(\lambda, T) = \{ v \in V \mid \text{存在 } k \text{ 使得 } (T-\lambda I)^k v = 0 \}$。
    
- **维数定理**：$\dim G(\lambda_i, T)$ = 特征值 $\lambda_i$ 的**代数重数**。
    
- **线性无关性**：不同特征值对应的广义特征向量绝对线性无关。
    

### 2. 全空间的准素分解 (Primary Decomposition)

- 若算子的极小多项式为 $p(x) = \prod (x-\lambda_i)^{n_i}$，则全空间可完美分解为各广义特征空间的直和：
    
    **$V = G(\lambda_1, T) \oplus G(\lambda_2, T) \oplus \dots \oplus G(\lambda_s, T)$**
    
- **子空间性质**：
    
    1. 每个 $G(\lambda_i, T)$ 都是 **$T$-不变子空间**。
        
    2. 限制算子 $(T - \lambda_i I)$ 在 $G(\lambda_i, T)$ 上是**幂零算子**。
        
    3. 算子 $T$ 限制在 $G(\lambda_i, T)$ 上，可表示为对角线全为 $\lambda_i$ 的**上三角矩阵**。全空间上则呈现**分块对角矩阵**。
        

### 3. 多项式算子的不变性

对于任意多项式 $p(x)$，子空间 $\text{range } p(T)$ 和 $\text{null } p(T)$ 必定是 **$T$-不变的**。

## 三、 特征多项式与极小多项式

### 1. 特征多项式 (Characteristic Polynomial)

- **定义**：$q(z) = \prod (z-\lambda_i)^{n_i}$，其中 $n_i$ 为代数重数（即 $\dim G(\lambda_i, T)$）。
    
- **凯莱-哈密顿定理 (Cayley-Hamilton Theorem)**：算子必然零化其自身的特征多项式，即 **$q(T) = \mathbf{0}$**。
    

### 2. 极小多项式 (Minimal Polynomial)

- **零化判定**：$q(T) = 0 \iff$ 极小多项式 $p(x)$ 是 $q(x)$ 的因式（即 $p$ 整除 $q$）。
    
- **与特征值的关系**：
    
    - 极小多项式与特征多项式拥有**完全相同的零点**（即全部特征值）。
        
    - 特征多项式是极小多项式的倍式。
        
- **阶数规律（极重要）**：
    
    在极小多项式中，因子 $(z - \lambda_i)$ 的指数 $k_i$，**严格等于**该特征值 $\lambda_i$ 对应的**最大若尔当块（Jordan Block）的阶数**。
    
    _(注：对角矩阵的最大若尔当块阶数均为1，故其极小多项式无重根。)_
    

## 四、 幂零算子与 Jordan 标准型

### 1. 幂零算子 (Nilpotent Operator)

- **定义**：存在正整数 $n$ 使得 $N^n = 0$。若 $\dim V = k$，必有 $N^k = 0$。
    
- **特征值**：幂零算子的所有特征值**严格为 0**。
    

### 2. Jordan 链与 Jordan 块

- **Jordan 链**：从生成元 $v$ 倒序迭代至零向量的序列 $B_v = \{N^m v, N^{m-1}v, \dots, Nv, v\}$，张成 $N$-循环子空间。
    
- **Jordan 块矩阵**：在此基底（Jordan 基）下，算子矩阵的**主对角线全为 0，次上方超对角线全为 1**。
    

### 3. Jordan 标准型 (JCF)

对于一般算子，由于 $T|_{U_i} = \lambda_i I + N_i$（纯量算子+幂零算子），在全空间的 Jordan 基下，其矩阵化为分块对角矩阵。每个块为 Jordan 块：**主对角线全为 $\lambda_i$，超对角线全为 1**。

## 五、 循环子空间与友矩阵 (Companion Matrix)

- **循环子空间构造**：由 $\{e_1, Te_1, T^2e_1, \dots, T^{m-1}e_1\}$ 线性无关向量张成的 $m$ 维 $T$-不变子空间。
    
- **多项式方程**：必然存在首一多项式 $p(x) = x^m + a_{m-1}x^{m-1} + \dots + a_0$，使得 $p(T)e_1 = \mathbf{0}$。这是该限制算子的极小与特征多项式。
    
- **友矩阵结构**：在循环基下，矩阵形式固定且极度标准：
    
    - 次下方（主对角线下一条）全为 $1$；
        
    - **最后一列**由多项式系数的相反数构成 $(-a_0, -a_1, \dots, -a_{m-1})^T$；
        
    - 其余全为 $0$。
        

## 六、 补充扩展（实数域与级数展开）

### 1. 实数域 $\mathbb{R}$ 上的特异性

实多项式不可约分解含二次因式 $(x^2+bx+c)$（且 $b^2 < 4c$）。在矩阵表示中，二次因式零空间对应的不变子空间不再是单一特征值，而是体现为 $2 \times 2$ 基础旋转/缩放矩阵块（如 $\begin{pmatrix} a & -b \\ b & a \end{pmatrix}$）。

### 2. 算子的泰勒级数展开（求平方根）

形如 $\sqrt{I+N}$（$N$ 为幂零算子）可利用泰勒展开精确求值：

$$(I+N)^{1/2} = I + \frac{1}{2}N - \frac{1}{8}N^2 + \dots$$

**核心依据**：由于 $N$ 是幂零的，无穷级数必定在有限项后截断，变为有限多项式的严格等式。此方法可用于计算正算子的平方根（提取特征值 $\lambda_i$ 后转化为幂零算子展开）。
