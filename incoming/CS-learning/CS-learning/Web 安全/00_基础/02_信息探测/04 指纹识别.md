> 计算机指纹识别与常见指纹识别相通。如，某 CMS 存在一个特征，在根目录下会存在 “dxs.txt”，其内容为 dxs v1.0，这个特征就相当于 CMS 的指纹，在碰到其他网站时也存在此特征，就能快速识别这一 CMS。

- CMS：Content Management System，内容管理系统。一个无需编写代码，就能让用户方便地创建、管理和发布数字内容（主要是网页内容）的软件平台。

- 计算机的指纹识别包括针对网站 CMS 的指纹识别、针对服务器操作系统的指纹识别、对 Web 容器的指纹识别等。

- `nmap -O` 就是针对操作系统进行的指纹识别，一些端口提供的具体服务也可以使用 `nmap -A` 来识别

- 有指纹识别就有指纹伪造。

- 指纹识别是必要的。比如识别出网站的系统，就可以去查询该系统的相关漏洞，便于接下来的操作。

- 指纹识别最重要的是特征库。

- AppPrint 是一款 Web 容器指纹识别工具，可针对单个 IP、域名或 IP 段 进行 Tomcat、WebLogic、WebSphere、IIS 等 Web 容器识别。HTTP 请求中 Server 头的 Web 容器信息可以直接伪造，AppPrint 不直接通过 Server 头获取，而是通过指纹识别，指纹都保存在 AppPrint 目录下的 signatures.txt 中。
