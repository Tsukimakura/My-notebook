## 一、 基本概念

**1. 一般形式与标准形式**

- **一般形式**（展开中心为 $x_0$）：$\sum_{n=0}^\infty a_n(x-x_0)^n$
    
- **标准形式**（展开中心为 $0$）：$\sum_{n=0}^\infty a_n x^n$
    
- $a_n$ 为幂级数的系数。一般通过平移变换 $t = x - x_0$ 将一般形式化为标准形式研究。
    

---

## 二、 敛散性与收敛域求解

**1. 阿贝尔第一定理（收敛域结构）**

- 若 $\sum_{n=0}^\infty a_n x^n$ 在 $x = \xi \ (\xi \neq 0)$ 处收敛，则在 $|x| < |\xi|$ 处**绝对收敛**。
    
- 若在 $x = \eta$ 处发散，则在 $|x| > |\eta|$ 处必**发散**。
    

**2. 收敛半径 $R$ 的计算**

设 $A = \lim_{n \to \infty} \sqrt[n]{|a_n|}$（根值法） 或 $A = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right|$（比值法）：

- $A = 0 \implies R = +\infty$（在 $(-\infty, +\infty)$ 绝对收敛）
    
- $0 < A < +\infty \implies R = \frac{1}{A}$
    
- $A = +\infty \implies R = 0$（仅在 $x=0$ 处收敛）
    
- _注：对于缺项级数，可直接对整个一般项 $u_n(x)$ 使用判别法求解。_
    

**3. 求解收敛域的标准策略**

1. 计算收敛半径 $R$。
    
2. 写出开区间（收敛区间） $(-R, R)$。
    
3. **必须单独代入并判断左右两个端点**（$x = R$ 和 $x = -R$）的敛散性，确定最终收敛域。

## 三、 幂级数的分析性质

**1. 阿贝尔第二定理与一致收敛性**

- **内闭一致收敛**：在收敛开区间 $(-R, R)$ 内的任意闭子区间 $[-r, r]$ 上一致收敛。
    
- **端点延拓**：若级数在端点 $x = R$ (或 $-R$) 处收敛，则在 $[0, R]$ (或 $[-R, 0]$) 上一致收敛。
    

**2. 和函数 $f(x)$ 的三大性质**

设 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛半径 $R > 0$，和函数为 $f(x)$：

- **连续性**：$f(x)$ 在其**整个收敛域**上连续。
    
- **逐项可积性**：在收敛域内的任意闭区间上可逐项积分。**积分后收敛半径 $R$ 不变**（但端点可能由发散变为收敛）。
    
- **逐项可导性**：在收敛开区间 $(-R, R)$ 内可无限次逐项求导。**求导后收敛半径 $R$ 不变**（但端点可能由收敛变为发散）。且 $a_n = \frac{f^{(n)}(0)}{n!}$。

## 四、 幂级数的代数运算与唯一性

**1. 代数运算**

设 $\sum a_n x^n$ 和 $\sum b_n x^n$ 的收敛半径分别为 $R_a, R_b$，令 $R = \min\{R_a, R_b\}$。在 $|x| < R$ 内：

- **线性运算**：$\sum ( \lambda a_n \pm \mu b_n ) x^n = \lambda \sum a_n x^n \pm \mu \sum b_n x^n$
    
- **柯西乘积**：$(\sum a_n x^n)(\sum b_n x^n) = \sum c_n x^n$，其中 $c_n = \sum_{k=0}^n a_k b_{n-k}$。
    
- _阿贝尔应用_：若常数项级数 $\sum a_n, \sum b_n, \sum c_n$ 均收敛，且 $c_n$ 满足上述卷积，则 $\sum c_n = (\sum a_n)(\sum b_n)$。
    

**2. 唯一性定理**

- 若两幂级数在 $x=0$ 的某邻域内和函数相同，则对应系数必完全相等（$a_n = b_n$）。
    
- **奇偶性推论**：若和函数为奇函数，则偶次项系数 $a_{2n} = 0$；若为偶函数，则奇次项系数 $a_{2n+1} = 0$。

## 五、 泰勒展开理论

**1. 展开的充要条件与充分条件**

- **充要条件**：$f(x)$ 展开为泰勒级数的充要条件是泰勒余项的极限为零，即 $\lim_{n \to \infty} R_n(x) = 0$。
    
- **充分条件（导数一致有界）**：若在 $U(x_0, r)$ 内存在常数 $M > 0$，使得对足够大的 $n$ 恒有 $|f^{(n)}(x)| \le M$，则 $f(x)$ 可展开。
    

**2. 麦克劳林多项式的三种余项（$x_0 = 0$）**

- **拉格朗日型**：$R_n(x) = \frac{f^{(n+1)}(\theta x)}{(n+1)!} x^{n+1}, \quad 0 < \theta < 1$
    
- **柯西型**：$R_n(x) = \frac{1}{n!} f^{(n+1)}(\theta x) (1-\theta)^n x^{n+1}, \quad 0 < \theta < 1$
    
- **积分型**：$R_n(x) = \frac{1}{n!} \int_0^x f^{(n+1)}(t)(x-t)^n dt$

## 六、 常见初等函数麦克劳林展开式

|**函数 f(x)**|**展开式**|**收敛域**|
|---|---|---|
|$e^x$|$\sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \dots$|$(-\infty, +\infty)$|
|$\sin x$|$\sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!} x^{2n+1} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$|$(-\infty, +\infty)$|
|$\cos x$|$\sum_{n=0}^{\infty} \frac{(-1)^n}{(2n)!} x^{2n} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$|$(-\infty, +\infty)$|
|$\frac{1}{1+x}$|$\sum_{n=0}^{\infty} (-1)^n x^n = 1 - x + x^2 - x^3 + \dots$|$(-1, 1)$|
|$\ln(1+x)$|$\sum_{n=0}^{\infty} \frac{(-1)^n}{n+1} x^{n+1} = x - \frac{x^2}{2} + \frac{x^3}{3} - \dots$|$(-1, 1]$|
|$\arctan x$|$\sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1} x^{2n+1} = x - \frac{x^3}{3} + \frac{x^5}{5} - \dots$|$[-1, 1]$|
|$\arcsin x$|$x + \sum_{n=1}^{\infty} \frac{(2n-1)!!}{(2n)!!} \frac{x^{2n+1}}{2n+1}$|$[-1, 1]$|
|$(1+x)^\alpha$|$1 + \sum_{n=1}^{\infty} \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!} x^n$|见下方端点说明|

**关于 $(1+x)^\alpha$ 收敛域的补充说明**：

- 当 $\alpha \le -1$ 时，收敛域为 $(-1, 1)$
    
- 当 $-1 < \alpha < 0$ 时，收敛域为 $(-1, 1]$
    
- 当 $\alpha > 0$（且非整数）时，收敛域为 $[-1, 1]$
    
- 当 $\alpha$ 为自然数 $m$ 时，退化为二项式定理，收敛域为 $(-\infty, +\infty)$

## 七、 Weierstrass 逼近定理

设 $f(x)$ 在闭区间 $[a, b]$ 上连续，则必存在多项式序列 $\{P_n(x)\}$，使得当 $n \to \infty$ 时，$P_n(x)$ 在 $[a, b]$ 上**一致收敛**于 $f(x)$。
