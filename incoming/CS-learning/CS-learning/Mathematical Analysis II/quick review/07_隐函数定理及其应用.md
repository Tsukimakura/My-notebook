### 一、 一元隐函数定理

- **隐函数概念**：若方程 $F(x,y) = 0$ 在局部存在唯一对应的 $y = f(x)$ 使得 $F(x, f(x)) \equiv 0$，则称该方程确定了隐函数。
    
- **定理 1（存在唯一性与连续性）**：
    
    - **三大条件**：1. 初始条件 $F(x_0, y_0) = 0$；2. $F$ 及 $F_y$ 在邻域内连续；3. 偏导数非零 $F_y(x_0, y_0) \neq 0$。
        
    - **结论**：在局部存在唯一的隐函数 $y=f(x)$，且该隐函数连续。
        
- **定理 2（可微性与求导公式）**：
    
    - **附加条件**：函数 $F$ 存在连续的偏导数 $F_x(x,y)$。
        
    - **结论**：隐函数连续可导，一阶导数公式为 $f'(x) = -\frac{F_x(x,y)}{F_y(x,y)}$。
        
- **高阶导数求法**（求 $y''$）：
    
    - 方法一（公式法）：直接对 $-\frac{F_x}{F_y}$ 关于 $x$ 求导，注意 $y$ 也是 $x$ 的函数，必须使用复合函数求导法则。
        
    - 方法二（隐式求导法）：对恒等式 $F_x + F_y \cdot y' = 0$ 两边再次关于 $x$ 求导，解出 $y''$。
        

### 二、 多元隐函数定理

- **定理内容**：将一元推广至 $n$ 元方程 $F(x_1, \dots, x_n, y) = 0$。
    
- **条件**：初始点处 $F=0$、所有一阶偏导数连续，且对因变量的偏导数 $F_y \neq 0$。
    
- **结论与公式**：局部存在唯一连续可微的隐函数 $y = f(x_1, \dots, x_n)$。其偏导数公式为：$f_{x_i} = -\frac{F_{x_i}}{F_y}$。
    

### 三、 隐函数方程组定理

- **雅可比行列式定义**：$m$ 个函数 $F_1, \dots, F_m$ 对 $m$ 个变量 $y_1, \dots, y_m$ 的偏导数构成的行列式，记作 $J = \frac{\partial(F_1, \dots, F_m)}{\partial(y_1, \dots, y_m)}$。
    
- **存在与可微条件**：方程组初始值为0，各函数的所有偏导数连续，且关于待求因变量的雅可比行列式在初始点**不为零**（$J \neq 0$）。
    
- **结论**：局部唯一确定 $m$ 个连续可微的隐函数组 $y_k = f_k(x_1, \dots, x_n)$。
    
- **隐函数组偏导数求解（矩阵法 / 克莱姆法则）**：
    
    - 对恒等式组两边同时对 $x_j$ 求导，得到线性方程组。
        
    - 矩阵形式：$J_y(F) \cdot J_x(y) = -J_x(F)$。
        
    - 两方程系统（求 $u_x, v_x$）：利用克莱姆法则，$u_x = -\frac{\frac{\partial(F, G)}{\partial(x, v)}}{\frac{\partial(F, G)}{\partial(u, v)}}$， $v_x = -\frac{\frac{\partial(F, G)}{\partial(u, x)}}{\frac{\partial(F, G)}{\partial(u, v)}}$。
        

### 四、 逆映射定理

- **适用场景**：已知映射 $u = \varphi(x,y), v = \psi(x,y)$，求逆映射 $x=x(u,v), y=y(u,v)$。
    
- **存在条件**：映射具有连续一阶偏导数，且雅可比行列式 $J = \frac{\partial(\varphi, \psi)}{\partial(x, y)} \neq 0$。
    
- **逆映射偏导数公式**：$x_u = \frac{\psi_y}{J}, y_u = -\frac{\psi_x}{J}, x_v = -\frac{\varphi_y}{J}, y_v = \frac{\varphi_x}{J}$。
    

### 五、 隐函数定理的几何应用（切线与切平面）

**1. 曲线的切线与法平面/法线**

- **平面曲线 $F(x,y)=0$**：法向量为 $\vec{n} = (F_x, F_y)$。
    
    - 切线：$F_x(P_0)(x - x_0) + F_y(P_0)(y - y_0) = 0$。
        
    - 法线：$\frac{x-x_0}{F_x(P_0)} = \frac{y-y_0}{F_y(P_0)}$。
        
- **空间曲线（参数方程 $x(t), y(t), z(t)$）**：切向量为 $\vec{T} = (x', y', z')$。
    
- **空间曲线（两曲面交线 $F=0, G=0$）**：切向量是两曲面法向量的叉乘，即 $\vec{l} = \vec{n}_F \times \vec{n}_G = \left( \frac{\partial(F,G)}{\partial(y,z)}, \frac{\partial(F,G)}{\partial(z,x)}, \frac{\partial(F,G)}{\partial(x,y)} \right)$。
    
    - 切线方程：$\frac{x-x_0}{\frac{\partial(F,G)}{\partial(y,z)}} = \frac{y-y_0}{\frac{\partial(F,G)}{\partial(z,x)}} = \frac{z-z_0}{\frac{\partial(F,G)}{\partial(x,y)}}$。
        
    - 法平面方程：点法式展开 $\frac{\partial(F,G)}{\partial(y,z)}(P_0)(x-x_0) + \frac{\partial(F,G)}{\partial(z,x)}(P_0)(y-y_0) + \frac{\partial(F,G)}{\partial(x,y)}(P_0)(z-z_0) = 0$。
        

**2. 曲面的切平面与法线**

- **隐式曲面 $F(x,y,z)=0$**：法向量为梯度 $\vec{n} = (F_x, F_y, F_z)$。
    
    - 切平面：$F_x(P_0)(x - x_0) + F_y(P_0)(y - y_0) + F_z(P_0)(z - z_0) = 0$。
        
    - 法线：$\frac{x - x_0}{F_x(P_0)} = \frac{y - y_0}{F_y(P_0)} = \frac{z - z_0}{F_z(P_0)}$。
        
- **显式曲面 $z=f(x,y)$**：法向量转化为隐式得 $\vec{n} = (f_x, f_y, -1)$。
    
- **参数曲面 $x(u,v), y(u,v), z(u,v)$**：法向量为两条参数曲线切向量的叉积 $\vec{n} = \vec{T}_u \times \vec{T}_v$。
    

### 六、 条件极值与拉格朗日乘数法

- **问题形式**：在 $m$ 个约束条件 $\varphi_k(x_1, \dots, x_n) = 0$ 之下求目标函数 $f(x_1, \dots, x_n)$ 的极值。
    
- **拉格朗日函数构造**：$L = f + \sum_{k=1}^m \lambda_k \varphi_k$（$\lambda_k$ 为乘子）。
    
- **必要条件（求驻点）**：前提是约束条件的雅可比矩阵满秩。联立方程组求驻点：
    
    - 各变量偏导为零：$L_{x_i} = 0 \quad (1 \le i \le n)$。
        
    - 各乘子偏导为零（即原约束）：$\varphi_j = 0 \quad (1 \le j \le m)$。
        
- **充分条件判定**：通过考察拉格朗日函数 $L$ 关于自变量构成的海森矩阵（Hessian Matrix）的正负定性，来判定是极大值还是极小值。
