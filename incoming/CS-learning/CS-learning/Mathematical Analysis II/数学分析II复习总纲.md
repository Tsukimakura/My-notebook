## 第一篇：级数理论（从离散求和到函数全局逼近）

### 一、 数项级数与上下极限

处理常数数列的无限求和及其收敛性，是整体级数理论的基石。

1. **上下极限理论**
    
    - **定义**：利用聚点集合法，上极限为收敛子列极限的 $\sup E$，下极限为 $\inf E$。
        
    - **核心性质**：数列极限存在的充要条件是 $\varlimsup a_n = \varliminf a_n$。具有严格的保序性。
        
2. **敛散性基础理论**
    
    - **收敛本质**：级数收敛等价于部分和数列 $\{S_n\}$ 收敛 。
        
    - **【重点：证明核心】**：判定级数收敛时，务必先检查必要条件，即 $\lim_{n \to \infty} a_n = 0$ 。此外，柯西收敛准则常用于直接进行理论证明 。
        
3. **正项级数判别法**
    
    - **【重点：解题逻辑】**：正项级数收敛的充要条件是部分和数列有界 。这是证明收敛的首要策略。
        
    - **具体判别法**：比较判别法（寻找 $p$ 级数等基准）、比值法、根式法（Cauchy）、积分法 。
        
4. **一般项级数（任意项级数）判别法**
    
    - **交错级数**：莱布尼茨判别法（通项单调递减且趋于0） 。
        
    - **A-D判别法**：处理乘积形式 $\sum a_n b_n$。狄利克雷判别法（Dirichlet：部分和有界且单减趋0）、阿贝尔判别法（Abel：收敛且单调有界） 。
        
5. **绝对收敛与条件收敛**
    
    - 若原级数绝对值收敛则为绝对收敛，具备无条件交换律（Dirichlet重排定理）；若仅原级数收敛则为条件收敛，极其不稳定（Riemann重排定理） 。柯西乘积在绝对收敛时具有最高自由度 。
        

### 二、 函数列与函数项级数

从常数推广至函数，核心在于探讨无限求和与极限、积分、导数运算交换顺序的合法性。

1. **逐点收敛 vs 一致收敛**
    
    - **逐点收敛**：固定点处的数列极限。
        
    - **一致收敛**：整个函数族在定义域上具备“公共误差阈值 $N$”同步逼近和函数 。内闭一致收敛指在区间任意闭子区间上一致收敛 。
        
2. **一致收敛的判别工具**
    
    - **函数列**：柯西准则 。
        
    - **【重点：首选判别法】**：考察函数列一致收敛最直接、考频最高的工具是上确界判别法（$M_n$ 判别法），即验证 $\lim_{n \to \infty} \sup_{x \in D} |f_n(x) - f(x)| [cite_start]= 0$ 。
        
    - **函数项级数**：部分和函数列是否一致收敛 ；柯西收敛准则（推论：通项一致趋于0） ；Weierstrass优级数判别法（M-判别法）、狄利克雷判别法、阿贝尔判别法 。
        
3. **一致收敛的三大分析性质（交换定理）**
    
    - **【重点：极限交换】**：若 $f_n \rightrightarrows f$ 且每项连续，则极限号与极限趋近过程可交换。证明题中常常利用这一点考察函数列的连续性、可积性和可微性 。
        
    - **函数项级数**：和函数保持连续性，且支持逐项求积、逐项求导 。要求导数序列必须一致收敛，条件最为严苛。
        

### 三、 幂级数与泰勒展开

探讨解析函数向多项式级数的局部展开形式。

1. **收敛域与收敛半径**
    
    - 根据阿贝尔第一定理，收敛域具有对称的圆盘结构（区间）。
        
    - **【重点：收敛半径的具体计算】**：利用 $\rho = \lim_{n \to \infty} \sqrt[n]{|a_n|}$ 或比值极限求得收敛半径 $R=1/\rho$ 。遇到如 $\sum a_n x^{2n-1}$ 这类带缺项的幂级数时，**不可生搬硬套公式**，必须直接利用定义 $\lim_{n \to \infty}\sqrt[n]{|a_n x^{2n-1}|} < 1$ 去求解实际的收敛半径 。
        
2. **幂级数的分析性质**
    
    - 在收敛区间内绝对收敛 ；在收敛域内内闭一致收敛 。
        
    - **【重点：逐项操作】**：在收敛区间内可任意次逐项求导、求积 。解题常利用已知基础函数（如 $1/(1+x), e^x, \sin x$ 等）的展开式，借由逐项求积或求导推导出新级数的和函数 。
        

### 四、 傅里叶级数

利用正交三角函数系实现对于周期函数的全局逼近。

1. **三角函数系与傅里叶系数**
    
    - 对于 $2\pi$ 周期函数，系数公式为 $a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx dx$ ；$b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx dx$ 。
        
    - 一般周期 $2T$ 可通过变量代换推导 。奇函数展开为正弦级数，偶函数展开为余弦级数 。
        
2. **核心预备理论与收敛定理**
    
    - **【重点：贝塞尔不等式】**：$\frac{a_0^2}{2} + \sum (a_n^2 + b_n^2) \le \frac{1}{\pi} \int f^2(x)dx$ 极其重要 。直接推论即黎曼-勒贝格引理（系数趋于0）。
        
    - **狄利克雷收敛定理**：按段光滑条件下，收敛于左右极限平均值 $\frac{f(x+0) + f(x-0)}{2}$。
        
3. **【重点：三角级数属性判定】**
    
    - 考卷中常设问“判别给定三角级数是否为傅里叶级数” 。
        
    - **判定准则**：若该级数满足一致收敛（利用优级数判别法），则必定是某连续函数的傅里叶级数 ；若系数平方和 $\sum(a_n^2+b_n^2)$ 发散，则根据贝塞尔不等式，必定不是傅里叶级数 。
        

## 第二篇：多元函数的连续性与微分学

### 一、 拓扑基础与多元函数极限连续

1. **点集拓扑**
    
    - 包含邻域、内点、边界、聚点及开闭集理论。有界闭集等价于紧集（具备序列紧致性）。
        
2. **多元函数极限**
    
    - **【重点：重极限的不存在性证明】**：利用反证逻辑，若以不同斜率的直线路径（归结原则）趋于 $(x_0, y_0)$ 时极限值不同，或以某种路径趋近时极限为无穷，则证明该重极限不存在 。
        
    - 重极限存在与累次极限存在互不蕴含，但若均存在则必定相等 。
        
3. **连续性**
    
    - 极限值等于函数值，即当 $(\Delta x, \Delta y) \to (0,0)$ 时 $|f(x_0+\Delta x, y_0+\Delta y) - f(x_0, y_0)| [cite_start]\to 0$ 。
        
    - 有界闭集上的连续函数具备有界性、取得最值以及一致连续性 。
        

### 二、 多元函数微分学与方向导数

1. **偏导数、方向导数与梯度**
    
    - **方向导数**：函数沿某单侧射线方向的变化率。若函数可微，则方向导数等于梯度向量与方向单位向量的内积，即 $\frac{\partial f}{\partial \vec{l}}(P_0) = \text{grad} f(P_0) \cdot \vec{l}$ 。
        
    - **梯度**：标量场的最大变化率方向，$\nabla f = (f_x, f_y)$。
        
2. **【重点：可微性的两步判定法】**
    
    - **考频极高**：判别函数在点 $P_0(x_0, y_0)$ 处的可微性 。
        
    - **步骤一（必要条件）**：首先求出该点的偏导数 $A = f_x(P_0)$ 与 $B = f_y(P_0)$ 。若不存在，则不可微。
        
    - **步骤二（验证极限）**：检验线性主部逼近误差，即判断极限 $\lim_{(\Delta x, \Delta y) \to (0,0)} \frac{|f(x_0+\Delta x, y_0+\Delta y) - f(x_0, y_0) - A\Delta x - B\Delta y|}{\sqrt{\Delta x^2 + \Delta y^2}}$ 是否严格等于 0 。等于0则可微，否则不可微。
        
    - **充分条件**：所有偏导函数在点 $P_0$ 连续 。
        

### 三、 复合求导、中值定理与泰勒公式

1. **链式法则与雅可比矩阵**
    
    - 复合函数求导严循链式法则（树状图法分叉相加、连线相乘），形如 $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$ 。高阶偏导数需将一阶偏导数视作新的复合函数继续运用链式法则求解 。
        
    - 一阶全微分形式不变性（外在代数表达形式恒定）。
        
2. **中值定理与泰勒公式**
    
    - 多元增量可展开为海森矩阵（Hessian Matrix）的二次型项与高阶无穷小余项（皮亚诺或拉格朗日余项） 。
        

### 四、 隐函数定理及其几何与极值应用

1. **隐函数定理与逆映射**
    
    - **存在唯一性与可微性**：对于方程 $F(x,y)=0$，若 $F_y \neq 0$ 且偏导连续，则局部存在隐函数，导数为 $\frac{dy}{dx} = -\frac{F_x}{F_y}$ 。计算也可采用方程两边直接关于自变量求导法 。
        
2. **【重点：几何应用的推导方法】**
    
    - **曲线/曲面的切线与法线** 。
        
    - **考场技巧**：对于两曲面交线确定的空间曲线切线与法平面，不要死记硬背公式，强烈建议直接计算两曲面法向量的外积取得切向量公式。对于隐式曲面 $F(x,y,z)=0$ 的法线公式 $\frac{x-x_0}{F_x(P_0)} = \frac{y-y_0}{F_y(P_0)} = \frac{z-z_0}{F_z(P_0)}$ 必须熟练掌握 。
        
3. **多元函数极值体系**
    
    - **无条件极值**：求驻点 $f_x=f_y=0$ 。利用海森矩阵 $H_f(P_0)$ 判别：正定为极小值点，负定为极大值点，不定则不是极值点 。
        
    - **【重点：条件极值】**：拉格朗日乘数法是重点应用题型，构造函数 $L = f + \sum \lambda_k \varphi_k$，用于计算区域边界点的条件极值点 。
        

## 第三篇：多元函数的积分学与场论

### 一、 重积分理论

1. **二重、三重积分计算策略**
    
    - **【重点：画图与雅可比行列式】**：计算重积分化为累次积分时，**必须借助作图来确定坐标与积分边界范围** ；在进行变量替换（极坐标、柱坐标、球坐标）时，绝对不可遗忘雅可比行列式 $|J|$ 的绝对值 。
        
    - 交换累次积分的顺序也是高频操作，常用于内层积分原函数难以初等表示时 。
        
2. **几何应用**
    
    - 面积 $\sigma(D) = \iint_D dxdy$，体积 $V(\Omega) = \iiint_\Omega dxdydz$ 。
        

### 二、 曲线与曲面积分

积分学两大体系，核心区分是否带有方向。

1. **第一型积分（对弧长 $ds$ / 对面积 $dS$）**
    
    - 与方向无关。计算需代入参数方程并乘上放大微元（如 $\sqrt{1+(y')^2}dx$ 或 $\sqrt{1+z_x^2+z_y^2}dxdy$）转化为定积分或二重积分 。
        
2. **第二型积分（对坐标）**
    
    - 物理意义对应做功或通量，**与路径/曲面侧面方向严格相关**（反向变号） 。
        
    - 第二型曲面积分化二重积分（投影法）：根据曲面方程投影至某坐标面，利用方向余弦法向分量决定正负号，公式形如 $\pm \iint_D (-P z_x - Q z_y + R) dxdy$ 。
        

### 三、 【重点：三大公式核心应用】

本学期压轴内容，**考试中三大公式必将涉及两个及以上，且着重考察辅助几何构建** 。

1. **格林公式 (Green's Theorem)**
    
    - **定理表述**：平面区域正向边界积分 $\oint_{\partial D} P dx + Q dy = \iint_D (\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}) dxdy$ 。
        
    - **关键解题技巧（补线法）**：当曲线不封闭时，通过添加辅助线构成闭区域应用公式，再减去辅助线上的积分值，即 $\int_L = \oint_{L \cup L_1} - \int_{L_1}$ 。
        
2. **高斯公式 (Gauss's Theorem)**
    
    - **定理表述**：将空间闭曲面（外侧）的积分转化为三重散度积分 $\iint_{\partial \Omega} P dydz + \dots = \iiint_\Omega (\frac{\partial P}{\partial x} + \frac{\partial Q}{\partial y} + \frac{\partial R}{\partial z}) dxdydz$ 。
        
    - **关键解题技巧（补面法）**：遇到非封闭有向曲面，需添加辅助曲面 $\Sigma_1$ 构成闭立体 $\Omega$，应用公式后再减去辅助面 $\Sigma_1$ 上的第二型曲面积分 。
        
3. **斯托克斯公式 (Stokes' Theorem)**
    
    - **定理表述**：将空间闭曲线积分化为旋度在曲面上的积分，满足右手法则诱导定向 。
        
    - 适用于将复杂的空间闭曲线第二型积分降维至曲面计算 。
        

### 四、 含参量积分（正常积分）

1. **【重点：基本性质】**
    
    - 在积分范围恒定且无广义奇点的含参量正常积分框架下，掌握其基本的三大操作性质：**连续性传递、含参量求导（可微性）以及累次积分交换顺序** 。考频相对于三大公式略低，注重理论验证即可。
