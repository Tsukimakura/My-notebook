## Chapter 1: Introduction

**1.1 Problem Description**

The "Dijkstra Sequence" problem requires us to verify whether a given permutation of vertices constitutes a valid sequence of vertex expansions as produced by Dijkstra's algorithm. Given an undirected, connected graph with $N_v$ vertices and $N_e$ weighted edges, we are provided with $K$ queries. Each query is a sequence of vertices. We must determine if each sequence strictly follows the greedy choice property of Dijkstra's algorithm (i.e., at every step, the next selected vertex must have the minimum shortest-path distance among all currently unvisited vertices).

**1.2 Background of the Algorithm**

Conceived by Edsger W. Dijkstra in 1956, Dijkstra's algorithm is a fundamental greedy algorithm used to solve the single-source shortest path problem for a graph with non-negative edge weights. It maintains a set of unvisited nodes and iteratively selects the node with the smallest tentative distance from the source. Because multiple nodes might share the same minimum distance at any given step, a single graph can yield multiple valid Dijkstra sequences.

## Chapter 2: Algorithm Specification

**2.1 Main Data Structures**

To efficiently store the graph and process queries, the following data structures are utilized:

- **Adjacency List (`LGraph` & `AdjListNode`):** An array of pointers to linked lists. This is chosen over an adjacency matrix to save memory, as the maximum number of edges $N_e \le 10^5$ is relatively sparse compared to $N_v \le 10^3$.
    
- **Distance Array (`dist`):** An integer array of size $N_v + 1$ to track the shortest distance from the source to each vertex. Initialized to `INFINITY`.
    
- **Visited Array (`known`):** A boolean/integer array to mark whether a vertex's shortest path has been permanently determined.
    

**2.2 Algorithm Description**

The core algorithm simulates the execution of Dijkstra's algorithm against the provided sequence.

1. **Initialization:** Set the distance of the first vertex in the sequence (the source) to 0.
    
2. **Sequence Traversal:** For each vertex $V_{curr}$ in the given sequence:
    
    - Scan the `dist` array to find the absolute minimum distance (`min_dist`) among all currently unvisited vertices.
        
    - **Validation:** Compare `dist[`$V_{curr}$`]` to `min_dist`. If `dist[`$V_{curr}$`]` $> min\_dist$, the sequence violates the greedy choice property. Return `False`.
        
    - Mark $V_{curr}$ as visited.
        
    - **Relaxation:** Traverse the adjacency list of $V_{curr}$. For each adjacent unvisited vertex $V_{next}$, update its distance if `dist[`$V_{curr}$`] + weight < dist[`$V_{next}$`]`.
        
3. **Completion:** If the loop finishes without violations, return `True`.
    

**2.3 Pseudo-code for Query Validation**

```text
Function Query(Sequence, Graph):
    Initialize dist[] to INFINITY, known[] to False
    dist[Sequence[0]] = 0
    
    For i from 0 to Graph.Nv - 1:
        curr = Sequence[i]
        min_dist = INFINITY
        
        // Find true minimum among unvisited
        For j from 1 to Graph.Nv:
            if not known[j] and dist[j] < min_dist:
                min_dist = dist[j]
                
        // Greedy property check
        if dist[curr] > min_dist:
            return False
            
        known[curr] = True
        
        // Edge Relaxation
        For each neighbor of curr:
            if not known[neighbor]:
                new_dist = dist[curr] + weight(curr, neighbor)
                if new_dist < dist[neighbor]:
                    dist[neighbor] = new_dist
                    
    return True
```

- Sequence 1 (`1 3 2`) visits `3` first. During the relaxation of `3`, `dist[2]` is correctly updated from `10` to `5`. The sequence is validated as `Yes`.

## Chapter 4: Analysis and Comments

**4.1 Time Complexity**

- **Graph Construction:** Reading the input and building the adjacency list takes $O(N_e)$ time.
    
- **Sequence Validation (Query):** For each sequence of length $N_v$, we iterate $N_v$ times. Inside the loop, finding `min_dist` takes $O(N_v)$. The relaxation step processes the edges. Across the entire sequence, every edge is visited at most twice, taking $O(N_e)$ time. Therefore, the time complexity for validating one sequence is $O(N_v^2 + N_e)$.
    
- **Total Time Complexity:** For $K$ queries, the overall time complexity is $O(N_e + K \times (N_v^2 + N_e))$. Given $N_v \le 1000$, $N_e \le 100000$, and $K \le 100$, the maximum operations are well within standard 1-second execution limits (approx. $10^8$ operations).
    

**4.2 Space Complexity**

- **Graph Storage:** The adjacency list requires an array of $N_v$ head pointers and $2 \times N_e$ nodes (since it is an undirected graph). This takes $O(N_v + N_e)$ space.
    
- **Query State:** The `dist` and `known` arrays allocated inside the `Query` function each take $O(N_v)$ space.
    
- **Total Space Complexity:** $O(N_v + N_e)$, which easily fits within standard memory limits (e.g., 64MB).
    

**4.3 Comments on Further Improvements**

While standard Dijkstra implementations often use a Min-Heap (Priority Queue) to reduce the minimum-finding step from $O(N_v)$ to $O(\log N_v)$, introducing a heap here is **not strictly necessary**. Because we are _verifying_ a sequence rather than searching blindly, we still must validate that the provided `curr` node's distance is equal to the absolute minimum. Given the very small constraint of $N_v \le 1000$, a linear scan $O(N_v)$ involves zero structural overhead, utilizes contiguous memory caching efficiently, and executes extremely fast.

## Appendix: Source Code (in C)

```c
#include <stdio.h>
#include <stdlib.h>
#define MAXNV 1010
#define MAXNE 100010

// Define an appropriately large value for INFINITY
#define INFINITY MAXNE*105

// Use typedef to make the vertex data type clear and semantic
typedef int Vertex;

// Structure representing a node in the adjacency list.
// Each node represents a directed edge originating from a specific vertex.
typedef struct AdjListNode{
    Vertex dest;  // The destination vertex of this edge
    int weight;   // The weight/cost of this edge
    struct AdjListNode *next;  // Pointer to the next adjacent node in the list
} AdjListNode;

// Structure representing the graph using an array of linked lists (Adjacency List)
typedef struct LGraph{
    int nv;  // Number of vertices in the graph
    int ne;  // Number of edges in the graph
    AdjListNode *heads[MAXNV];  // Array of pointers, each pointing to a linked list of edges
} LGraph;

typedef LGraph *Graph;

// Allocates memory for a new graph, sets the number of vertices and edges,
// and initializes all adjacency list head pointers to NULL.
Graph InitGraph(int nv, int ne){
    Graph G = (Graph)malloc(sizeof(LGraph));
    G->nv = nv;
    G->ne = ne;
    for(int i = 1; i <= nv; i++){
        G->heads[i] = NULL;
    }
    return G;
}

// Inserts a new directed edge from v1 to v2 into the graph using head insertion
// For undirected graphs, this should be called twice (v1 to v2, and v2 to v1)
void AddEdge(Vertex v1, Vertex v2, int w, Graph G){
    AdjListNode *tmp = G->heads[v1];
    AdjListNode *NewEdge = (AdjListNode*)malloc(sizeof(AdjListNode));
    NewEdge->dest = v2;
    NewEdge->weight = w;
    // Insert the new edge at the beginning of the linked list
    G->heads[v1] = NewEdge;
    NewEdge->next = tmp;
}

// Simulates Dijkstra's algorithm to check if the given sequence 'seq' is a valid
// order of vertex extraction.
// Returns: 1 if it is a valid Dijkstra sequence, 0 otherwise
int Query(Vertex *seq, int nv, Graph G){
    int *dist = (int*)malloc((nv+1)*sizeof(int));
    int *known = (int*)malloc((nv+1)*sizeof(int));
    // Step 1: Initialize distances to INFINITY and all nodes as unvisited (0)
    for(int i = 1; i <= nv; i++){
        known[i] = 0;
        dist[i] = INFINITY;
    }
    // The first vertex in the sequence is the source. Set its distance to 0
    dist[seq[0]] = 0;
    // Step 2: Iterate through the given sequence vertex by vertex
    for(int i = 0; i < nv; i++){
        Vertex curr = seq[i];
        int min_dist = INFINITY;
        // Step 3: Find the true minimum distance among all unvisited vertices
        for(int j = 1; j <= nv; j++){
            if(!known[j] && dist[j] < min_dist){
                min_dist = dist[j];
            }
        }
        // Step 4: Validate the sequence
        // If the currently proposed vertex has a distance strictly greater than
        // the true minimum distance, it violates the greedy choice property
        if(dist[curr] > min_dist){
            free(dist);
            free(known);
            return 0; // Invalid sequence
        }
        // Mark the current vertex as visited/known
        known[curr] = 1;
        // Step 5: Relaxation process
        // Iterate through all adjacent vertices of 'curr' and update their
        // shortest distances if a shorter path is found
        AdjListNode *tmp = G->heads[curr];
        while(tmp != NULL){
            Vertex Next = tmp->dest;
            // If the adjacent node is unvisited AND the path through 'curr' is strictly shorter
            if(!known[Next] && dist[curr] + tmp->weight < dist[Next]){
                dist[Next] = dist[curr] + tmp->weight; // Update shortest distance
            }
            tmp = tmp->next; // Move to the next adjacent edge
        }
    }

    // If the loop completes without returning 0, the sequence is perfectly valid
    free(dist);
    free(known);
    return 1;
}

// Handles standard input/output, constructs the graph, and processes queries
int main(){
    int nv, ne, k;
    int v1, v2, weight;
    scanf("%d %d", &nv, &ne);
    Graph G = InitGraph(nv, ne);
    for(int i = 0; i < ne; i++){
        scanf("%d %d %d", &v1, &v2, &weight);
        AddEdge(v1, v2, weight, G);
        AddEdge(v2, v1, weight, G);
    }
    scanf("%d", &k);
    Vertex *seq = (Vertex*)malloc(nv*sizeof(Vertex));
    for(int i = 0; i < k; i++){
        for(int j = 0; j < nv; j++){
            scanf("%d", &seq[j]);
        }
        if(Query(seq, nv, G)){
            printf("Yes\n");
        }else{
            printf("No\n");
        }
    }
    free(seq);
    return 0;
}
```

#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <stdbool.h>

#define NV 1000
#define NE 100000
#define K 100

// Adjacency matrix to prevent duplicate edges during generation
bool adj[NV + 1][NV + 1];

int main() {
    // Seed the random number generator
    srand(time(NULL));
    
    // Print Nv and Ne
    printf("%d %d\n", NV, NE);

    int edges_added = 0;
    
    // Step 1: Generate a random spanning tree to guarantee the graph is connected
    for (int i = 2; i <= NV; i++) {
        int u = (rand() % (i - 1)) + 1; // Connect to a randomly chosen existing node
        int v = i;
        int w = (rand() % 100) + 1;     // Random weight between 1 and 100
        printf("%d %d %d\n", u, v, w);
        adj[u][v] = adj[v][u] = true;
        edges_added++;
    }

    // Step 2: Fill in the remaining edges to reach exactly NE
    while (edges_added < NE) {
        int u = (rand() % NV) + 1;
        int v = (rand() % NV) + 1;
        // Avoid self-loops and duplicate edges
        if (u != v && !adj[u][v]) {
            int w = (rand() % 100) + 1;
            printf("%d %d %d\n", u, v, w);
            adj[u][v] = adj[v][u] = true;
            edges_added++;
        }
    }

    // Step 3: Generate K queries (Random permutations of Nv vertices)
    printf("%d\n", K);
    for (int q = 0; q < K; q++) {
        int seq[NV + 1];
        for (int i = 1; i <= NV; i++) seq[i] = i;
        
        // Fisher-Yates shuffle to create a random permutation
        for (int i = NV; i > 1; i--) {
            int swap_idx = (rand() % i) + 1;
            int temp = seq[i];
            seq[i] = seq[swap_idx];
            seq[swap_idx] = temp;
        }
        
        // Output the sequence
        for (int i = 1; i <= NV; i++) {
            printf("%d%s", seq[i], i == NV ? "" : " ");
        }
        printf("\n");
    }
    
    return 0;
}
